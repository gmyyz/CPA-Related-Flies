# CPA 会计复习资料库

一套围绕 CPA《会计》30 章整理的个人复习资料库。项目把章节笔记、专题知识卡片和可离线打开的复习网页放在同一套可验证的源码流程中。

> 项目状态：已完成主要复习内容，作为学习成果归档与可持续维护的静态网站项目保存。

## 在线复习页

主分支会由 GitHub Actions 自动构建并部署到 GitHub Pages：

<https://gmyyz.github.io/CPA-Related-Flies/>

网页支持章节筛选、搜索、知识卡片、易错点和重点分录复习；也可以直接下载仓库中的离线 HTML 文件使用。

## 项目结构

```text
01-会计/
├── 00-学习管理/       学习清单与复习进度资料
├── 01-章节笔记/       按专题沉淀的 Markdown 笔记
├── 02-参考资料/       可公开的文字与图片参考资料
└── 99-历史备份/       已归档的历史文本资料

会计复习网页/
├── data/              卡片内容与章节索引
├── src/               页面模板、样式、交互源码
├── scripts/           构建与数据校验脚本
├── tests/             Node.js 测试
└── CICPA会计复习手册.html  构建生成的离线成品

docs/                  项目维护说明
.github/workflows/     GitHub Pages 自动构建与发布
```

## 本地使用

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run check
open '会计复习网页/CICPA会计复习手册.html'
```

`npm run check` 会重新构建页面、运行测试，并确认生成文件与源码一致。

## 源码与生成物

| 内容 | 维护位置 | 说明 |
| --- | --- | --- |
| 知识卡片 | `会计复习网页/data/topics/` | 日常补充或勘误的主要入口 |
| 卡片顺序和元信息 | `会计复习网页/data/index.mjs`、`data/meta.mjs` | 新增卡片时同步维护 |
| 页面样式与交互 | `会计复习网页/src/` | 唯一网页源码入口 |
| 构建逻辑 | `会计复习网页/scripts/` | 生成和校验数据、离线网页 |
| 离线 HTML 与 `study-data.js` | 构建生成 | 不直接编辑，执行构建后更新 |

详细维护流程见 [维护指南](docs/维护指南.md)。

## 资料边界

仓库只保留本人整理的 Markdown、网页源码、必要的生成页面和公开说明。课程 PDF、工作簿、浏览器测试截图等本地资料均不再上传，统一由 `.gitignore` 排除；它们不会影响本地复习使用。

本项目为个人学习整理，不替代教材、准则、官方辅导材料或专业意见。引用或使用任何第三方课程、讲义与素材前，请自行确认授权范围。
