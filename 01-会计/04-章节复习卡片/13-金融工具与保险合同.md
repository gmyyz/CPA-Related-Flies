## 02｜二、金融资产分类与计量：总决策树

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

先排除应适用长期股权投资等其他准则的资产，再按以下规则分类。

| 工具与条件 | 一般分类 |
| --- | --- |
| 债务工具通过SPPI，业务模式为收取合同现金流量 | AC |
| 债务工具通过SPPI，业务模式为收取现金流量并出售 | 债务工具FVOCI |
| 债务工具未通过SPPI，或不属于上述业务模式 | FVTPL |
| 衍生金融资产 | 通常FVTPL；符合条件的套期会计另行处理 |
| 非交易性权益工具投资 | 初始确认时可以指定为FVOCI且不得撤销，否则FVTPL |
| 交易性权益工具投资 | FVTPL，不能指定FVOCI |

**消除或显著减少会计错配时，初始确认可以将金融资产指定为FVTPL且不得撤销；适用于原本满足AC或债务工具FVOCI条件的资产，不仅限于AC。**

业务模式在管理金融资产的适当汇总层次判断，同一企业可有多个模式，不能依据对单项资产的临时出售意图随意改变分类。“收取合同现金流量”也不等于绝对禁止出售。

债务工具FVOCI来自业务模式与现金流特征的分类；权益工具FVOCI来自符合条件的初始指定，两者后续利息、减值和处置规则不同，见第十六、十七节。

## 03｜三、金融资产定义：四类权利

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

| 类别 | 定义与例子 |
| --- | --- |
| 现金、其他方权益工具、收款合同权利 | 现金、持有其他公司股票、应收账款、应收票据等；普通预付货款取得商品或服务，通常不属于金融资产 |
| 在潜在有利条件下交换金融资产或金融负债的合同权利 | 如买入以其他公司股票为标的的看涨期权；是否预计行权不决定金融资产身份 |
| 以自身权益工具结算的非衍生合同 | 企业将根据合同收到可变数量自身权益工具 |
| 以自身权益工具结算的衍生合同 | 不属于以固定数量自身权益工具交换固定金额现金或其他金融资产的合同；具体权益条件及例外见第五节 |

### 买入期权：金额例题

支付5万元买入看涨期权，未来可付100万元购买乙公司股票；假设按FVTPL计量，期末价值8万元：

```text
取得期权：
借：衍生金融资产 5
  贷：银行存款 5
升值：
借：衍生金融资产 3
  贷：公允价值变动损益 3
行权，结算日价值仍为8：
借：相关股票投资 108
  贷：银行存款 100
      衍生金融资产 8
另一情形：未行权失效，从账面8冲至0：
借：公允价值变动损益 8
  贷：衍生金融资产 8
```

行权所得股票按自身分类核算，不能仅凭购股来自期权就指定为其他权益工具投资。

### 可变数量自身股票

企业支付100万元，约定以后收取价值100万元的自身普通股：结算股价10元则收10万股，20元则收5万股。非衍生合同下收股数量可变，合同权利满足金融资产定义；**是否按FVTPL计量仍须另做分类判断**。

实际收回自身股票后按库存股处理，不再列为金融资产。结算分录为借库存股、贷相关金融资产，按结算时应转出的金额核算。反向的“交付可变数量自身股”通常形成金融负债。

### 非权益类衍生合同：正负头寸转换

不满足权益分类条件、按FVTPL计量的自身股票衍生合同，公允价值为正20万元时为金融资产；以后变为负15万元，确认损失35万元：

```text
先确认正头寸：
借：衍生金融资产 20
  贷：公允价值变动损益 20
转为负头寸：
借：公允价值变动损益 35
  贷：衍生金融资产 20
      衍生金融负债 15
```

分录可依科目设置使用“衍生工具”等明细；科目名称与FVTPL分类概念分开理解，不能把所有衍生工具都视为普通股权投资。

## 04｜四、金融负债定义与准则范围

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

先看合同支付义务，再看专门准则的适用范围；不能以“未来付现金”一项判断所有负债。

| 项目 | 处理边界 |
| --- | --- |
| 借款、应付货款等合同现金支付义务 | 通常适用金融工具准则 |
| 借入其他公司股票并卖出，负有归还股票义务 | 交付其他方权益工具的义务，通常为金融负债 |
| 普通预收货款、合同负债 | 主要义务为交货或服务，通常不属于金融负债；退款义务另按合同判断 |
| 职工薪酬相关计划形成的权利义务 | 由职工薪酬准则规范，不因现金支付而套用金融工具确认计量规则 |
| 保证类质量保证的维修义务 | 通常按或有事项准则确认预计负债 |
| 收取后须退还的质量保证金或押金 | 属合同现金偿付义务时通常为金融负债，不能与上行的保修义务混淆 |

奖金例：计提30万元，借管理费用／生产成本等30，贷应付职工薪酬30。其科目和准则归属不会因最终付现而改变。

“排除在某金融工具准则适用范围之外”与“不满足金融负债定义”并非同一判断；应付职工薪酬相关计划有明确专门准则。本章后续涉及租赁、保险等也先判断适用范围。

## 05｜五、权益工具与金融负债：一般判断及结算方式

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

发行方依据合同实质判断，不只看“优先股”“认股权证”等名称。

| 判断 | 权益分类通常要求 |
| --- | --- |
| 现金或其他金融资产义务 | 能无条件避免交付，不存在潜在不利交换义务 |
| 涉及自身权益工具的非衍生合同 | 不包括交付可变数量自身权益工具的合同义务 |
| 涉及自身权益工具的衍生合同 | 通过固定数量自身权益工具交换固定金额现金或其他金融资产结算，即固定换固定 |

“固定换固定”不能不加区分地套在所有非衍生工具上。可回售工具、仅清算时交付净资产等须再看准则的特定例外；承担现金回购自身权益工具义务还须确认相应负债，见第七、八节。

不分红引起股价下跌、普通股分红受限等经济压力本身不等于合同支付义务；合同中形成的间接义务则须识别，见第六节“永续债等类似工具”。

### 固定换固定的认股权证

例：甲发行欧式看涨期权，投资者可按30元/股购买甲10万股、每股面值1元，合同只能收款并总额交付这些普通股，不得现金净额结算。初始期权费90万元，年末期权价值100万元、股价40元。

```text
发行：
借：银行存款 90
  贷：其他权益工具 90
权益分类后不重估，价值90变100不确认损益。
行权：
借：银行存款 300
    其他权益工具 90
  贷：股本 10
      资本公积——股本溢价 380
```

价款、股数和允许的结算方式均须核对，不能只见股数固定就判权益。

### 强制转股与结算选择权

优先股无强制付息、无赎回义务，10年后强制转普通股：若为非衍生工具且固定比例转股，通常支持权益分类；若按面值除以转股日股价确定交付股数，则股数可变，通常为金融负债。

衍生合同有结算选择权时，**所有可选方式均符合权益条件才可列权益**。即使现金净额结算选择权属于发行方，也不能只看另一条固定换固定路径；若各选项都只是符合权益条件的固定数量A类或B类自身股，则可列权益。

依据：[2017金融工具列报准则](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694118.htm)。

## 06｜六、永续债等类似工具

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

将到期日、清偿顺序、票息和间接义务结合判断，不以“永续”名称直接认定权益。

| 因素 | 判断要点 |
| --- | --- |
| 无固定到期日 | 持有人无权要求赎回或清算，且其他条款不形成现金义务时，通常支持权益分类 |
| 约定未来赎回日 | 须能无条件自主决定不赎回；仅约定清算日通常不形成支付义务，但清算确定会发生且不受发行方控制、或由持有方决定的除外 |
| 清偿顺序 | 劣后普通债券及其他债务，在其他条款不形成支付义务时支持权益判断；与普通债同顺序须审慎评估，不是自动列权益或负债 |
| 利率跳升 | 结合实际环境判断间接义务；有封顶不等于一定无义务 |

跳升次数有限、有封顶且封顶未超过同期同行业同类型工具平均利率，或跳升总幅度较小且封顶未超过该水平，可能不构成间接义务；封顶高于该水平通常构成间接义务。不要简化成任何经济压力都等于负债。

持有方分类按第二节总决策树，并分析选择权条款；不能直接采用发行方报表科目作为持有方计量类别。

依据：[财政部《永续债相关会计处理的规定》](https://m.mof.gov.cn/zcfb/201901/P020190130562568550137.pdf)。

## 07｜七、权益工具与金融负债区分：附回购条款增资的两种计量

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 判断与计量

先判断企业能否无条件避免现金回购，再按合同实质确定负债类别，最后选择科目。除准则规定的特殊权益工具等例外，发行方承担现金回购自身股份的义务，即使是否回购取决于持有人行使回售权，也应按回购支付金额现值确认金融负债并扣减权益。

| 回购安排 | 后续计量判断 |
| --- | --- |
| 固定本金加固定收益，属于普通融资负债 | 通常采用摊余成本和实际利率法；不能直接把合同收益率当实际利率 |
| 回购额与股价等变量挂钩 | 评估衍生条款及是否分拆、整体FVTPL等适用条件，不能仅凭“挂钩股价”认定整个工具都是衍生工具 |

一般金融负债分类见本章基础分类，嵌入衍生工具见第十三节。科目名称不决定计量基础。

### 固定收益例：未上市则回购

甲公司每股10元发行4,000万股，每股面值1元，收到40,000万元；约定3年内未上市则按本金加年收益率8%回购。上市成功并非甲公司可单方面控制，不能因此避免确认回购义务。假设该普通融资负债初始公允价值及回购金额现值均为40,000万元：

~~~text
借：银行存款 40,000
    贷：股本 4,000
    贷：资本公积——股本溢价 36,000

借：库存股 40,000
    贷：长期应付款——股份回购义务 40,000
~~~

本例采用库存股作为权益扣减科目；其他具体安排应结合合同及核算要求确定权益科目，不能只将36,000万元股本溢价确认为负债。上述两笔合计使权益净增加为零。

若题目另给实际利率为8%，首年融资费用为40,000×8%=3,200万元：

~~~text
借：财务费用 3,200
    贷：长期应付款——股份回购义务 3,200
~~~

若回购收益按单利累积，须结合最终现金流求实际利率，不能连续各年均按期初摊余成本乘合同单利8%。

### 股价挂钩例：股权价值与本息孰高

保留原笔记的5,000万元练习：投资者取得20%股权，其中实收资本500万元；未上市时，回购价为该股权公允价值与本金加8%单利收益孰高。**以下分录以题设已确定回购负债整体采用FVTPL，且各期估值分别为5,000、5,400和6,000万元为前提**。原题完整估值条件未附，不能把回购公式直接等同于任一报告日的负债公允价值；实际估值还需考虑期限等相关因素。

| 时点 | 20%股权价值 | 累计固定本息 | 本练习采用的负债估值 | 本期增加 |
| --- | ---: | ---: | ---: | ---: |
| 2×19年初 | — | 5,000 | 5,000 | — |
| 2×19年末 | 26,000×20%=5,200 | 5,000×1.08=5,400 | 5,400 | 400 |
| 2×20年末 | 30,000×20%=6,000 | 5,000×(1+8%×2)=5,800 | 6,000 | 600 |

~~~text
借：银行存款 5,000
    贷：实收资本 500
    贷：资本公积 4,500

借：资本公积 5,000
    贷：交易性金融负债 5,000

借：公允价值变动损益 400
    贷：交易性金融负债 400

借：公允价值变动损益 600
    贷：交易性金融负债 600
~~~

2×21年1月15日新协议解除回购条款，属于新发生事项，不调整2×20年末报表。若解除时负债账面价值仍为6,000万元，原股份继续存续且不再附回购义务：

~~~text
借：交易性金融负债 6,000
    贷：资本公积 6,000
~~~

依据：[金融工具列报准则第十一、十二条](https://www.mof.gov.cn/gkml/caizhengwengao/2017wg/wg201706/201708/P020170818533174427263.pdf)。

## 08｜八、权益工具与金融负债区分：子公司少数股东看跌期权

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 三种报表视角

母公司签出以子公司股份为标的的现金实物交割看跌期权，须分别判断各主体的合同义务：

| 报表层面 | 确认与计量 |
| --- | --- |
| 母公司个别报表 | 签出期权通常为衍生金融负债，按期权公允价值计量，变动计入当期损益 |
| 子公司个别报表 | 确无相关合同权利义务时不处理；不能只凭回购方写的是母公司就断言子公司没有义务 |
| 母公司合并报表 | 集团不能无条件避免现金回购少数股东权益时，按回购支付金额现值确认金融负债并扣减权益，不等到实际行权才确认 |

财政部应用案例特别指出：子公司作为协议一方，如无法证明自己不属于母公司可指定的回购方，也可能承担自身股份回购义务。

### 金额例：期权公允价值与回购现值不同

甲持乙80%股权，向少数股东签出6个月后以1,000万元购入剩余20%股权的看跌期权。签约日期权公允价值60万元，回购金额现值950万元；行权前期权公允价值升至100万元。乙不承担合同义务，忽略税费。

**个别报表。**初始确认60万元衍生金融负债，借方取决于取得的对价及交易实质，不能只凭期权公允价值便直接确认60万元损失。为演示完整分录，另假设甲签约时收到等额期权费60万元：

~~~text
借：银行存款 60
    贷：衍生金融负债 60

借：公允价值变动损益 40
    贷：衍生金融负债 40
~~~

期权实物交割时，同时结清100万元衍生负债并取得股权；在该简化例中，新增长投为1,000−100=900万元：

~~~text
借：长期股权投资 900
借：衍生金融负债 100
    贷：银行存款 1,000
~~~

不能只记“借长投1,000、贷银行1,000”后遗漏衍生负债的结算；如合同为现金净额结算或与其他交易构成一揽子安排，应按实际条款处理。

**合并报表。**回购义务初始为950万元，不能直接沿用个别报表的60万元期权负债。以下仅列回购义务的处理，权益扣减项目须结合少数股东是否仍享有当前所有权收益等合同事实判断：

~~~text
借：权益扣减项目 950
    贷：金融负债——少数股权回购义务 950
~~~

若后续仅有折现摊回，至行权日增加50万元并支付：

~~~text
借：财务费用 50
    贷：金融负债——少数股权回购义务 50

借：金融负债——少数股权回购义务 1,000
    贷：银行存款 1,000
~~~

购买少数股权属于权益性交易；须结合此前已扣减的权益及仍确认的少数股东权益编制合并调整，避免重复扣减，不能将以上负债分录当作全部合并抵销分录。

依据：[财政部金融负债与权益工具区分应用案例](https://kjs.mof.gov.cn/zt/kjzzss/srzzzq/jrgjzzyy/202209/P020220913413146445202.pdf)。案例支持三种报表的分类依据；本节60、950等金额为独立演算假设。

## 09｜九、复合金融工具：可转债分拆、费用与资本化

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

先判断转股权是否符合权益条件；不符合时不能直接套用“负债＋权益”分拆。符合条件的复合工具，先计量负债成分公允价值，再用总发行价款减负债成分得权益成分。

### 发行费用与实际利率

设费用前负债L、权益E、直接相关发行费用C：

```text
负债承担费用＝C×L/(L＋E)
权益承担费用＝C×E/(L＋E)
负债初始账面价值＝L－负债承担费用
权益净增加额＝E－权益承担费用
```

负债费用按实际利率法摊销；权益费用直接扣权益，不计当期财务费用。第28节专门区分“其他权益工具科目余额”与“权益净额”，本节不重复科目变形。

例：平价发行1,000万元、3年期、票息4%、每年末付息；同类无转股权债券市场利率8%，发行费用20万元，转股权符合权益条件。按例题取值：

| 项目 | 金额（万元） |
| --- | ---: |
| 负债公允价值：40×年金现值系数＋1,000×复利现值系数 | 896.92 |
| 权益成分：1,000－896.92 | 103.08 |
| 负债承担费用：20×896.92/1,000 | 17.94 |
| 权益承担费用：20－17.94 | 2.06 |
| 负债净额：896.92－17.94 | 878.98 |
| 权益净额：103.08－2.06 | 101.02 |

两者合计980万元，与净收款相等。若本例在其他权益工具中直接扣减权益费用，合并分录为：

```text
借：银行存款                              980.00
    应付债券——可转债（利息调整）          121.02
  贷：应付债券——可转债（面值）          1,000.00
      其他权益工具                        101.02
```

扣费用后实际利率r满足：878.98＝40/(1＋r)＋40/(1＋r)²＋1,040/(1＋r)³。按该已舍入净额求解r约8.7606%，首年利息约77.00万元；票面应付利息仍为40，利息调整摊销约37.00。不能继续把拆分时市场利率8%当作扣费用后的实际利率。

```text
借：财务费用                         77.00
  贷：应付利息                       40.00
      应付债券——可转债（利息调整）   37.00
```

题目若已给出含交易费用的实际利率，直接使用；题给近似系数或插值方法时应保持取整口径一致。

### 附持有人回售权：分成分判断

例：票息2%，持有人第2年可按本金及未付利息回售，第3年末可按每股10元将固定面值转为发行方普通股。

| 成分 | 判断 |
| --- | --- |
| 本金与利息 | 存在不可避免付现义务，形成负债成分 |
| 固定换固定转股权 | 可单独形成权益成分，不因同时有回售权而全部变负债 |
| 回售权 | 须按嵌入衍生工具规则判断是否与债务主合同紧密相关；仅写“本金＋利息”不足以普遍排除分拆，还须核对行权价与主合同摊余成本等条件 |

金融负债没有任意指定为FVOCI的通常分类。

### 可转债用于工程：负债资金与权益资金

只有负债成分产生借款费用。一般资本化起点和专门借款规则见第11章；本例保留复合工具特有的资金划分计算。

题设：2×20年初募集20,000万元，票息4%、3年期、每年末付息，无发行费用；同类普通债券市场利率6%，取年金系数2.6730、复利系数0.8396。2月1日付工程款2,000，4月1日必要购建活动开始；2×21年初再付10,000且全年符合资本化条件。两年资本化期间闲置收益分别270、160万元。**下列计算按工程支出优先占用负债资金、闲置收益按闲置资金比例分配的题设口径**：

| 项目 | 计算（万元） |
| --- | --- |
| 初始负债 | 800×2.6730＋20,000×0.8396＝18,930.4 |
| 初始权益 | 20,000－18,930.4＝1,069.6 |
| 2×20资本化 | 18,930.4×6%×9/12－270×(18,930.4－2,000)/18,000＝597.91 |
| 2×21年初负债账面价值 | 18,930.4×1.06－800＝19,266.224 |
| 2×21资本化 | 19,266.224×6%－160×(18,930.4－12,000)/8,000＝1,017.37 |

利息按负债账面价值算，闲置资金占比按实际未动用资金算，不能把利息调整摊销也当作新增筹资现金。资本化期内负债资金闲置收益冲在建工程，权益资金收益不冲借款费用。2×22年初全部转股后，该债券负债消失，不再产生其借款费用。

资金使用及收益归属须有事实依据，不能把本题分配比例作为所有可转债工程的固定公式。

依据：[金融工具列报准则第14、23—24条](https://www.mof.gov.cn/gkml/caizhengwengao/2017wg/wg201706/201708/P020170818533174427263.pdf)。

## 10｜十、金融资产分类：SPPI 中的正常利息与杠杆效应

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 看补偿性质，不看“利息”名称

SPPI要求合同现金流仅为本金及基于未偿本金的利息支付。按金融资产**计价货币**评估；基本借贷利息可补偿货币时间价值、信用及其他基本借贷风险（如流动性风险）、管理成本和利润。

| 条款 | 判断要点 |
| --- | --- |
| LPR＋100基点（即＋1个百分点） | 固定点差通常可补偿基本借贷风险成本，仍须检查其他合同条款 |
| 利息直接挂钩股票价值、商品或碳价格指数 | 引入非基本借贷风险，通常不符合SPPI |
| 另收债务人净利润5% | 参与经营成果，不是普通借贷利息 |
| 本息挂钩计价货币通胀指数 | 在无杠杆且本金受到保护等条件下，可与基本借贷安排一致；不能将所有指数挂钩一概视为正常利息 |
| 有抵押、担保或完全追索权 | 本身不使现金流不符合SPPI；也不能挽救已引入非借贷风险的条款 |
| 正常贷款基准改为LPR | 基准名称改变本身不决定分类，仍看调整后的经济实质 |

### 或有条款：先看变化前后，再看触发事项

根据解释第19号，先确认所有可能合同情景下、变动前后的现金流均与基本借贷安排一致，不以触发概率低为由跳过判断。再分两类：

| 触发事项 | 判断 |
| --- | --- |
| 直接对应基本借贷风险成本，且现金流变化方向一致 | 如信用评级下降、信用风险上升而利率上调，可符合SPPI |
| 不直接对应基本借贷风险成本 | 仅当所有可能情景下，与其他条款相同但不含该特征的工具相比，现金流不存在显著差异，才可符合SPPI |

例如利率3%，达到约定碳减排目标降为2.9%，属于目标触发的固定降息，并非直接挂钩碳价格指数。**不能仅凭相差0.1个百分点就自动判定通过**，须结合全部期限、金额及可能情景评估差异；结论显然时可定性判断，否则需定量评估。

相关或有条款还需按类别披露性质、现金流可能变动的定量范围及有关金融资产账面余额、金融负债摊余成本。该解释自2026年1月1日起施行，首次执行累积影响调整当年年初相关项目，不改前期比较数据。

### 加点与倍数

“LPR＋1个百分点”与“LPR×1.10”不同：LPR从4%升至5%，前者从5%升至6%，后者从4.4%升至5.5%，后者把基准变动从1个百分点放大到1.1个百分点。

倍数条款须评估是否引入不符合基本借贷安排的杠杆；若存在使现金流不具备SPPI特征的杠杆，不能分类为摊余成本或债务FVOCI。不能只凭利率高低作结论。

依据：[解释第19号第四项官方全文](https://czj.wuhan.gov.cn/kjfw/HJFWZQ/202512/t20251223_2699225.html)。

## 11｜十一、应收款项融资：分类与列报分开

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

“应收款项融资”是报表项目，不是第四类金融资产。它反映按FVOCI计量的应收票据、应收账款等；具体分类仍按第二节业务模式与SPPI规则判断。

| 应收款项的管理方式 | 一般处理 |
| --- | --- |
| 以收取合同现金流量为目标且通过SPPI | AC，通常列应收票据、应收账款等 |
| 以收款和出售为目标且通过SPPI | 债务工具FVOCI，按适用报表格式列应收款项融资等 |

银行承兑汇票可能持有到期，也可能贴现或背书，但不能仅因“可能转让”就认定FVOCI。应检查组合管理事实，以及转让是否满足金融资产终止确认；不满足终止确认的贴现融资不能直接当作分类判断中的出售。信用风险较低本身也不是FVOCI分类条件。

## 12｜十二、基金及合伙份额能否指定权益工具FVOCI

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

先排除适用长期股权投资等其他准则的投资，再按合同实质判断权益工具定义；不能只看“股份”“合伙份额”名称或普通／有限合伙人身份。

| 持有工具的性质 | 投资方判断 |
| --- | --- |
| 符合权益工具定义、非交易性 | 可在初始确认时不可撤销地指定为权益工具FVOCI |
| 可回售或固定寿命等特殊工具，发行方仅依列报准则第三章例外列权益 | 投资方不能据此指定为权益工具FVOCI |
| 不属于权益工具投资 | 再按金融资产分类规则判断；收益随净资产价值等变化、未通过SPPI时通常FVTPL |

例：600万元购买期限5年的有限合伙企业10%份额。应核对清算、退伙、赎回及收益条款：若属于发行方仅按特殊例外列权益的有限寿命份额，不能指定权益工具FVOCI；不能只凭“5年、有限合伙人”就跳过合同判断。

上述工具在发行方个表可能列权益，在集团合表对应少数股东部分须列金融负债，与投资方能否作权益工具投资是不同层次。FVOCI与FVTOCI都是常见英文缩写，不应把缩写写法当作分类错误。

## 13｜十三、嵌入衍生工具：识别与分拆

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

混合合同包含非衍生主合同和嵌入衍生工具，后者使部分或全部现金流量随利率、汇率、股票或商品价格、指数等变量变化。主合同可能为债务、租赁、保险、服务或特许权合同。

如果相关衍生工具可以独立转让，或交易对手不同，应作为独立工具考虑。仅有浮动条款不意味着一定分拆，还须判断衍生工具定义及下表条件。

| 判断步骤 | 结果 |
| --- | --- |
| 主合同属于金融资产准则范围内的金融资产 | 不分拆；整体按金融资产分类规则处理 |
| 主合同不属于上述金融资产 | 继续检查下列三项条件 |
| 嵌入部分与主合同经济特征和风险不紧密相关；相同条款的单独工具符合衍生工具定义；混合合同未整体按FVTPL计量 | 三项均满足才分拆；主合同按适用准则，衍生部分单独核算 |
| 需分拆但无法单独计量 | 按准则判断整个混合合同的FVTPL指定处理，不能任意忽略嵌入部分 |

例：债券利息挂钩股票指数、贷款收益挂钩黄金价格，须分析相应衍生特征；持有人面对金融资产主合同时整体分类，不能套用发行人的分拆结论。租金与一般通胀指数挂钩可能紧密相关，但须检查杠杆、指数与经济环境等条款，不能说所有指数挂钩都不用拆。

另签的利率互换通常为独立衍生工具；附回售权债券的紧密相关判断见第九节。

## 14｜十四、金融资产和金融负债的确认与终止确认

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 确认时点

| 业务 | 判断 |
| --- | --- |
| 属于金融工具准则范围的合同 | 成为合同一方时确认相应金融资产或金融负债 |
| 常规方式购买、出售金融资产 | 采用交易日会计，不等到交收日才确认或终止确认 |
| 普通商品、服务采购销售订单 | 仅签订单通常不确认应收应付；履约及权利义务条件满足时确认 |
| 远期、期权等衍生合同 | 成为合同一方时确认；初始公允价值为零的远期可无金额分录，后续按正负价值反映资产或负债 |

例如1月1日签普通原材料采购合同、3月1日收货，通常在收货时确认存货及应付账款。若属于金融工具准则范围的可净额结算商品合同，或适用确定承诺套期等规则，则不能机械等到收货。

销售已满足收入确认条件且收款权利无条件时（以下忽略税项）：

```text
借：应收账款
    贷：主营业务收入
```

收到商品或服务并形成应付义务时：

```text
借：存货／成本费用等
    贷：应付账款
```

购买、签出不属于发行方权益工具的普通期权，支付或收到期权费时分别为：

```text
借：衍生金融资产
    贷：银行存款
```

```text
借：银行存款
    贷：衍生金融负债
```

自身权益工具结算的分类另见第五节，不能把所有认股权证都视为衍生负债。

### 终止确认

- 金融资产：合同收款权利终止，或已转移并满足金融资产转移准则的终止确认条件；具体转移判断见第二十二节。
- 金融负债：现时义务解除；实质不同的新债替换旧债，或合同条款实质性修改时，终止确认旧债并确认新债。

负债条款修改的10%测试、定性判断及终止确认前后计量，见债务重组章“债务人修改债务条款时，10%测试、原实际利率与新实际利率分别何时使用？”；金融资产合同修改见第十五节。

### 电子支付提前终止确认

解释第19号自2026年1月1日起施行。企业通过电子支付系统以现金结算负债，已启动付款指令且同时满足下列条件时，可选择在结算日前终止确认：

1. 无实际能力撤回、停止或取消指令。
2. 无实际能力支取已用于该结算的现金。
3. 系统结算风险不重大；若指令执行仍取决于结算日企业能否交付现金，则不满足此条件。

该选择应一致适用于**同一电子支付系统的所有结算**。例：1月3日形成应付账款，10日启动付款并满足三条件，11日对方收到通知，12日实际划款；已选择该政策时，最早在10日终止确认。仅按下付款键或对方收到通知不够。

首次执行该规定的累积影响调整2026年1月1日留存收益及相关项目，无需调整前期比较数据。依据：[解释第19号官方转载全文](https://czj.wuhan.gov.cn/kjfw/HJFWZQ/202512/t20251223_2699225.html)。

## 15｜十五、会计计量-债权投资

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 初始计量与正常计息

债权投资按摊余成本计量，初始成本包括公允价值及直接相关交易费用；已到付息期但尚未领取的利息单列。债券面值记“成本”，差额记“利息调整”：

```text
借：债权投资——成本（面值）
借：应收利息（已到期未领利息）
借：债权投资——利息调整（溢价差额；折价时改记贷方）
    贷：银行存款（含交易费用）
```

| 金额 | 计算与科目 |
| --- | --- |
| 票面利息 | 面值×票面利率×期间；分期付息记应收利息，到期一次还本付息在到期前记应计利息 |
| 实际利息收入 | 按下表确定计息基础和利率，计入投资收益 |
| 利息调整摊销 | 实际利息与票面利息之差；通常折价为借方、溢价为贷方 |

```text
借：应收利息／债权投资——应计利息（票面利息）
借：债权投资——利息调整（折价摊销；溢价时改记贷方）
    贷：投资收益（实际利息收入）
```

### 信用减值对利息收入的影响

本节的**账面余额**指扣除损失准备前的实际利率法余额；**摊余成本＝账面余额−损失准备**。其他债权投资计息也适用下表，不能用其报表公允价值替代计息基础。

| 资产状态 | 利息收入 |
| --- | --- |
| 初始未减值，目前仍未发生信用减值（一般模型第一、二阶段） | 账面余额×原实际利率 |
| 初始未减值，后续已发生信用减值（第三阶段） | 后续期间按摊余成本×原实际利率 |
| 上一行资产后来不再信用减值，且改善可客观联系至后续发生的事件 | 恢复按账面余额×原实际利率计息 |
| 购入或源生时已发生信用减值（POCI） | 自初始确认起按摊余成本×经信用调整的实际利率，不因后来改善而改套普通三阶段计息 |

例如60万元购入面值100万元的严重违约债权，若折价反映信用损失，应判断POCI；普通折价购债不当然属于POCI。经信用调整的实际利率在估计现金流时已考虑初始预期信用损失。

信用风险改善时，按新估计调整损失准备；不把以前按净额计息的期间改算成总额并追补利息收入。减值阶段、准备金额及简化处理见第十九节。

### 合同现金流修改，但未终止确认

未终止确认的合同修改按原实际利率重算账面余额；POCI、套期利率例外及修改费用处理，统一见债务重组章“债权人修改其他条款”的终止确认对照卡。

例：原账面余额1,000、原实际利率5%，修改后现金流按该利率折现为920，损失80；若为1,030，则利得30。以下为两种独立情形：

```text
借：投资收益 80
    贷：债权投资——利息调整 80
```

```text
借：债权投资——利息调整 30
    贷：投资收益 30
```

### 减值与处置

```text
借：信用减值损失
    贷：债权投资减值准备
```

转回时作相反分录。不再合理预期全部或部分合同现金流能够收回时，直接减记相应账面余额，不能无限期只挂损失准备。

出售时结清成本、利息调整、应计利息等明细及对应损失准备，实收对价与净账面价值的差额计入投资收益；应收利息按实际结算范围一并结清。例如各资产明细均为借方余额、出售有收益时：

```text
借：银行存款
借：债权投资减值准备
    贷：债权投资——成本
    贷：债权投资——利息调整
    贷：债权投资——应计利息
    贷：投资收益
```

贷方利息调整余额应反向结清；处置损失记投资收益借方。

## 16｜十六、其他权益工具投资处置：递延所得税转回仍进其他综合收益

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 税项跟随原交易

指定为FVOCI的非交易性权益投资，公允价值变动及相关递延所得税计入其他综合收益（OCI）；处置差额与累计OCI转入留存收益，不转损益。原在OCI确认的递延所得税转回仍经OCI处理，不能将“累计OCI转留存”理解为税项直接转留存。

与权益交易相关的**当期所得税也计入权益**。递延所得税资产须满足很可能取得足够应纳税所得额等确认条件，不能看到可抵扣差异就自动确认。一般规则见所得税章。

### 220→200→190完整例

2X24年12月购入成本220，年末公允价值200；2X25年2月以190出售。假设计税基础一直为220，处置损失30当期可全额抵税，适用税率25%，满足递延所得税资产确认条件；留存收益按盈余公积10%、未分配利润90%分列。金额单位一致。

年末确认公允价值损失20、递延所得税资产5，OCI净减少15：

```text
借：其他综合收益 20
    贷：其他权益工具投资——公允价值变动 20
借：递延所得税资产 5
    贷：其他综合收益 5
```

处置差额10及原税前OCI损失20转入留存收益，转回递延所得税资产：

```text
借：银行存款 190
    盈余公积 1
    利润分配——未分配利润 9
    贷：其他权益工具投资 200

借：盈余公积 2
    利润分配——未分配利润 18
    贷：其他综合收益 20

借：其他综合收益 5
    贷：递延所得税资产 5
```

处置损失30带来的当期税额减少7.5，其中原OCI损失对应5，处置差额对应2.5；以下列示对当期应交所得税的调减部分，完整当期所得税仍须结合企业其他业务计算：

```text
借：应交税费——应交所得税 7.5
    贷：其他综合收益 5
        盈余公积 0.25
        利润分配——未分配利润 2.25
```

核对：OCI及递延所得税资产均结清；留存收益累计减少30−7.5=22.5（盈余公积2.25、未分配利润20.25）。若题目明确不考虑当期所得税，只做前述三组处置分录，其留存收益减少30是税前结果；不能冒充完整税后结果。

依据：[财政部《企业会计准则第18号——所得税》第13、21—22条](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/200806/t20080618_46230.htm)。

## 17｜十七、其他债权投资：摊余成本、减值和出售时 OCI 结转

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

其他债权投资属于债务工具FVOCI：资产负债表按公允价值列示；实际利息、减值及相关汇兑损益按准则计入当期损益，其余公允价值变动计入其他综合收益。计息基础沿用第十五节，不能把公允价值当作摊余成本；完整数值拆解见第二十六节。

### 持有期间：公允价值与减值分别入账

```text
借：其他综合收益——其他债权投资公允价值变动
    贷：其他债权投资——公允价值变动
```

上例表示公允价值下降，上升作相反分录。信用减值另记：

```text
借：信用减值损失
    贷：其他综合收益——信用减值准备
```

减值转回作相反分录。损失准备在其他综合收益中确认，不另扣资产负债表中的公允价值；但计算摊余成本时仍须扣损失准备。

### 出售：累计 OCI 转入损益

先结清资产明细，实收对价与账面价值差额计入投资收益。以下模板假设各资产明细均为借方余额且出售有收益：

```text
借：银行存款
    贷：其他债权投资——成本
    贷：其他债权投资——利息调整
    贷：其他债权投资——应计利息
    贷：其他债权投资——公允价值变动
    贷：投资收益
```

贷方明细余额反向结清，处置损失记投资收益借方。再将累计其他综合收益（包括相关信用减值准备）转入损益；累计贷方余额时：

```text
借：其他综合收益
    贷：投资收益
```

累计借方余额时反向；所得税影响另按所得税准则处理。

其他权益工具投资的处置及税项见第十六节，不套本节债务工具的损益结转。

## 18｜十八、指定 FVTPL 金融负债：自身信用风险变动进 OCI

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 适用范围与例外

| 金融负债 | 公允价值变动去向 |
| --- | --- |
| 一般交易性金融负债 | 通常全部计入当期损益 |
| 指定FVTPL的金融负债，一般情况 | 自身信用风险变动部分计入其他综合收益，其余计入当期损益 |
| 上述分拆会造成或扩大损益中的会计错配 | 全部计入当期损益，包括自身信用风险部分 |
| 指定FVTPL的财务担保合同、不可撤销贷款承诺 | 全部利得或损失计入当期损益 |

自身信用恶化可能使负债公允价值下降；一般情况下将该部分放入OCI，避免把信用恶化体现为当期收益。不能据此忽略表中的例外。

### 例：负债公允价值下降8

假设不属于上述例外，其中5由自身信用风险恶化导致、3由其他因素导致：

```text
借：指定为FVTPL的金融负债 8
    贷：其他综合收益 5
    贷：公允价值变动损益 3
```

公允价值上升时反向处理。实际核算按企业设置的对应金融负债科目及明细记录。

### 终止确认

自身信用风险形成的累计OCI不得重分类进损益；负债终止确认时转入留存收益。累计贷方余额时：

```text
借：其他综合收益
    贷：盈余公积
    贷：利润分配——未分配利润
```

累计借方余额时反向。留存收益内部的分配按适用核算要求确定。

依据：[金融工具确认和计量准则第六十八、七十条](https://kjs.mof.gov.cn/zhengcefabu/201704/P020170406398225042083.pdf)。

## 19｜十九、金融工具减值：三阶段模型、简化处理和利息收入口径

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 预期信用损失与一般三阶段模型

预期信用损失（ECL）反映合同应收与预期实收现金流短缺的概率加权现值，并考虑货币时间价值及合理、有依据的前瞻信息；不能用公允价值跌幅替代。**12个月ECL是未来12个月内可能违约所导致的整个存续期损失的一部分，不是只计未来12个月现金短缺。**

简化算例（不另考虑折现，单位元）：风险暴露1,000,000，12个月违约概率0.5%、违约损失率25%，ECL＝1,250；风险显著增加后，若整个存续期违约概率30%、损失率60%，ECL＝180,000。每期确认的是准备余额的变动，不能重复全额计提。

| 阶段（初始未发生信用减值） | 损失准备 |
| --- | --- |
| 一：信用风险自初始确认后未显著增加 | 12个月ECL |
| 二：信用风险显著增加，但未发生信用减值 | 整个存续期ECL |
| 三：已发生信用减值 | 整个存续期ECL |

各阶段及POCI的计息基础、利率和恢复总额计息条件见第十五节。POCI不套普通三阶段：按整个存续期ECL自初始确认后的累计变动确认损失准备，有利变动也应确认为减值利得。

### 简化处理适用范围

| 项目 | 是否始终按整个存续期ECL |
| --- | --- |
| 收入准则交易形成的应收款项、合同资产，无重大融资成分，或按准则不考虑一年以内合同融资成分 | 必须 |
| 上述交易形成且含重大融资成分的应收款项、合同资产 | 可作会计政策选择；对应收款项类、合同资产类可分别选择，同类一致适用 |
| 租赁应收款 | 可作会计政策选择；融资租赁与经营租赁应收款可分别选择，同类一致适用 |
| 其他应收款，如普通可退还保证金 | 不属于上述简化范围，按一般模型判断；进入第二、三阶段时同样要计整个存续期ECL |

票据是否适用简化处理，须看是否由收入准则交易形成及融资成分条件，不能只看科目名称。合同资产的减值方法适用ECL，常用分录为：

```text
借：资产减值损失
    贷：合同资产减值准备
```

债权投资减值分录见第十五节，其他债权投资减值分录见第十七节；两者准备的列报位置不同。

## 20｜二十、权益工具与金融负债之间重分类：差额怎么处理

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

本节讨论原工具因合同原定条件、事项变化而满足另一类别条件的重分类，包括特殊可回售工具等。**不能把重新谈判的债转股、以权益工具清偿债务等交易一律套成“负债按账面转权益”**；这些须先判断是否适用债务重组、合同修改或原转换条款等具体规定。

| 重分类方向 | 计量及差额 |
| --- | --- |
| 权益工具→金融负债 | 自不再满足权益分类条件之日起，负债按重分类日公允价值计量；与原权益账面价值的差额计入权益 |
| 金融负债→权益工具 | 自满足权益分类条件之日起，按重分类日负债账面价值转入权益，不确认重分类损益 |

### 分录模板

权益转负债（假设负债公允价值大于原权益账面价值）：

```text
借：其他权益工具（原账面价值）
借：资本公积等权益项目（差额）
    贷：金融负债（重分类日公允价值）
```

公允价值较小时，差额记权益贷方。具体权益科目按原工具及适用核算要求确定。

负债转权益：

```text
借：金融负债（重分类日账面价值）
    贷：其他权益工具等（相同金额）
```

附现金回购义务的增资及义务解除另见第七节：确认回购负债并扣减权益，不等于可以忽略其回购金额现值和后续计量规定。金融资产三类之间重分类见第二十一节，与本节对象不同。

## 21｜二十一、金融资产重分类：摊余成本、FVOCI、FVTPL 六类转换对照表

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 前提与日期

仅在管理金融资产的业务模式真实改变时，对受影响资产重分类。下表适用于可因业务模式变更而转换类别的债务工具；未通过SPPI的资产不能仅改业务模式便转为摊余成本或债务FVOCI。初始不可撤销的FVTPL指定、权益FVOCI指定，不适用这类自由转换。

重分类日为业务模式改变后的首个报告期间第一天，采用未来适用法，以前确认的损益、减值及利息不追溯。例：仅按自然年度报告、2×25年业务模式改变，重分类日为2×26年1月1日；有中期报告时须按实际报告期间判断，不能一律等次年。

### 六类转换

| 方向 | 重分类日计量 | 差额与后续基础 |
| --- | --- | --- |
| 摊余成本→FVTPL | 按公允价值 | 与原净账面价值差额进损益，通常公允价值变动损益 |
| 摊余成本→债务FVOCI | 按公允价值 | 与原净账面价值差额进OCI；实际利率及ECL计量不因重分类改变 |
| 债务FVOCI→摊余成本 | 累计OCI转出调整资产，视同一直按摊余成本计量 | 不进损益；实际利率及ECL计量不因重分类改变 |
| 债务FVOCI→FVTPL | 继续按公允价值 | 累计OCI转入当期损益，通常投资收益 |
| FVTPL→摊余成本 | 公允价值作为新账面余额 | 据此确定实际利率，重分类日视为初始确认日适用减值规定 |
| FVTPL→债务FVOCI | 继续按公允价值 | 同样据此确定实际利率并开始适用减值规定；以后公允价值变动按新类别处理 |

FVTPL转出不倒回以前的公允价值变动损益。

### 分录与准备位置

摊余成本转FVTPL（公允价值高于原净账面价值时）：

```text
借：交易性金融资产（公允价值）
借：债权投资减值准备
    贷：债权投资（账面余额）
    贷：公允价值变动损益（差额）
```

差额为损失时记借方。摊余成本与FVOCI互转，以账面余额100、准备2、净额98、公允价值105为演算例，忽略税项：

```text
借：其他债权投资 105
借：债权投资减值准备 2
    贷：债权投资 100
    贷：其他综合收益 7
```

OCI增加7中，公允价值调整5、信用减值准备2应按明细区分。反向转换假设仍为同组金额：

```text
借：债权投资 100
借：其他综合收益 7
    贷：其他债权投资 105
    贷：债权投资减值准备 2
```

转回后净额仍为98，不能只将98记入债权投资后遗漏准备的单独核算。

FVOCI转FVTPL，先按公允价值结转资产，再转出累计OCI；累计贷方余额时：

```text
借：交易性金融资产
    贷：其他债权投资

借：其他综合收益
    贷：投资收益
```

累计OCI为借方余额则反向结转。FVTPL转摊余成本或FVOCI，先按重分类日公允价值结转，再确认适用的损失准备：

```text
借：债权投资／其他债权投资
    贷：交易性金融资产

借：信用减值损失
    贷：债权投资减值准备／其他综合收益——信用减值准备
```

两个贷方按转入类别分别选用，不能同时计提。依据：[金融工具确认和计量准则第27—32条](https://kjs.mof.gov.cn/zhengcefabu/201704/P020170406398225042083.pdf)。负债类别之间不得进行该类重分类；负债与权益属性变化见第二十节。

## 22｜二十二、金融资产转移：终止确认、继续确认和继续涉入

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 判断顺序

先确定报表层面和整体/部分范围，再判断合同收款权是否终止；权利未终止的，判断是否发生转移，继而看风险报酬和控制。转入方属于受控主体时，合并报表须先纳入合并范围，再在集团层面判断，不能把集团内部出售当作对外终止确认。

| 环节 | 判断与结果 |
| --- | --- |
| 可单独判断的部分 | 特定可辨认现金流、全部现金流完全成比例部分、特定可辨认现金流完全成比例部分；其他情形看整体 |
| 收款权已终止 | 终止确认，如债务人清偿或期权未行权到期 |
| 收款权未终止且未发生合格转移 | 继续确认 |
| 已转移几乎所有风险报酬 | 终止确认；转移中产生或保留的独立权利义务另行确认 |
| 保留几乎所有风险报酬 | 继续确认原资产，收到对价确认为负债 |
| 既未转移也未保留几乎所有风险报酬 | 再看控制：未保留控制则终止确认；保留控制则按继续涉入程度确认资产及相关负债 |

只转债券利息、转全部现金流90%、转利息现金流90%，分别属于前三种部分范围。转让贷款组合“最先收到的90万元”不属于完全成比例部分，应对整体判断，不能仅凭金额明确就单独处理。

### 转移与过手安排

转移包括转让合同收款权；也包括保留收款权、承担向最终收款方转付义务且同时满足：

1. 仅收到对等现金流才须转付。**可全额收回并按市场利率收息的短期垫款**视同满足。
2. 合同禁止出售或抵押原资产，但可作为向最终收款方付款义务的保证。
3. 收款后及时转付、无重大延误。短暂结算期间投资于现金或现金等价物，且收益按合同一并交给最终收款方，视同满足；不是任意再投资。

风险报酬比较的是转移前后未来净现金流金额和时间分布的变动风险。仅在两端均不满足时才判断控制：转入方能否单方面将资产整体卖给无关联第三方且不附额外限制。**不打算出售不等于没有出售能力；没有活跃市场也不是自动保留控制的唯一标准。**

### 常见安排

| 安排 | 通常结果（须结合完整合同） |
| --- | --- |
| 无条件出售，或按回购时公允价值回购 | 转移几乎所有风险报酬，终止确认 |
| 回购原资产或实质相同资产，价格固定或原售价加回报 | 保留几乎所有风险报酬，继续确认 |
| 重大价内回售/回购期权 | 通常继续确认 |
| 重大价外回售/回购期权 | 通常终止确认 |
| 仅承担部分信用损失 | 仍须量化风险报酬，不能仅凭担保比例小于100%认定继续涉入 |

终止确认其他债权投资的资产结清与OCI转损益见第十七节；权益FVOCI的OCI不套此损益规则。若仅部分终止确认，应按保留与终止确认部分的相对公允价值分摊原账面价值，相关可重分类OCI也相应分摊。

### 继续确认：卖出回购

原资产继续核算；以下以银行业务科目示例：

```text
借：银行存款
    贷：卖出回购金融资产款

借：利息支出
    贷：卖出回购金融资产款

借：卖出回购金融资产款
    贷：银行存款
```

第二笔为实际利率法融资成本，第三笔为到期回购。相关资产与负债、资产收入与负债费用不抵销；也不应再单独确认会导致同一权利义务重复入账的衍生工具。

### 继续涉入：担保例

以下例题均**另假设已判断既未转移也未保留几乎所有风险报酬，且保留控制**。担保方式下：

- 继续涉入资产＝原资产账面价值与担保金额孰低。
- 相关负债＝担保金额＋担保合同公允价值。担保金额是所收对价中可能被要求偿还的最高金额；不能对所有安排都替换成“继续涉入资产＋担保公允价值”。

例一：应收款余额1,000、准备40、净额960；对余额30%以内信用损失担保，担保公允价值20。担保金额300，继续涉入资产300、负债320。

例二：贷款账面价值1,000万元，担保上限300，担保公允价值100，转入方无实际出售能力。假设**收到的全部对价合计990万元，未另收担保费**，资产300、负债400，转移损失110：

```text
借：存放中央银行款项 990
借：继续涉入资产 300
借：投资收益 110
    贷：贷款 1,000
    贷：继续涉入负债 400
```

若990仅为贷款售价且另收到担保费100，现金合计1,090，则不能沿用损失110；在其余假设相同时损失为10。原题对价范围必须明确。

后续担保初始公允价值随义务履行摊销入损益；继续确认资产仍按适用金融工具规则计量。继续涉入并非先把原资产全部终止确认后任意另造一对等额科目。

依据：[金融资产转移准则正式附件](https://m.mof.gov.cn/zcfb/201704/P020170406401655144830.pdf)。

## 23｜二十三、套期会计：尚未确认的确定承诺履约时怎么处理

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

确定承诺是具有法律约束力、约定未来按特定价格交换特定数量资源的协议。以下假设满足套期会计条件，并指定为**公允价值套期**：指定后因被套期风险产生的累计公允价值变动，确认为资产或负债并计入相关期间损益；履约时并入取得资产或承担负债的初始金额。

### 固定100万元采购原材料：两种独立情形

假设被套期风险为全部相关商品价格风险，忽略折现等其他因素；以下只列确定承诺一侧，套期工具另按规定确认。

| 履约时市场价 | 确定承诺累计变动 | 原材料初始金额 |
| --- | --- | ---: |
| 108万元 | 有利8，确认资产 | 100+8=108 |
| 92万元 | 不利8，确认负债 | 100−8=92 |

有利情形：

```text
借：被套期项目——确定承诺 8
    贷：套期损益 8

借：原材料 108
    贷：银行存款 100
    贷：被套期项目——确定承诺 8
```

不利情形：

```text
借：套期损益 8
    贷：被套期项目——确定承诺 8

借：原材料 92
借：被套期项目——确定承诺 8
    贷：银行存款 100
```

初始成本包含的是**已确认的被套期风险累计变动**，不能无条件推广为“履约一律按全部市场公允价值入账”。履约后原确定承诺消失，取得的原材料不自动延续该套期关系；若继续对存货指定套期，应重新满足指定及其他条件。

## 24｜二十四、现金流量套期：套期储备后续怎么转

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 先确认储备与无效部分

套期工具有效部分计入其他综合收益——套期储备，无效部分计入当期损益。累计储备以“套期工具累计利得或损失”与“被套期项目预计未来现金流现值累计变动”两者绝对额孰低确定；当期OCI确认储备的变动额，不能重复计入累计总额。

### 储备转出

| 后续事项 | 处理 |
| --- | --- |
| 预期交易形成非金融资产或非金融负债，或此类预期交易转为适用公允价值套期的确定承诺 | 转出储备，调整初始确认金额 |
| 其他现金流量套期 | 在被套期现金流影响损益的相同期间转入损益 |
| 储备为损失，预计全部或部分不能弥补 | 立即将预计不能弥补部分转入损益 |

采购原材料的储备为利得时，降低成本：

```text
借：其他综合收益——套期储备
    贷：原材料
```

储备为损失时反向。这里限定**非金融**项目，不能把所有资产负债都按此处理。

预期销售影响收入时，有效利得可转入对应收入项目（以下不含风险净敞口跨损益项目的特殊列报情形）：

```text
借：银行存款
    贷：主营业务收入

借：其他综合收益——套期储备
    贷：主营业务收入
```

浮动利率借款套期则在相关利息影响损益期间调整财务费用等。若累计储备损失10、预计只能弥补6，立即转损益4：

```text
借：套期损益 4
    贷：其他综合收益——套期储备 4
```

### 终止套期会计不等于立即转出储备

| 未来现金流判断 | 累计储备 |
| --- | --- |
| 预期仍会发生 | 保留，后续按上表处理；不能弥补的损失仍须及时转出 |
| 不再极可能，但预期仍会发生 | 停止套期会计，储备按上一行处理 |
| 预期不再发生 | 立即转入当期损益 |

## 25｜二十五、已确认资产负债：怎么区分公允价值套期和现金流量套期

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 按指定风险分类

| 被套期项目及风险 | 通常适用类型 |
| --- | --- |
| 固定利率债权、借款或债券的利率公允价值风险 | 公允价值套期：现金流固定，市场利率改变其现值 |
| 浮动利率债权或债务的未来利息风险 | 现金流量套期：未来利息收付随利率变动 |
| 已持有存货的商品价格风险 | 公允价值套期 |
| 已确认外币应收应付款的汇率风险 | 根据指定风险与套期关系判断，见第二十九节 |

上述是风险识别，不能仅凭交易名称自动适用套期会计：还须有合格工具和项目、开始时的正式指定与书面文件，以及符合准则的有效性关系。固定/浮动利率的速判只针对利率风险，不替代外汇等其他风险判断。

### 公允价值套期的确认边界

一般情况下，套期工具和被套期风险产生的利得损失均计入当期损益；对未按公允价值计量的已确认被套期项目，调整相应账面价值。

- 债务工具FVOCI已按公允价值列示，不再叠加同一套期账面调整；被套期风险利得损失计入损益。
- 指定FVOCI的非交易性权益投资作为被套期项目时，套期工具及被套期风险利得损失均计入OCI，不能套“两边进损益”。
- 尚未确认确定承诺的处理见第二十三节。现金流量套期储备见第二十四节。

### 铜存货例：只调整指定后被套期风险变动

套期开始日存货账面价值500万元、公允价值550万元。假设指定后被套期风险使存货价值下降20万元，套期工具相应利得20万元，无其他影响：

```text
借：套期损益 20
    贷：被套期项目——存货 20

借：套期工具 20
    贷：套期损益 20
```

调整后的账面价值为500−20=480万元，两笔损益净额为零。不能先将存货从500调到550再减20，也不能因本例完全抵销而认为所有套期都没有无效部分。

## 26｜二十六、其他债权投资：减值后账面价值、摊余成本和利息基础三套口径

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

本节用一题区分金额；计量规则见第十七节，阶段判断见第十九节。

企业2×25年初以2,082.03万元购入面值2,000万元、票面利率8%、实际利率7%的其他债权投资。年内未发生信用减值，年末收到票面利息160万元；年末公允价值2,100万元，损失准备35万元，初始无损失准备。金额保留两位小数：

| 计算项目 | 金额（万元） |
| --- | ---: |
| 本年利息收入 | 2,082.03×7%=145.74 |
| 期末账面余额（未扣准备的实际利率法余额） | 2,082.03+145.74−160=2,067.77 |
| 期末摊余成本 | 2,067.77−35=2,032.77 |
| 资产负债表账面价值 | 公允价值2,100 |
| 公允价值调整 | 2,100−2,067.77=32.23 |

```text
借：应收利息 160
    贷：投资收益 145.74
    贷：其他债权投资——利息调整 14.26

借：银行存款 160
    贷：应收利息 160

借：其他债权投资——公允价值变动 32.23
    贷：其他综合收益——其他债权投资公允价值变动 32.23

借：信用减值损失 35
    贷：其他综合收益——信用减值准备 35
```

忽略税项，本年损益净增加145.74−35=110.74万元，其他综合收益增加32.23+35=67.23万元。不能把35万元再次从2,100万元报表价值中扣除。

下一期计息另分两种独立假设：若年末仍为第一或第二阶段，按2,067.77×7%=144.74万元；若年末已进入第三阶段，则后续期间按2,032.77×7%=142.29万元。不能仅凭“已计提35万元准备”认定发生信用减值。

## 27｜二十七、分类为金融负债还是权益工具：利息和股利怎么处理

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

本节采用**发行方**视角。工具名称不决定分配的会计性质；永续债、优先股等先按第五、六节判断负债或权益分类。

| 发行方分类 | “利息”或股利的性质 | 核算 |
| --- | --- | --- |
| 金融负债 | 融资成本 | 通常计入损益；符合借款费用资本化条件的计入相关资产成本 |
| 权益工具 | 对持有人的权益分配 | 确认为利润分配，减少权益，不列财务费用 |

### 普通摊余成本负债

利息费用按实际利率法确定，不一定等于票面利息。下面以折价、分期付息债券为例；溢价摊销的利息调整记借方：

```text
借：财务费用／在建工程等（实际利息费用）
    贷：应付利息（票面利息）
    贷：应付债券——利息调整（折价摊销）
```

资本化起止、暂停和金额计算见第十一章。FVTPL负债的公允价值变动另按其类别处理，不能对所有负债机械套用摊余成本分录。

### 权益工具分配

对满足权益分类条件的永续债或优先股，确认分配及支付时：

```text
借：利润分配——应付优先股股利／应付永续债利息等
    贷：应付股利

借：应付股利
    贷：银行存款
```

合同称作“利息”也不改变上述会计处理。税法是否允许扣除及所得税影响另行判断，不能因税前可扣除而改记财务费用；相关税项归属见所得税章。

## 28｜二十八、可转债：权益科目余额与权益净额

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

发行费用的分摊和实际利率统一见第九节。本节只区分**费用前拆分金额、具体科目余额、扣费后权益净额**。

例：发行8,000万元，负债公允价值7,346.11、权益成分653.89，发行费100万元。负债分摊91.83，权益分摊8.17，负债净额7,254.28，权益净额645.72。

如果题目明确采用“权益费用借记资本公积”的科目口径：

```text
借：银行存款                             7,900.00
    应付债券——可转债（利息调整）           745.72
    资本公积                                 8.17
  贷：应付债券——可转债（面值）           8,000.00
      其他权益工具                         653.89
```

此时其他权益工具余额653.89，权益净增加额仍为653.89－8.17＝645.72。若相关权益费用直接在其他权益工具中扣减，则该科目净额为645.72，权益合计不变。**准则规定从权益扣减，并不能据此断言所有题目的“其他权益工具余额”都必须不扣发行费。** 做具体余额题时需核对给定核算资料，不能用不明来源的题库惯例替代准则。

假设本例为3年期，每年末票息160万元、到期还本8,000万元，按初始负债7,254.28精确求解实际利率约5.4520%，首年利息约395.50万元。若题目给定实际利率5.46%，首年利息按题设为396.08万元。

## 29｜二十九、外汇风险套期：为什么既可能是公允价值套期，也可能是现金流量套期

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

外汇风险按**被指定的风险敞口**分类；套期会计适用条件及一般分类见第二十五节。

| 场景 | 指定风险及处理方向 |
| --- | --- |
| 已确认美元债券 | 指定其汇率导致的价值风险时为公允价值套期；指定未来美元本金、利息折合本币的现金流风险时为现金流量套期 |
| 外币应收应付款 | 根据指定的公允价值或现金流风险确定，不能仅凭“已入账”定类型 |
| 极可能发生的未来外币采购、销售 | 未来现金流风险，现金流量套期 |
| 已签有法律约束力的合同，3个月后以美元购买设备 | 尚未确认的确定承诺，其外汇风险可选择两类套期之一 |

设备采购若采用公允价值套期，按第二十三节确认确定承诺调整；采用现金流量套期，按第二十四节处理套期储备。两者不是可在期末随意切换的分录方案，应依开始时的指定及后续准则条件处理。

指定文件应明确项目、风险、金额或现金流部分及期间。同一美元债券的不同风险或现金流部分须分别识别，不得将同一笔利息的同一汇率风险重复指定、重复确认。

## 30｜三十、保险合同准则适用范围：两类主线和四类特殊合同

**难度**：章节笔记　·　**更新**：2026-09-07

### 完整笔记

### 保险与再保险

保险合同以承担保单持有人转移的**重大保险风险**为前提：约定的不确定未来保险事项对其产生不利影响时，签发人给予赔偿。保险风险不包括金融风险；寿险身故赔付、车险事故赔付、财产险火灾赔付均是常见例子。

保险合同准则适用于企业签发的保险合同（含分入再保险）、分出的再保险，以及通过合同转让或非同一控制下企业合并取得的上述合同。按单项合同判断保险风险是否重大；合同开始日已符合保险合同定义的，后续不再重新评估。

再保险是对原保险合同引起的赔付等进行补偿。例如甲保险公司承保客户财产险，再向乙公司分保：**乙是再保险签发人，甲是再保险持有人**。

### 四类特殊合同

| 合同 | 识别及例子 | 适用准则与选择单位 |
| --- | --- | --- |
| 财务担保合同 | 特定债务人未按债务工具条款偿付时，签发人向持有人赔付以补偿损失。甲为乙向银行借款担保：甲是签发人，银行是持有人，乙是债务人 | 原则上适用金融工具相关准则；企业**明确将其视为保险合同，且已按保险合同相关准则处理**的，才按单项合同选择保险合同准则或金融工具相关准则；选择不可撤销 |
| 符合保险合同定义、主要以固定收费提供服务的合同 | 如收固定年费提供不限次数道路救援；服务商是签发人，车主是持有人 | 同时满足下列三条件，可按单项合同选择收入准则或保险合同准则；选择不可撤销 |
| 符合保险合同定义、赔偿仅限于清算持有人因该合同产生的支付义务的合同 | 如贷款约定借款人死亡后豁免剩余本息；银行是签发人，借款人是持有人 | 按**保险合同组合**选择金融工具相关准则或保险合同准则；选择不可撤销 |
| 具有相机参与分红特征的投资合同 | 不转移重大保险风险，属于金融工具；投资者有权收取保证金额及附加金额，后者由签发人基于特定项目回报相机决定，且预计构成合同利益的重要部分 | **签发保险合同的企业**同时签发此类投资合同，适用保险合同准则；不签发保险合同的企业签发此类合同，适用金融工具相关准则。判断实际签发业务，不能只看是否名为“保险公司” |

固定收费服务合同的三项条件须同时成立：

1. 定价不反映对单个保单持有人的风险评估。
2. 通过提供服务而非支付现金补偿。
3. 保险风险主要源于持有人对服务的使用，而非服务成本的不确定性。

不满足三条件，只是不能据此选择收入准则；如果仍符合保险合同定义且无其他范围排除，适用保险合同准则。

相机参与分红投资合同例如“最低保证收益＋由签发人根据指定投资组合回报相机决定的重要额外分红”。适用保险合同准则时，在**成为合同一方之日**初始确认，合同服务边际按投资服务提供模式在合同组期限内摊销。

### 混合合同先分拆

保险合同中，符合金融工具准则分拆条件的嵌入衍生工具、可明确区分的投资成分，分拆后适用金融工具相关准则；其中符合相机参与分红投资合同定义的投资成分仍适用保险合同准则。可明确区分的商品或非保险服务承诺适用收入准则；剩余部分适用保险合同准则。

投资成分是**无论保险事项是否发生均须偿还**给保单持有人的金额，不能把任何预期赔款都当成投资成分。嵌入衍生工具的一般分拆判断见本章第十三节。
