## 01｜收入确认五步法和取得控制权怎么记？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：收入按合同、履约义务、交易价格、分摊、确认五步处理，核心是客户取得控制权。

### 一、收入确认五步法总览

**识别客户合同 → 识别单项履约义务 → 确定交易价格 → 分摊交易价格 → 履行履约义务时确认收入。** 具体条件分别见后续专题。

控制权是客户能够主导商品使用并从中获得几乎全部经济利益的现时能力，也包括能够阻止其他方主导使用并获益。关注的是现在的能力，不是未来可能取得的权利；经济利益可以体现为现金流入、成本节约等。

企业履行履约义务的实质是向客户转移商品或服务控制权。收入可在一段时间内或一个时点确认，取决于控制权转移模式。发货、开票或收款本身不等于履约完成；尚需转让商品的预收款通常先确认为合同负债，相关税额另行核算。

## 02｜合同资产转为应收账款，是否就决定了外币折算方法？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：收款权是否无条件决定合同资产或应收账款列报；外币货币性另按固定或可确定金额收取的定义判断，不能仅看科目。

### 核心结论

- 合同资产：已转让商品或服务，但收款还取决于时间流逝之外的条件；应收账款：只需等待付款日。
- 外币折算另按准则19第11条判断：将以固定或可确定金额货币收取的资产属于货币性项目；不能仅因权利附有履约条件就断定非货币性。

### 判断与例题

- 设计完成后须安装才可收款：设计部分先列合同资产，安装条件满足再转应收账款；还须另查对价是否以固定或可确定外币金额结算。
- 按上述定义，若该项已确认对价权利满足固定或可确定外币金额收取的条件，应按货币性项目折算，无须等改列应收账款才开始调汇；若不满足，则按其实际性质与计量基础处理。此判断来自准则定义，不是对所有合同资产统一定性。
- 货币性项目期末按即期汇率折算，汇兑差额通常计当期损益；历史成本非货币性项目按交易日汇率，公允价值非货币性项目按公允价值确定日汇率。具体折算规则集中见外币折算章。

### 易错提醒

- 合同资产的预期信用损失计量不替代货币性分类判断；转应收时不能机械照抄未按适用准则更新的旧人民币金额。

### 关键分录

#### 履约但收款权尚附其他条件：确认合同资产

- **适用范围**：合同资产与应收账款
- **条件**：已转让商品或服务，但还须完成后续安装等条件才有权收款


> **提示**：先按收入准则确认和列报，再依据结算条款及外币准则确定折算；不预设合同资产均不调汇。

| 方向 | 科目 | 金额 |
| --- | --- | --- |
| 借 | 合同资产 | 按已履约部分的交易价格 |
| 贷 | 主营业务收入 | 按已履约部分的交易价格 |

#### 收款权利无条件时：合同资产转为应收账款

- **适用范围**：合同资产与应收账款
- **条件**：除时间流逝外不再需要满足其他条件


> **提示**：转出金额应为按适用准则更新后的账面余额；相关减值准备另作相应处理，不能遗漏汇率变动应有影响。

## 03｜合同成立五个条件如何快速记忆？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：收入合同须满足批准承诺、权利、付款条款、商业实质及可收回性五条件；不满足时另判已收款。

### 二、合同成立五条件的快速理解

适用收入准则正常确认模式，合同须同时满足以下五项；这是会计处理条件，不等同于合同法律效力判断。

| 条件 | 判断重点 |
| --- | --- |
| 各方批准并承诺履约 | 有可执行的权利义务；合同可采用书面、口头或其他形式 |
| 商品相关权利明确 | 明确各方与拟转让商品或服务有关的权利 |
| 支付条款明确 | 对价如何确定、结算及支付 |
| 有商业实质 | 将改变未来现金流的风险、时间分布或金额 |
| 有权取得的对价很可能收回 | 结合客户到期支付能力与意图评估，不要求已收款 |

付款条款清楚不代表客户有能力付款；“很可能收回”也不是把全部合同标价机械当成收款基础。

合同开始日符合条件的，除有迹象表明相关事实和情况发生重大变化外，无需重新评估；开始日不符合的，持续评估。仍不符合时，已收款先列负债，只有**不再负有转让商品的剩余义务，且已收对价无需退回**，才能确认该已收对价为收入。

依据：[财政部《企业会计准则第14号——收入》第4—6条](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694006.htm)。

## 04｜单项履约义务成立的两个条件怎么理解？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：先判断能否单独受益及合同承诺能否区分，再检查系列规则；质量保证按是否提供额外服务等分类。

### 三、单项履约义务成立的两个条件

### 可明确区分：同时满足两条件

| 条件 | 判断重点 |
| --- | --- |
| 客户能单独受益 | 商品本身可使用、出售、消耗，或能与客户已有、市场上易于取得的资源一起使用并受益 |
| 合同中的承诺可单独区分 | 企业承诺分别转让商品或服务，而非将各部分整合成交付成果；商品本身有用，不代表合同中的承诺也能分开 |

重大整合服务、重大修改或定制、商品高度关联，**通常表明**承诺不可单独区分，应结合合同实质判断。

- 普通设备、标准软件、原材料、维修服务通常能满足单独受益条件，但仍须检查合同承诺。
- 设备＋普通安装：若客户能从设备结合易于获得的安装资源受益，且安装不涉及重大整合、修改等，通常可以区分。
- 设计＋施工＋调试一条高度定制生产线：若承诺实质是整合后的生产线，相关投入通常合为一项履约义务。

履约义务还包括公开政策、声明或惯例使客户在订约时合理预期的承诺；仅为履约进行的内部准备活动，未向客户转让商品或服务的，通常不构成履约义务。

**系列规则：**一系列实质相同、转让模式相同的可明确区分商品或服务，也作为一项履约义务。转让模式相同要求每项均满足时段履约条件，并采用相同方法确定履约进度。

### 质量保证

| 情形 | 处理 |
| --- | --- |
| 客户可选择单独购买质量保证 | 作为单项履约义务 |
| 不可单独购买，且仅保证商品符合既定标准 | 按或有事项准则处理 |
| 在保证合格之外提供额外服务 | 额外服务作为单项履约义务；综合法定要求、保证期限、履行任务性质判断 |
| 保证类与服务类并存且无法合理区分 | 两类质量保证合为一项履约义务，按收入准则处理 |

分摊给服务类或上述合并质量保证的交易价格随履约确认收入；商品交付时，若对应价款已收或已到期应收而保证服务尚未履行，未履约部分列合同负债。

**标签**：`收入准则` · `Markdown同步` · `单项履约义务` · `可明确区分` · `质量保证`

## 05｜合同合并和单项履约义务合并有什么区别？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：合同合并确定合同范围，履约义务识别确定核算单元；满足合并条件不代表所有承诺成为一项义务。

### 四、合同合并与单项履约义务合并的区别

**先确定合同范围，再识别其中的履约义务。**多份合同合并后，仍可包含多项履约义务。

| 层面 | 解决的问题 | 判断依据 |
| --- | --- | --- |
| 合同合并 | 多份合同是否作为一份合同处理 | 下列合同合并条件 |
| 履约义务识别 | 合同中哪些商品或服务应分别核算 | 上节的可明确区分条件及系列规则 |

### 合同合并条件

前提：与**同一客户或该客户的关联方**同时或在相近时间订立两份或多份合同。在此前提下，满足任一项即应合并：

1. 基于同一商业目的订立，且构成一揽子交易。
2. 一份合同的对价金额取决于其他合同的定价或履行情况。
3. 各合同承诺的商品，或每份合同中的部分商品，共同构成一项履约义务。

仅客户相同、签约时间相近，不足以要求合并。

### 电脑与维护服务例

企业与同一客户同时签订销售100台标准电脑和提供3年维护服务的合同；假设两份合同基于同一商业目的构成一揽子交易、价格相互依赖，应合并处理。

合并后，若电脑交付与维护服务可明确区分，应分别识别履约义务；这里的维护是额外服务，不是仅保证电脑符合既定标准。至于一系列维护服务是否合为一项，按上节系列规则判断。

## 06｜某一时段履约的三个条件如何记？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：满足即时消耗、控制在建商品、无替代用途且全程有权收款之一，按时段履约；进度不能合理确定另行处理。

### 五、某一时段内履行履约义务的三个条件

满足下表**任一项**即为时段履约；均不满足才是时点履约。

| 条件 | 例子与边界 |
| --- | --- |
| 客户在企业履约的同时取得并消耗经济利益 | 日常保洁、安保。更换企业后，无须重做已完成工作，是辅助判断线索 |
| 客户控制履约过程中在建的商品 | 在客户土地上建办公楼，若客户确实控制在建工程，满足此项；不能仅凭土地归属自动判断 |
| 商品无替代用途，且整个合同期间均有权就累计已完成部分收款 | 两条件必须同时满足：合同或实际可行性限制使企业不能轻易改作他用；因客户或其他方原因终止合同，企业有具有法律约束力的权利收取已发生成本和合理利润 |

**定制设备例：**设备按客户特殊规格制造，转售需重大改造；合同约定因客户取消而终止时，应支付累计已完成部分的成本及合理利润，且该权利可依法执行。若这两项条件在上述要求下成立，即使客户尚未控制在建设备，也属于时段履约。仅“定制”、有预付款或约定进度付款，不能代替完整判断。

### 时段收入的计量

- 按商品性质选用恰当的产出法或投入法确定履约进度；类似情况下的类似履约义务采用相同方法。
- 进度不能合理确定、已发生成本预计可获补偿时，暂按已发生成本金额确认收入，直至进度能合理确定。
- 收入进度不等于所有成本都乘同一比例；已履约耗用成本与为未来履约形成的资源，应按合同成本规则区分。

## 07｜某一时点履约的控制权转移迹象怎么记？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：时点收入以控制权转移为准，综合现时收款权、所有权、实物占有、风险报酬和客户接受等迹象。

### 六、某一时点履行履约义务的控制权转移迹象

不满足时段履约条件的，在客户取得控制权的时点确认收入。综合考虑以下迹象及其他证据，既不要求五项全部满足，也不能仅凭其中一项机械认定。

| 速记 | 控制权转移迹象 |
| --- | --- |
| 钱 | 企业有现时收款权，客户负有现时付款义务 |
| 权 | 客户已取得法定所有权 |
| 物 | 客户已实物占有商品 |
| 险 | 商品所有权上的主要风险和报酬已转移给客户 |
| 收 | 客户已接受商品 |

**判断边界：**交付、验收、主要风险报酬转移及现时收款权等相互印证，通常支持控制权已转移。寄售中受托方仅占有商品，不当然取得控制权；开票或预收款也不能替代控制权判断。

客户验收须看实质：若企业能够客观确定已符合约定规格，形式性验收通常不推迟控制权转移；若无法客观确定是否达标，在客户验收前通常不能认定已取得控制权。

## 08｜可变对价限制和知识产权提成专门规则怎么区分？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：普通可变对价先估计并限制，逐期重估；知识产权销售或使用提成按实际发生与相关履约孰晚确认。

### 七、确定交易价格：可变对价限制与知识产权提成的专门规则

| 情形 | 处理 |
| --- | --- |
| 普通可变对价，如奖励、罚款、折扣、返利、退款或价格折让 | 用期望值或最可能发生金额估计；包含可变对价的交易价格，不得超过不确定性消除时累计已确认收入**极可能不会发生重大转回**的金额，同时考虑转回可能性与比重；每个资产负债表日重新估计 |
| 授予知识产权许可，约定按客户实际销售或使用收取提成 | 不提前预计未来提成确认收入；在客户实际销售或使用发生、企业履行相关履约义务两者孰晚时确认 |

**奖金例：**固定价款100万元，另有绩效奖金20万元。即使预计能取得奖金，也须通过可变对价限制，不能直接将全部120万元作为交易价格；金额计入交易价格后，还须按分摊和履约规则确认收入。

固定授权费与销售提成的组合例及分录见第17节。

## 09｜重大融资成分怎么判断和做分录？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：重大融资成分按现销金额确定交易价格，差额按实际利率摊销；一年简化与非融资原因须满足各自条件。

### 八、确定交易价格：重大融资成分的判断

存在重大融资成分时，交易价格按客户取得控制权时的现销金额确定；与合同对价的差额按实际利率法摊销。客户晚付款可能由企业提供融资，客户早付款可能向企业提供融资；**有时间差不等于有重大融资成分**。

| 情形 | 判断条件 |
| --- | --- |
| 一年以内的简化 | 合同开始日预计控制权转移与付款间隔不超过一年，可不考虑重大融资成分；超过一年仍须判断实质 |
| 客户自主决定使用时间 | 客户预付并可自行决定转让时间，如自主消费的储值卡、会员余额等；不能仅凭“预收款”或“积分”名称认定 |
| 大部分对价可变 | 金额或付款时间取决于未来事项，且该事项实质上不受任何一方控制；销售/使用提成、业绩奖金须结合此条件判断，不能将所有未来事项一概排除 |
| 融资以外的差额 | 如为保障履约安排的预付款、尾款或质保金，差额须与该原因相称；并非所有保护性条款均自动排除融资 |
| 审批导致的延迟 | 新能源补贴收款例：须有证据表明延迟主要来自审批所需必要时间、性质不是融资；不能推成“涉及审批就无融资” |

### 分录：统一采用名义应收款与未实现融资收益列示

以下不考虑税额，利息支出假设不符合资本化条件；只有已确认相应合同资产、应收款项或合同负债，才确认相关利息。

企业先交货、客户两年后付款：

```text
借：长期应收款                  合同收款总额
    贷：主营业务收入              现销价格
        未实现融资收益            差额

借：未实现融资收益              当期实际利息
    贷：财务费用等                当期实际利息
```

客户先付款、企业两年后交货：

```text
借：银行存款                    预收款
    贷：合同负债                  预收款

借：财务费用等                  当期实际利息
    贷：合同负债                  当期实际利息
```

上述“财务费用等”按企业适用科目核算；企业完成相应履约时，再将合同负债转为收入。名义应收款法与净额应收款法的后续分录不能混用。

## 10｜非现金对价如何确定交易价格？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：非现金对价通常按合同开始日公允价值计量；后续区分对价形式本身变化与履约等其他原因。

### 九、确定交易价格：非现金对价

客户以实物、无形资产、股权或广告服务等支付时，通常按**合同开始日非现金对价的公允价值**确定交易价格；无法合理估计该公允价值时，参照企业承诺转让商品或服务的单独售价间接确定。

| 后续变动原因 | 对交易价格的影响 |
| --- | --- |
| 对价形式本身变化，如固定数量股票的市场价格涨跌 | 不调整交易价格；相关资产或权利按适用准则另行计量，不能无条件说成已经持有股票的损益 |
| 对价形式以外的原因，如履约指标影响可取得的股票数量 | 按可变对价处理，并适用金额限制 |

**固定股票例：**客户用10万股支付，合同开始日每股10元，交易价格100万元；此后涨至12元，仅因股价上涨不把收入改成120万元。

**数量可变例：**最多支付10万股，实际数量取决于提前完工或业绩达标情况，应估计并限制可计入交易价格的金额。不要混淆“每股价格变了”和“履约影响能取得多少股”。

## 11｜应付客户对价如何处理？

**难度**：高频提高　·　**更新**：2026-09-07

> **速览**：应付客户对价先判断是否取得可区分商品；应冲减部分在相关收入与支付或承诺支付孰晚时点扣减。

### 十、确定交易价格：应付客户对价的处理

应付客户对价包括向客户、或向客户购买本企业商品的第三方支付的款项。先判断是否换取可明确区分的商品或服务，不能仅按“广告费、进场费、补贴”的名称定科目。

| 取得的商品或服务 | 处理 |
| --- | --- |
| 可明确区分，公允价值能合理估计，支付金额不超过公允价值 | 按与其他采购一致的方法核算 |
| 可明确区分，公允价值能合理估计，但支付金额超过公允价值 | 公允价值内按采购处理，超过部分冲减交易价格 |
| 不可明确区分，或公允价值不能合理估计 | 全额冲减交易价格 |

**冲减收入时点：确认相关收入与支付（或承诺支付）客户对价两者孰晚。**如先承诺后销售，在确认销售收入时扣减；如收入已确认后才支付或承诺支付，则调整当期收入。

### 超市例：销售价款100万元，另支付5万元

假设忽略增值税，销售已满足收入确认条件；广告服务在当期已提供、应计入销售费用。三种情形独立比较：

| 客户提供的服务 | 收入 | 销售费用 | 判断 |
| --- | --- | --- | --- |
| 可区分广告服务，公允价值5 | 100 | 5 | 5全部是采购服务 |
| 可区分广告服务，公允价值3 | 98 | 3 | 多付的2冲减收入 |
| 仅同意采购，没有可区分服务；或服务公允价值不能合理估计 | 95 | 0 | 5全额冲减交易价格 |

第一种情形：

```text
借：应收账款                    100
    贷：主营业务收入              100
借：销售费用                      5
    贷：银行存款 / 应付账款          5
```

第二种情形，假设原100收入已确认且现已到冲减时点：

```text
借：销售费用                      3
    主营业务收入                  2
    贷：银行存款 / 应付账款          5
```

第三种情形，假设销售前已承诺另付5，销售时尚未支付、与100货款分别结算：

```text
借：应收账款                    100
    贷：主营业务收入               95
        其他应付款——应付客户对价    5

借：其他应付款——应付客户对价      5
    贷：银行存款                    5
```

“应付客户对价”在本例为其他应付款明细，具体科目随款项性质确定，不是统一的独立总账科目。

## 12｜交易价格分摊后续变动如何处理？

**难度**：高频综合　·　**更新**：2026-09-07

> **速览**：分摊以合同开始日单独售价为基础，区分折扣、可变对价归属及合同变更后二次分摊；已履约变动调整当期收入。

### 十一、交易价格分摊：后续变动与可变对价归属

### 分摊基础

| 事项 | 规则 |
| --- | --- |
| 一般分摊 | 合同开始日按各单项履约义务的单独售价相对比例分摊；后续单独售价改变，不重算原比例 |
| 单独售价不能直接观察 | 优先利用可观察信息，合理采用市场调整法、成本加成法等；余值法适用于近期售价波动巨大，或未定价且未曾单独销售导致售价无法可靠确定的情况 |
| 合同折扣 | 原则上按比例分摊；有确凿证据仅与部分义务相关的，分给相关义务。如又需用余值法，先分配该折扣，再估计余值 |
| 可变对价及后续变动 | 可分给相关一项或多项义务，或一项系列履约义务中的部分商品；须与其履约等具体相关且符合分摊目标，否则按一般原则分摊 |
| 已履约部分分到后续变动额 | 调整变动当期收入，不追溯改以前期间；合同变更后的特殊情况见下表 |

**安装奖金例：**设备单独售价100万元、安装10万元，提前安装奖励5万元。假设设备和安装可明确区分，奖金已符合可变对价限制，且全部分给安装符合分摊目标，可仅分给安装；不能只因奖励名义与安装有关就跳过条件。

**比例例：**A、B单独售价100、300，比例25%、75%；交易价格后续增加40，若适用一般规则，仍分给A 10、B 30。

### 合同变更之后的可变对价后续变动

| 变更处理 | 后续变动分给谁 |
| --- | --- |
| 变更作为单独合同 | 先判断与哪项合同相关，再按可变对价分摊规则处理 |
| 原合同终止、剩余部分并入新合同，且变动与变更前已承诺的可变对价相关 | 先按原合同开始日基础分摊；分到变更日尚未履约部分的，再按新合同开始日基础二次分摊 |
| 其他情形 | 分给合同变更日尚未履行的履约义务 |

二次分摊针对上述原可变对价的**后续变动额**。原未履约部分已分摊的固定及可变对价，加上变更新增的固定加价，先组成新合同交易价格，按新合同规则分摊。

### A、B、C二次分摊例（元）

A、B原合同固定1000＋可变200＝1200。假设可变金额均符合限制，A、B、C均可明确区分、单独售价相同且在交付时确认收入；后续变动不适用仅归属某一商品的例外。

| 日期/事项 | 计算与处理 |
| --- | --- |
| 原合同开始 | A、B各分1200÷2＝600 |
| 2x24年11月1日交付A | 确认收入600 |
| 12月1日新增C，加价300不反映其单独售价 | 不能作为单独合同；B、C与已交付A可区分，原合同终止，B、C组成新合同；总价600＋300＝900，各分450 |
| 12月31日原可变对价200增至240 | 增加40先按原合同分A、B各20；A的20当期追加收入；B的20进入新合同，B、C再各分10 |
| 2x25年3月31日交付B | 确认450＋10＝460 |
| 2x25年6月30日交付C | 确认450＋10＝460 |

合计：A 620＋B 460＋C 460＝1540，与1000＋240＋300一致。不能把40直接全部分给B、C，也不能把旧B分到的20全部留给B。

**数量例：**原100件同价可区分商品，固定300＋可变100＝400，已交付80件；变更按“原合同终止＋新合同”处理，新增同样20件、固定加价50，原可变对价之后增至110，均符合限制且不适用特定归属例外：

- 原剩余20件分得400×20/100＝80，与新增50组成新合同130；新合同共40件。
- 后续增加10先分给原已交付80件8、原剩余20件2；8调整当期收入，2再在新合同40件分摊。若各件单独售价相同，原剩余组与新增组各分1，最终各分66。

**标签**：`收入准则` · `Markdown同步` · `交易价格分摊` · `后续变动` · `合同变更`

## 13｜销售返利、重大权利和客户积分怎么处理？

**难度**：高频综合　·　**更新**：2026-09-07

> **速览**：本次价款返利按可变对价，未来额外优惠判断重大权利；积分兑换估计变化调整履约进度，不重分初始交易价格。

### 十二、销售返利与重大权利的区分

| 实质 | 处理 |
| --- | --- |
| 返还本次交易价款，如现金返利或本次价款抵扣 | 通常为可变对价，估计并限制可计入交易价格的金额，预计返还部分确认为负债 |
| 不购买本次商品也能获得的普通促销优惠 | 不构成当前合同的重大权利；不为该优惠分摊当前交易价格，未来按新交易条件确认收入 |
| 因当前合同取得、提供额外优惠的未来购买选择权 | 评估是否构成重大权利；构成时作为单项履约义务分摊对价，客户行使并取得相关商品控制权或选择权失效时确认收入 |

选择权单独售价不能直接观察时，结合额外折扣和行使可能性估计；若行使价反映相关商品单独售价，不构成重大权利。以下各例独立且不考虑增值税；商品销售均假设控制权已转移。

### 现金返利（万元）

销售价款100，预计应付返利10，假设估计已符合可变对价限制、返利与货款分别结算：

```text
借：应收账款 / 银行存款          100
    贷：主营业务收入               90
        其他应付款——销售返利       10

借：其他应付款——销售返利         10
    贷：银行存款                   10
```

退款义务与科目选择的区别见第21节；附退货权销售见第15节。

### 普通九折券与重大权利（元）

| 事项 | 普通促销 | 重大权利 |
| --- | --- | --- |
| 条件 | 所有顾客下月均可领九折券，不因本次购买才取得 | 本次购买100后，可用60购买正常售价100的商品；普通客户最低价90 |
| 选择权单独售价 | 无需为普通优惠分摊 | 额外优惠90−60＝30；预计使用率80%，单独售价30×80%＝24 |
| 本次收款100的分摊 | 收入100 | 当前商品100×100/124＝80.65；选择权100×24/124＝19.35 |
| 以后购买并取得商品 | 标价100，付90，收入90 | 付60，加原合同负债19.35，收入79.35 |
| 原例商品成本 | 本次60、以后55 | 本次60、以后50 |

普通券销售分别借银行存款100/90、贷主营业务收入100/90。四次销售的成本均按实际金额：借主营业务成本，贷库存商品（60、55、60、50），不随收入分摊比例机械缩减。

重大权利的分录：

```text
本次销售：
借：银行存款                    100
    贷：主营业务收入             80.65
        合同负债                 19.35

客户行使并取得商品：
借：银行存款                     60
    合同负债                    19.35
    贷：主营业务收入             79.35

或者，客户未使用，权利到期失效：
借：合同负债                    19.35
    贷：主营业务收入             19.35
```

使用与失效是互斥情形，不能重复结转同一合同负债。

### 客户积分：兑换数量估计变化（元，计算结果按元取整）

2024年1月1日销售收款100000，每消费10元得1积分、每积分抵1元，共10000积分。假设构成重大权利，商品单独售价100000，预计兑换率95%，企业预计有权获得客户未兑换部分对应金额，按客户行使模式确认。

| 阶段 | 计算 | 本期积分收入 | 期末积分合同负债 |
| --- | --- | --- | --- |
| 合同开始 | 积分单独售价10000×1×95%＝9500；按100000∶9500分摊，商品91324、积分8676 | — | 8676 |
| 2024年12月31日 | 已兑4500，预计总兑9500；累计4500/9500×8676≈4110 | 4110 | 8676−4110＝4566 |
| 2025年12月31日 | 累计已兑8500，预计总兑9700；累计8500/9700×8676≈7603 | 7603−4110＝3493 | 8676−7603＝1073 |

初始分录：借银行存款100000，贷主营业务收入91324、合同负债8676；两年积分履约分别借合同负债、贷主营业务收入4110和3493。兑换取得商品的成本另按实际成本结转，题目未给金额。

**9500变9700只改变积分履约进度，不重算商品与积分的初始分摊。**不能可靠预期有权获得客户放弃金额时，剩余负债何时结转按“客户未行使权利”专题判断，不能无条件套预计兑换比例。

## 14｜合同履约成本、合同取得成本和减值怎么处理？

**难度**：高频综合　·　**更新**：2026-09-07

> **速览**：先按适用准则确认履约资产，区分未来资源与已履约耗用；合同资产和合同成本适用不同减值规则。

### 十三、合同成本：确认、摊销、减值与建造合同

### 确认顺序与费用化边界

| 项目 | 处理条件 |
| --- | --- |
| 履约购入的存货、固定资产、无形资产等 | 先按各自准则确认；不能仅因服务客户合同就计入合同履约成本 |
| 合同履约成本资产 | 不属于其他准则范围，且同时满足：与当前或预期取得合同直接相关、增加未来履约资源、预期可收回 |
| 合同取得成本资产 | 不取得合同就不会发生的增量成本（如符合条件的销售佣金），且预期可收回；摊销期限不超过一年，可选择发生时费用化 |
| 当期费用 | 已履约部分支出、无法区分已履约与未来履约的支出、应费用化的管理支出；未反映在合同价格中的非正常消耗也应费用化 |
| 非增量的合同取得支出 | 无论是否取得合同均发生的差旅费等通常费用化，明确由客户承担的除外 |

合同成本资产按与相关商品收入确认相同的基础摊销。管理或销售用途的折旧摊销分别计入管理费用、销售费用；履约用途须区分当期耗用和未来履约资源，不能将“先归集”误当作期末可以任意保留资产。

### 资产负债表列报

按明细科目**初始确认时预计摊销期限**判断，而非期末剩余期限；以账面余额扣除相关减值准备后的金额列示。

| 成本资产 | 不超过一年或一个正常营业周期 | 超过一年或一个正常营业周期 |
| --- | --- | --- |
| 合同取得成本 | 其他流动资产 | 其他非流动资产 |
| 合同履约成本 | 存货 | 其他非流动资产 |

它们与已履约形成的合同资产不同，也不是上述报表的单独项目名称。

### 五年信息中心管理服务例（万元）

硬件300、软件200、平台设计搭建测试120、项目工资50。假设硬件软件分别符合固定资产、无形资产确认条件；平台120不属于其他准则范围，满足合同履约成本三条件。工资50仅服务于本期已提供服务，未形成未来资源。

| 支出或后续处理 | 分录 |
| --- | --- |
| 硬件300 | 借固定资产300，贷银行存款300 |
| 软件200 | 借无形资产200，贷银行存款200 |
| 平台成本120 | 借合同履约成本120，贷银行存款/应付账款等120 |

| 平台每年摊销24 | 假设服务均匀转移、五年直线摊销：借主营业务成本24，贷合同履约成本24 |
| 硬件每年折旧60 | 假设已达到可使用状态、按完整年度计提，五年直线法、残值零：借主营业务成本60，贷累计折旧60 |

### 建造例：40%是收入进度，不是所有成本的结转比例（万元）

合同价1000、预计总成本700，属于时段履约，第三方测量进度40%且能恰当反映控制权转移。本年支出及处理如下，假设忽略税额：

| 项目 | 金额 | 处理 |
| --- | ---: | --- |
| 已形成已完成工程的材料、人工、机械费 | 280 | 已履约消耗，计主营业务成本；可先归集再全额结转 |
| 后续施工用专属构件，未安装且尚未转移控制权 | 60 | 购入构件若适用存货准则，先列原材料等；仅不属其他准则且满足三条件的成本，才列合同履约成本。专用于合同并不自动改变准则归属 |
| 未反映在合同价格中的非正常材料浪费 | 10 | 当期损失或费用，不资本化 |
| 总部管理工资，不由客户承担 | 20 | 管理费用 |

收入1000×40%＝400：借合同资产或应收账款400，贷主营业务收入400，科目取决于收款权是否无条件。

成本分录集中如下：

```text
借：合同履约成本                280
    贷：原材料 / 应付职工薪酬等    280
借：主营业务成本                280
    贷：合同履约成本              280

购入构件，假设适用存货准则：
借：原材料等                     60
    贷：银行存款等                 60
以后耗用形成已履约部分：
借：主营业务成本                 60
    贷：原材料等                   60

借：当期损失或费用               10
    贷：原材料等                   10
借：管理费用                     20
    贷：应付职工薪酬               20
```

### 合同资产与合同成本减值

科目名称不决定准则归属：

| 项目 | 减值与转回 |
| --- | --- |
| 合同资产 | 已履约形成、但收款权尚有时间以外条件的权利；按金融工具准则计量预期信用损失，损失准备随估计变化调整，可转回。这里保留教材常用“资产减值损失”科目，不据此套长期资产不得转回规则 |
| 合同履约成本、合同取得成本 | 按收入准则比较账面价值与“相关商品预期剩余对价−估计尚需发生的相关成本”，账面价值超出部分计提减值；因素变化后可转回，但转回后不得超过假设从未计提减值的当日账面价值 |

减值顺序：先按其他相关准则测试与合同有关的其他资产，再测试合同成本资产；若随后按资产减值准则测试相关资产组，应将合同成本资产减值后的账面价值纳入。

```text
计提：
借：资产减值损失
    贷：合同资产减值准备
        或 合同履约成本减值准备 / 合同取得成本减值准备
转回：借相关减值准备，贷资产减值损失。
```

模板中的准备科目按资产类型择用，同一损失不同时贷记三类准备。

### 综合例：亏损建造合同与质保金（万元）

## 15｜合同履约成本中的运费怎么判断？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：运输先看客户合同及控制权时点，再判断独立服务、存货成本或期间费用；内部调拨不自动费用化。

### 十四、合同履约成本中运费的处理

按运输目的和控制权转移时点判断，不能仅凭“运费”名称计入销售费用。

| 情形 | 核算 |
| --- | --- |
| 为履行销售合同运输，商品送达指定地点后才转移控制权 | 通常不构成单项履约义务；运输成本作为合同履约成本，按商品收入确认基础摊销，列营业成本 |
| 客户已取得商品控制权，企业又承诺运输 | 评估运输服务是否构成单项履约义务；构成时分摊交易价格，确认运输服务收入并结转对应成本，不能只核算费用而漏分收入 |
| 非客户合同运输，但为存货达到目前场所和状态所必需、形成预期经济利益资源 | 按存货准则计入存货成本 |
| 非客户合同运输，且不满足上述资本化条件 | 按性质计当期费用，如参展运输通常为销售费用 |

**内部调拨例：**不能仅因在企业内部运输就一律记管理费用；先判断是否属于使存货达到目前场所和状态的必要支出，否则再按费用性质核算。

营业成本是报表列报项目；具体用主营业务成本或其他业务成本，应与相关业务性质一致。运输发生在控制权转移后，只是识别独立服务的线索，仍须检查可明确区分条件。

**标签**：`收入准则` · `Markdown同步` · `合同履约成本` · `运费`

## 16｜附有销售退回条款的销售如何处理？

**难度**：高频综合　·　**更新**：2026-09-07

> **速览**：附退货权销售分别计量收入、退款负债和应收退货成本；持续重估，并区分收入限制与融资条件。

### 十五、特殊交易：附有销售退回条款的销售

客户取得控制权后仍有退货权，应分别确认收入、退款义务和收回商品的权利：

| 项目 | 计量 |
| --- | --- |
| 收入 | 预期有权收取、符合可变对价限制的对价，不包含预计退还金额；仅能估计退货率并不自动满足限制 |
| 退款负债 | 预计退还对价，本例用预计负债——应付退货款 |
| 应收退货成本 | 预计退回商品转让时账面价值，扣除预计收回成本和价值减损 |
| 主营业务成本 | 转让商品账面价值减应收退货成本；因此包括预计收回费用及价值减损的影响 |

每个资产负债表日重新估计退货情况和相关资产价值，按会计估计变更调整；不能把实际退货与原估计差异长期留在准备中。

### 100件商品例（元）

每件售价100、成本60，预计退10件；预计运费50、检测包装30，无额外价值减损。假设估计符合可变对价限制，题设增值税率13%，销售时对全部价款确认销项税；实际退货时满足冲减相应销项税额的条件。

| 计算 | 金额 |
| --- | ---: |
| 含税应收100×100×1.13 | 11300 |
| 收入90×100；退款负债10×100 | 9000；1000 |
| 销项税10000×13% | 1300 |
| 应收退货成本10×60−50−30 | 520 |
| 主营业务成本6000−520＝5400＋80 | 5480 |

```text
销售：
借：应收账款                    11300
    贷：主营业务收入              9000
        预计负债——应付退货款      1000
        应交税费——应交增值税（销项税额） 1300
借：主营业务成本                 5480
    应收退货成本                  520
    贷：库存商品                  6000
```

若实际恰好退回10件、收回费用恰为80且无价值减损，退款及收回商品：

```text
借：预计负债——应付退货款         1000
    应交税费——应交增值税（销项税额） 130
    贷：银行存款 / 应收账款        1130

借：库存商品                      600
    贷：应收退货成本               520
        银行存款等                  80
```

实际支付80实现了原来计量应收退货成本时扣除的收回费用，不重复计入损益。若实际费用、退回数量或商品价值不同，应先更新估计并反映差额；上述分录不代表退回商品一律按600入账。

### 特殊例：退货估计受限且延期收款（元）

客户在合同开始日取得A产品控制权，享有90天退货权；企业无该新品退货历史或其他可参考信息，**本例没有任何对价金额符合可变对价限制**。约定合同开始日后第二年末收12100，开始日现销价10000、成本8000，忽略税费及收回成本、价值减损；退货期满没有退货。

| 阶段 | 处理及理由 |
| --- | --- |
| 合同开始 | 收入0；借应收退货成本8000，贷库存商品8000 |
| 90天退货期内 | 本例尚未确认合同资产或应收款项，故不确认相关融资影响；不是仅因收入为0就一概不计息 |
| 退货期满 | 不确定性消除，确认收入和应收款；下列10000计量还假设开始日与退货期满日应收款公允价值无重大差异 |
| 其后至收款日 | 按剩余合同期限确定实际利率，摊销2100融资收益，并按金融工具准则评估应收款减值 |

```text
退货期满确认收入：
借：长期应收款                  12100
    贷：主营业务收入             10000
        未实现融资收益            2100
结转成本：
借：主营业务成本                 8000
    贷：应收退货成本              8000
后续计息：
借：未实现融资收益               当期实际利息
    贷：财务费用等                 当期实际利息
```

不能把“有退货权”或“没有历史数据”直接等同于零收入，仍须考虑其他可用信息及可变对价限制；后续信息足以支持金额时应及时更新估计，不必机械等到退货期满。

本例的10000与2100依赖上述公允价值假设；若两日公允价值差异重大，须重新分析，不能照搬金额。由于计息从退货期满后开始，不能直接按12100/10000推算完整两年的年利率并将其用于剩余期间。

**标签**：`收入准则` · `Markdown同步` · `销售退回` · `可变对价` · `应收退货成本` · `分录`

## 17｜主要责任人和代理人如何区分？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：转让前控制特定商品或服务的按总额确认；代理人按佣金净额确认，主要责任、存货风险和定价权仅为判断迹象。

### 十六、特殊交易：主要责任人与代理人的区分

**先识别向客户提供的特定商品或服务，再判断企业在转让前是否控制它。**不能仅凭合同称谓、第三方发货或收取客户全款判断身份。

| 身份 | 收入计量 |
| --- | --- |
| 主要责任人：转让前控制商品或服务 | 已收或应收对价总额 |
| 代理人：转让前不控制，只安排第三方提供 | 预期有权收取的佣金或手续费；可按收款减应付其他方金额，或约定佣金金额/比例确定 |

控制情形包括先取得商品再转售、能够主导第三方代表企业向客户提供服务、先控制第三方商品再通过重大整合服务形成组合产出。**第三方实际执行服务，不必然使企业成为代理人。**

承担主要履约责任、转让前后存货风险、自主定价权等是辅助迹象，须结合所有事实判断，不是必须全部满足的清单。

### 手机销售比较（元，忽略税额，相关履约已完成）

| 情形 | 判断与分录 |
| --- | --- |
| 甲先买入并控制手机，再售1000，进货成本700；承担滞销和售后责任、自主定价 | 主要责任人：借银行存款1000，贷主营业务收入1000；借主营业务成本700，贷库存商品700 |
| 平台不控制手机，只安排商家发货及负责售后，取得佣金100 | 代理人：只收佣金时，借银行存款/应收账款100，贷主营业务收入100 |
| 同一代理情形，平台代收全部1000，扣佣100后付商家 | 借银行存款1000，贷其他应付款900、主营业务收入100；支付商家时借其他应付款900，贷银行存款900 |

平台两种收款分录是不同结算方式，不能重复确认佣金；代收900是负债，不是平台收入。

## 18｜授予知识产权许可如何确认收入？

**难度**：高频综合　·　**更新**：2026-09-07

> **速览**：许可先识别履约义务，再按重大影响活动、客户受影响和活动不另转让商品三条件判断时段；固定费与提成分别计量。

### 十七、特殊交易：授予知识产权许可

先判断许可是否可明确区分、构成单项履约义务；若不能，结合其他承诺整体判断。以下讨论单独识别的许可。

### 时点或时段：按三条件判断

同时满足以下三项，作为时段履约；否则作为时点履约：

1. 合同要求，或客户能够合理预期，企业将从事对该知识产权有重大影响的活动。
2. 这些活动会对客户产生有利或不利影响。
3. 这些活动本身不会向客户转让某项商品或服务。

“现成/静态”“持续运营/动态”只能帮助理解，不能替代条件。时段收入采用能反映履约的进度方法，并非一律直线摊销。

| 例子 | 判断 |
| --- | --- |
| 已完成插画授权2年，可用于包装，企业不再更新或从事重大影响活动 | 通常是时点履约；客户能够使用许可并从中获益时确认，不能仅因两年期限分期确认 |
| 动漫角色授权3年，企业持续更新动画、推广电影及粉丝活动，重大影响角色且使客户受益或受损，活动不另向客户转让成果 | 满足三条件时按时段履约；不是只要有宣传就满足 |
| 另外交付10条专属广告视频、100张设计图、包装方案、定制模块或源代码 | 先看是否有可明确区分的其他义务；例如许可＋10张设计图、许可＋广告片制作，能区分时分别核算。不能将新增成果简单都归为“维护IP” |

授权期限1年或3年、地域中国或全球、用途服装或玩具，是权利范围限制，本身不决定时点/时段。若1月1日签约、4月1日才允许开始使用，不能在4月1日前确认许可收入。

标准软件固定授权费也按许可本身判断：安装、激活或收款延后不当然推迟收入，但若相关步骤使客户尚不能使用或获益，不能提前确认。

### 固定费与提成：同一许可可以有不同确认节奏（万元）

2024全年动漫授权，固定费100、销售提成5%、每季度结算。假设许可满足上述三个时段条件且全年均匀履约，忽略税费：

| 对价或情形 | 计算与确认 |
| --- | --- |
| 固定100预收 | 借银行存款100，贷合同负债100；各月借合同负债、贷主营业务收入。前11个月各8.33，末月8.37，合计100 |
| 第一季度客户实际销售600，企业已履行对应义务 | 提成600×5%＝30：借应收账款30，贷主营业务收入30；收款时借银行存款30，贷应收账款30 |
| 企业已履约，但第一季度客户未销售 | 不预计未来提成；第二季度实际销售600并满足履约条件时，确认30 |

提成确认规则见第7节；季度结算频率本身不替代收入确认条件。

**延后开放的独立变式：**假设客户3月已有符合提成约定的实际销售200（仅收预售款不等于该事实成立），许可4月1日开放。3月企业尚未履约，不确认提成；之后在相关履约条件满足时确认200×5%＝10，借应收账款10、贷主营业务收入10。若是持续履约许可，不能只凭“4月1日开始授权”就断言相关义务已全部履行；固定费也须另按实际授权期间处理，不能照搬全年例。

## 19｜售后回购如何判断是销售、租赁还是融资？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：先区分企业回购义务或回购权与客户回售权；仅客户回售权先判行权动力，再按条件分类租赁、融资或退货销售。

### 十八、特殊交易：售后回购

售后回购涉及日后购回同一、相同或几乎相同商品，或含原商品作为组成部分的商品。**先看权利义务属于谁，不能一律先问客户有没有行权动力。**

| 回购安排 | 分类 |
| --- | --- |
| 企业负有远期回购义务，或企业享有回购权 | 客户在销售时点未取得控制权，按租赁或融资处理；不先套客户行权动力判断 |
| 客户有权要求企业回购 | 合同开始日评估客户有无行权的重大经济动因；有则按租赁或融资，无则按附销售退回条款处理 |

比较回购价与预期市场价值可辅助评估客户动力，还须考虑权利期限等相关事实。例：预计回购时市场价80万元，客户可要求企业100万元回购，通常有重大经济动因；这与下一步比较**原售价**是两回事。

### 已确定按租赁或融资处理后

| 比较 | 处理与例子（万元） |
| --- | --- |
| 回购价低于原售价 | 租赁交易，按租赁准则；如原售价100、回购80，差额20体现客户一定期间使用资产的对价 |
| 回购价不低于原售价 | 融资交易；如原售价100、回购105，收到100确认为金融负债，差额5在回购期间确认为利息费用等 |

价格比较应考虑货币时间价值；上例只示意分类，假设折现不改变比较结果。不能将售后回购的租赁处理与已满足销售条件的售后租回混为一谈。

### 融资例分录

假设企业负有回购义务、原收100后付105，忽略税额，相关利息不符合资本化条件；用其他应付款明细核算该金融负债：

```text
收到款项：
借：银行存款                    100
    贷：其他应付款——回购融资款    100
回购期间计息（合计5，按适用期间分配）：
借：财务费用                      5
    贷：其他应付款——回购融资款      5
实际回购支付：
借：其他应付款——回购融资款       105
    贷：银行存款                  105
```

融资时不确认商品销售收入或结转其销售成本，原资产继续按适用准则核算。若为企业享有回购权的融资安排，权利到期未行使，应在到期时终止确认金融负债、确认收入，并按商品转让情况结转相应成本；不得套用到必须履行的回购义务。

客户回售权且无重大经济动因时，收入、退款负债与应收退货成本按前节销售退回规则处理，不在此重复分录。

## 20｜客户未行使的权利如何确认收入？

**难度**：高频综合　·　**更新**：2026-09-07

> **速览**：不可退预收款的未行使部分，满足有权取得预期时按行使模式确认；收入、实际消费税额及到期余额分别判断。

### 十九、特殊交易：客户未行使的权利

客户预付取得储值卡、点券或课程等权利时，尚未履约的款项先确认为合同负债，税额另行核算。后续按下表处理：

| 情形 | 收入确认 |
| --- | --- |
| 客户使用，企业已提供相关商品或服务 | 按履约转收入；如消费300（忽略税额），借合同负债300，贷主营业务收入300 |
| 预付款无需退回，企业预计有权取得客户放弃权利的金额 | 随客户行使权利的模式按比例确认未使用部分，而非收款时一次确认 |
| 不能作出上述预期 | 等客户要求履行剩余义务的可能性极低时，才转收入；长期未用或形式到期不自动满足 |
| 依法必须转交其他方的款项 | 不能留作本企业收入，按义务转其他应付款等 |

预付课程、健身卡还应先识别履约承诺：若企业承诺期间内随时可用的服务，即使客户未到场也可能已履约，不能一律按“实际来几次”或“到期才履约”处理。普通免费优惠券也不因过期而产生收入。

### 不含税简例（元）

充值1000，预计不可退且最终不会使用100，实际已消费450；假设有依据支持企业有权取得未使用金额：预计使用900，进度450/900＝50%，本期收入450＋100×50%＝500。

```text
充值：借银行存款1000，贷合同负债1000。
履约及按比例确认未使用部分：借合同负债500，贷主营业务收入500。
```

### 面包店储值卡例（元，按元取整）

2025年售5000张卡，每张200，共1000000；预计50000不会使用，年末实际消费400000。假设卡款不可退、支持按行使模式确认，题设税率13%，实际消费时产生销项税；税率及纳税时点仅为本例条件。

| 项目 | 计算与金额 |
| --- | --- |
| 初始合同负债 | 1000000/1.13≈884956 |
| 初始待转销项税额 | 1000000−884956＝115044 |
| 行使比例 | 400000/(1000000−50000)＝400000/950000 |
| 含实际消费及未使用部分的计量基数 | 400000＋50000×400000/950000≈421053；不是当期增值税应税销售额 |
| 本期收入 | （400000＋50000×400000/950000）/1.13≈372613 |
| 本期销项税 | **400000/1.13×13%≈46018**，只按实际消费，不能用421053替代400000 |
| 期末余额 | 合同负债884956−372613＝512343；待转销项税115044−46018＝69026 |

```text
售卡收款：
借：库存现金 / 银行存款         1000000
    贷：合同负债                884956
        应交税费——待转销项税额  115044
年末确认：
借：合同负债                   372613
    应交税费——待转销项税额      46018
    贷：主营业务收入             372613
        应交税费——应交增值税（销项税额） 46018
```

### 到期剩余待转税额：区分余额计算与终止确认条件

沿用原教学变式（万元）：卡款500，最终实际消费460、未消费40，题设税率13%。初始待转税500/1.13×13%≈57.52；实际转销项460/1.13×13%≈52.92，剩余40/1.13×13%≈4.60。

余额不能因账面挂在“应交税费”就认定必然要交税，也不能仅因卡面到期就冲掉。先确定退款、续期、履约及纳税等义务是否已终止，再按相应性质处理。

原教学处理在“未消费款已确定归企业、无退款或继续履约义务、无相应增值税义务”的假设下，将剩余待转税额转入营业外收入：借应交税费——待转销项税额4.60，贷营业外收入4.60。这是该教学例的科目处理，不作为所有储值卡到期的统一规定；上述义务仍存在时不得照搬。

## 21｜无需退回的初始费如何确认收入？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：不可退初始费计入交易价格，按所对应履约义务确认；内部准备不形成收入，平均摊销须有履约基础。

### 二十、特殊交易：无需退回的初始费

合同开始或接近开始时收取的入会费、开户费、加盟费等，**计入交易价格，但不因不可退还而立即确认收入**。

| 与已承诺商品或服务的关系 | 确认收入 |
| --- | --- |
| 相关，且该商品或服务构成单项履约义务 | 转让时按分摊至该义务的交易价格确认，不一定等于名义初始费 |
| 相关，但不构成单项履约义务 | 并入包含它的履约义务，按该义务履行情况确认 |
| 不相关 | 作为未来商品或服务的预收款，随未来转让确认 |

开户、建档、办卡等若只是内部准备，未向客户转让商品或服务，不形成已履约收入，也不计入履约进度；相关支出另按合同成本规则判断资本化或费用化。

### 三个例子（元，忽略税额）

| 情形及必要假设 | 分录与计算 |
| --- | --- |
| 平台不可退入门费600，开始时无单独交付；假设对应未来12个月均匀提供的平台接入服务，无需跨续约期分配 | 收款借银行存款600，贷合同负债600；每月借合同负债50，贷主营业务收入50 |
| 初始收款1000含设备，设备单独售价800、成本500；可与其他服务商配合使用，且合同承诺可明确区分；**假设按全部义务相对单独售价计算后确实分给设备800** | 已收款先列合同负债1000；设备控制权转移时借合同负债800，贷主营业务收入800；借主营业务成本500，贷库存商品500；剩余200随对应义务确认 |
| 健身年费1200＋入会费300，建档办卡不单独转让服务；假设合计1500仅对应12个月随时可用、均匀履行的健身服务，不另形成续约重大权利 | 收款借银行存款1500，贷合同负债1500；每月借合同负债125，贷主营业务收入125 |

平台若仅给予未来购买选择权，或续约免初始费构成重大权利，应按选择权与相关服务判断，不能直接用600÷12。服务并非均匀履行时，也不能机械按月平均确认。

## 22｜退款负债、预计负债、其他应付款和合同负债怎么区分？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：退钱义务与交货义务不同；退款科目按业务和结算安排判断，不以尚需估计或是否已收款作唯一标准。

### 二十一、退款负债、预计负债与其他应付款的区分

**负债性质与使用科目分开判断。**企业预期应退还客户的对价不计入交易价格；承担的是退钱义务，不是未来交付商品或服务的义务。

| 事项 | 性质与本章科目口径 |
| --- | --- |
| 收款后仍须交付商品或服务 | 合同负债，随履约转收入 |
| 预计销售退回款 | 退款义务，本章用预计负债——应付退货款；另计应收退货成本，详见销售退回专题 |
| 现金返利等需向客户另行结算 | 退款/返还义务，本章现金返利例用其他应付款——销售返利；具体科目依业务性质和结算安排，不能仅凭“尚需估计”就一律改用预计负债 |
| 原合同只因折让等预计少收，且没有独立返还义务 | 调整交易价格及相关收入、应收等；不能凭收入减少额另造一笔退款负债 |

### 100、90、10的两种安排（万元，忽略税额）

- **已收100，预期有权取得90，需退10：**90按履约情况列收入或合同负债，10列返还义务，不能将100都作为合同负债或收入。
- **无条件应收100，预计另返10：**已有独立返利义务且收入确认条件满足时，确认收入90及返利负债10，分录见第12节。未收货款不否定另行返款义务；具体业务若采用预计负债——应付客户返还款，也须按义务性质判断，不是所有返利的唯一科目。

反之，若实际只有收90的权利，也没有另付10的义务，就按相应权利和交易价格处理，不能同时虚列应收100及应付10。退款义务的存在不等于各报表项目可以任意抵销。

**标签**：`收入准则` · `Markdown同步` · `退款负债` · `预计负债` · `其他应付款` · `合同负债` · `销售返利`
