## 01｜政策变更、估计变更与前期差错如何区分和处理？

**难度**：系统补齐　·　**更新**：2026-09-07

> **速览**：先判断改变的是政策、估计还是前期错误，再确定追溯、未来适用及重要性。

### 一、政策变更、估计变更与前期差错的判断和处理

| 事项 | 性质与处理 |
| --- | --- |
| 会计政策变更 | 变更确认、计量、报告的原则、基础或方法。按国家规定变更的先执行相关规定；自愿变更须能提供更可靠、更相关的信息，原则上追溯调整 |
| 会计估计变更 | 因新信息、经验或情况变化修订估计，采用未来适用法；只影响当期的计入当期，同时影响未来的分期反映，不重编以前期间 |
| 重要的前期差错 | 当时能够取得并应当考虑的可靠信息未用或误用，导致错报或漏报，原则上追溯重述 |

追溯调整视同新政策自交易初始就已采用；追溯重述视同前期差错从未发生。两者均涉及比较信息及相关期初项目，不能仅凭分录是否调整留存收益区分。追溯不切实可行的处理见第二节；差错须先判断重要性，不能将任何小额错误均套为追溯重述。

### 估计变更的常见例子

固定资产折旧年限、净残值和折旧方法；无形资产摊销年限或方法；坏账准备估计比例；存货可变现净值估计。前提是基于真实可靠的新信息，若原处理违反准则或误用了当时已有信息，应判断为差错，不能借“估计变更”避开更正。

确实难以区分政策与估计变更的，按估计变更处理。以前漏记折旧、错误确认收入或费用跨期，则按前期差错判断。政策变更的存货等例子见第三节。

## 02｜追溯不切实可行时，从哪个时点开始处理？

**难度**：系统补齐　·　**更新**：2026-09-07

> **速览**：区分列报前期影响和当期期初累积影响无法确定，并披露无法追溯的原因与处理起点。

### 二、追溯不切实可行时如何处理

“不切实可行”须经过合理努力仍无法处理，不等于工作量大或资料暂未整理。常见障碍包括：无法确定前期影响数；必须假定当时管理层意图；需作重大估计且无法客观区分当时可取得的信息与事后信息。

| 事项与障碍 | 处理起点 |
| --- | --- |
| 政策变更：对列报前期的影响无法确定 | 从可追溯调整的最早期间期初应用新政策；不能因此直接放弃全部追溯 |
| 政策变更：当期期初仍不能确定以前各期累积影响 | 采用未来适用法，将新政策应用于变更日及以后交易事项 |
| 重要前期差错：影响数无法确定 | 按准则从可追溯重述的最早期间调整相关期初余额，或采用未来适用法 |

附注说明无法追溯的事实、原因及开始应用或更正的时点和具体情况。国家规定的政策变更另有衔接安排时，先按其规定执行。

## 03｜哪些属于会计政策变更，哪些只是交易发生了变化？

**难度**：系统补齐　·　**更新**：2026-09-07

> **速览**：同类交易的政策不得随意变更；新交易、交易本质改变及准则规定的重分类另行判断。

### 三、会计政策变更的常见场景与边界

| 场景 | 判断 |
| --- | --- |
| 发出存货先进先出法改为加权平均法 | 政策变更；须符合会计信息更可靠、更相关等变更条件，不能随意更换 |
| 投资性房地产成本模式改为公允价值模式 | 符合条件后作为政策变更，追溯例见第6节；公允价值模式不得转回成本模式。模式选择条件及解释18号分组例外见投资性房地产章 |
| 新准则改变收入确认、金融工具分类计量等 | 按新准则规定及衔接要求处理 |
| 政府补助总额法与净额法之间变更 | 属于政策变更，同类或类似业务须保持一致，并满足政策变更条件 |

交易本质与以前不同、首次发生或对不重要交易采用新政策，不属于政策变更。金融资产因业务模式实际改变而重分类、房地产因用途改变而转换，也不能仅因核算方法变化就视为政策变更。

## 04｜政策追溯调整与差错重述的分录如何处理？

**难度**：系统补齐　·　**更新**：2026-09-07

> **速览**：政策调整通常直接调整期初项目；重要差错涉及前期损益时经以前年度损益调整，税项须另行判断。

### 四、追溯调整与重述的分录处理

| 方法 | 分录与报表处理 |
| --- | --- |
| 政策变更追溯调整 | 通常直接调整相关资产、负债及期初留存收益，不通过“以前年度损益调整”；调整列报前期最早期初及各比较期间相关数据 |
| 重要前期差错追溯重述 | 先纠正错误；涉及以前年度损益时通常通过“以前年度损益调整”过渡，再转留存收益，具体分录见第五节 |

以下仅为累积影响归属留存收益的示意，相关权益项目也可能需要调整，不能把原属其他综合收益的影响一律转入未分配利润。所得税先按所得税准则判断：可能形成、转回递延税项或影响当期所得税，并非每次都有递延所得税。

### 调增留存收益：假设同时新增递延所得税负债

```text
借：相关资产（增加）/ 相关负债（减少）
  贷：递延所得税负债
      盈余公积
      利润分配--未分配利润
```

### 调减留存收益：假设同时新增且满足确认条件的递延所得税资产

```text
借：盈余公积
    利润分配--未分配利润
    递延所得税资产
  贷：相关资产（减少）/ 相关负债（增加）
```

题目假设按10%提取盈余公积、无其他限制或分配影响时：盈余公积调整＝税后累积影响×10%，未分配利润调整＝税后累积影响×90%。实际按适用提取规则和题设调整，不能将所有权益变动机械按10%拆分。

## 05｜重要前期差错如何更正收入、费用与税项？

**难度**：系统补齐　·　**更新**：2026-09-07

> **速览**：分别处理错记项目、适用税项和留存收益；纯重分类不经过以前年度损益调整。

### 五、重要前期差错的更正分录

以下适用于重要前期差错影响以前年度损益且采用追溯重述的情形。税项按第四节原则判断；斜线科目按事实择用，无税务影响时省略税项分录。

### 补记以前年度收入

```text
借：应收账款 / 银行存款等
  贷：以前年度损益调整
```

假设补记收入增加应纳税额或形成递延所得税负债：

```text
借：以前年度损益调整
  贷：应交税费--应交所得税 / 递延所得税负债
```

结转留存收益：

```text
借：以前年度损益调整
  贷：盈余公积
      利润分配--未分配利润
```

### 补记以前年度费用或折旧

```text
借：以前年度损益调整
  贷：累计折旧 / 应付账款 / 其他应付款等
```

假设补记费用可减少应纳税额，或形成满足确认条件的递延所得税资产：

```text
借：应交税费--应交所得税 / 递延所得税资产
  贷：以前年度损益调整
```

结转留存收益：

```text
借：盈余公积
    利润分配--未分配利润
  贷：以前年度损益调整
```

### 不影响以前年度损益的差错

如果差错只影响资产、负债或权益内部项目，不影响以前年度损益，可以直接调整相关项目。

例如，原将应计入其他应付款的款项误记应付账款，仅重分类：

```text
借：应付账款
  贷：其他应付款
```

留存收益拆分见第四节；涉及原递延税项转回时，按实际差异改写分录。

## 06｜投房成本转公允价值时，累计调整与比较年度调整有何区别？

**难度**：系统补齐　·　**更新**：2026-09-07

> **速览**：期初资产和递延税项看累计影响，比较利润表只调整该年度折旧、公允价值变动和税费。

### 六、投资性房地产成本模式改为公允价值模式例题

假设2×25年初符合变更条件且追溯可行，税法继续按成本折旧、税务折旧与原会计折旧一致，原账面价值等于计税基础，无其他账税差异或权益分配事项。

| 题设 | 金额或比例 |
| --- | ---: |
| 2×23年1月1日取得成本 | 8,000 |
| 每年折旧（包括2×23年全年） | 600 |
| 2×23年末公允价值 | 9,200 |
| 2×24年末即2×25年初公允价值 | 9,600 |
| 所得税率、盈余公积提取比例 | 25%、10% |

### 期初累计影响与比较年度影响

| 调整对象 | 计算 | 调整额 |
| --- | --- | ---: |
| 2×25年初投资性房地产净额 | 9,600－(8,000－600×2)＝9,600－6,800 | 增2,800 |
| 2×25年初递延所得税负债 | 2,800×25% | 增700 |
| 2×25年初留存收益 | 2,800－700 | 增2,100 |
| 其中盈余公积 | 2,100×10% | 增210 |
| 其中未分配利润 | 2,100×90% | 增1,890 |
| 2×24年其他业务成本 | 撤销该年折旧 | 减600 |
| 2×24年公允价值变动收益 | 9,600－9,200 | 增400 |
| 2×24年所得税费用 | (600＋400)×25% | 增250 |

勾稽：2×24年初应调整递延所得税负债＝[9,200－(8,000－600)]×25%＝450；年内增加250，至2×25年初为700。比较利润表反映当年影响，不能填累计700税项或两年累计1,200折旧。
