## 01｜多次交易形成非同一控制下企业合并怎么理解？

**难度**：系统补齐　·　**更新**：2026-09-06

> **速览**：分步非同控：个别报表先辨原投资类别；合并报表按购买日公允价值重计量原股权。

### 一、多次交易形成非同一控制下企业合并

以下适用于不属于一揽子交易的分步取得控制；一揽子交易作为一项取得控制的交易处理。

| 原投资 | 购买日个别报表 | 购买日合并报表 |
| --- | --- | --- |
| 权益法长期股权投资 | 原账面价值＋新增投资成本转为成本法；原权益法 OCI、其他资本公积暂不结转 | 原股权按购买日公允价值重新计量，差额计入投资收益；原权益法项目按直接处置相关资产、负债的相同基础结转 |
| FVTPL 金融资产 | 先按原分类确认购买日前公允价值变动，再以公允价值＋新增投资成本转为长投 | 使用已调整的购买日公允价值，不重复确认同一重计量收益 |
| 其他权益工具投资 | 先调整至购买日公允价值，再加新增投资成本；累计 OCI 转留存收益 | 累计 OCI 不转投资收益 |

合并成本＝原股权购买日公允价值＋新增对价公允价值。商誉＝合并成本－取得的可辨认净资产公允价值份额；负差额须先复核计量，再确认营业外收入。控股合并的个别报表不单列商誉。

### 原投资为权益法：账面与公允价值的区别

甲原持有乙 30%，账面价值 3,200；追加 40% 支付 5,000 后取得控制。购买日原股权公允价值 3,800，乙可辨认净资产公允价值 12,000，单位均为万元。

| 计算项目 | 金额 |
| --- | ---: |
| 个别报表长投成本 | 3,200＋5,000＝8,200 |
| 合并成本 | 3,800＋5,000＝8,800 |
| 合并层面重计量收益 | 3,800－3,200＝600 |
| 商誉 | 8,800－12,000×70%＝400 |

### 原投资为金融资产：转换及累计 OCI

原 5% 股权成本 1,000，上年末公允价值 1,100，购买日公允价值 1,200；新增 48% 支付 12,000 后取得控制。

FVTPL 原投资上年及本期各确认公允价值变动损益 100；购买日转换：

```text
借：长期股权投资 13,200
  贷：交易性金融资产—成本 1,000
      交易性金融资产—公允价值变动 200
      银行存款 12,000
```

若原投资为其他权益工具投资，将上列转出资产科目换为“其他权益工具投资”，两期公允价值变动均进 OCI；另结转累计 OCI（假设盈余公积提取比例 10%）：

```text
借：其他综合收益 200
  贷：盈余公积 20
      利润分配—未分配利润 180
```

“个别看账面”仅适合概括原权益法长投；不能据此跳过原金融资产转换前的公允价值计量。

## 02｜分步实现企业合并时，实现合并那次的交易费用怎么处理？

**难度**：高频易错　·　**更新**：2026-09-06

> **速览**：合并中介费用计入当期损益；发行证券费用和非合并取得长投费用分别处理。

### 十五、分步实现企业合并时，取得控制那次交易费用的处理

| 费用性质 | 处理 |
| --- | --- |
| 同控、非同控企业合并的审计、法律、评估等中介及相关管理费 | 发生时计入管理费用等当期损益 |
| 企业合并以外取得长投的直接相关必要支出 | 计入初始投资成本 |
| 发行权益证券的直接增量费用 | 冲减股本溢价，不足依次冲减留存收益 |
| 发行按摊余成本计量的债务工具的直接交易费用 | 调整初始确认金额，计入实际利率计算 |

原投资初始取得时按当时分类处理费用，不因后来取得控制而追溯改记为合并费用。长投初始成本的原投资基础见本章前两节，不能一律写成“原股权公允价值＋新增对价”。

### FVTPL 分步取得控制例

甲首次取得乙 10% 支付 1,200，含已宣告未发放股利 50、交易费 10：金融资产成本＝1,140，应收股利＝50，投资收益借方＝10。上年末公允价值 1,240；本年追加取得 40% 后实际取得控制，原股权当日公允价值 1,280，新增价款 3,840，中介费 20，单位万元。

```text
借：交易性金融资产—公允价值变动 40
  贷：公允价值变动损益 40
借：长期股权投资 5,120
  贷：交易性金融资产 1,280
      银行存款 3,840
借：管理费用 20
  贷：银行存款 20
```

## 03｜多次交易形成同一控制下企业合并怎么理解？

**难度**：高频易错　·　**更新**：2026-09-06

> **速览**：同控长投以最终控制方账面净资产份额及承继商誉计量，与账面对价之差调整权益。

### 二、多次交易形成同一控制下企业合并

不属于一揽子交易时，合并日个别报表长投初始成本＝最终控制方合并报表中被合并方净资产账面价值×合并后持股比例＋应承继的原商誉账面价值。

初始成本与“原投资合并日账面价值＋新增对价账面价值”的差额调整资本公积（资本溢价或股本溢价）；不足冲减时依次冲减盈余公积、未分配利润。本次不产生新的购买法商誉。

| 比较对象 | 同控处理 |
| --- | --- |
| 原权益法长期股权投资 | 按账面价值结转，不因取得控制另作公允价值重计量 |
| 原按金融工具准则计量的股权 | 合并前仍按原分类处理，不能以“同控不重估”跳过原金融资产自身的后续计量 |
| 新支付的固定资产等非现金对价 | 按账面价值转出，不确认公允价值处置利得 |
| 原权益法或其他权益工具投资已确认的 OCI | 个别报表暂不结转；后续处置时按原项目性质处理 |

原金融资产加固定资产对价的1,200→1,300、长投10,500例题，统一保留在“原投资按公允价值计量，新增固定资产对价”卡片中。个别报表OCI暂不处理的[教学说明](https://www.233.com/zhongji/shiwu/fudao/202403/08150242693803.html)不适用于非同控金融资产转长投的结转情形。

合并报表按同控原则追溯，比较报表不早于双方同受最终控制之日。原投资损益的去重期间，从取得原股权日与双方同受最终控制日孰晚日起至合并日；该期间已确认的投资损益按所属期间冲减比较报表期初留存收益或当期损益，避免与并入的经营成果重复。依据：[2014合并报表应用指南“分步实现的同一控制下企业合并”（转载）](https://www.webtax.com.cn/articles/191550)。

合并底稿的权益去重：[正保2024综合阶段解析第1页（考生回忆版）](https://www.chinaacc.com/upload/resources/file/2024/08/24/2387831.pdf)区分原权益法形成的OCI、其他净资产变动与原金融资产公允价值变动形成的OCI，均在合并报表中冲回；前者结合资本溢价或股本溢价调整。此为教学解释，不把底稿冲回视为处置原投资而将OCI一律转入投资收益，也不改变个别报表暂不结转的处理。

## 05｜权益法下长期股权投资：其他综合收益和其他资本公积的去向怎么理解？

**难度**：系统补齐　·　**更新**：2026-09-06

> **速览**：权益法处置：OCI 按来源处理，其他资本公积转投资收益；结转范围看处置后核算方法。

### 三、权益法下长期股权投资：其他综合收益和其他资本公积的去向

处置长期股权投资时，原权益法确认的权益项目按来源及处置后核算方法结转。

| 项目 | 结转基础 |
| --- | --- |
| 其他综合收益（OCI） | 与被投资单位直接处置相关资产或负债采用相同基础；具体去向见第四节“其他综合收益的主要去向总表” |
| 资本公积—其他资本公积 | 结转投资收益，借方余额作相反分录 |

| 处置后状态 | 结转范围 |
| --- | --- |
| 剩余股权仍采用权益法 | 与处置部分对应的比例 |
| 全部处置，或剩余股权改按金融工具准则 | 全部原权益法相关余额 |
| 追加投资取得控制 | 不属于本表的处置情形；按本章分步取得控制规则区分个别和合并报表 |

原其他资本公积为贷方余额时：

```text
借：资本公积—其他资本公积
  贷：投资收益
```

不能把“其他综合收益”和“其他资本公积”视为同一项目，也不能只凭“不能重分类进损益”推断所有项目都必须转留存收益。

## 06｜其他综合收益的主要去向总表怎么理解？

**难度**：系统补齐　·　**更新**：2026-09-06

> **速览**：其他综合收益先辨来源，再确定转损益、转留存收益、调整成本或保留的处理。

### 四、其他综合收益的主要去向总表

OCI 按来源确定去向；权益法处理基础和范围见第三节“其他综合收益和其他资本公积的去向”。

| OCI 来源 | 转出时点与去向 |
| --- | --- |
| 其他债权投资公允价值变动 | 处置时转投资收益 |
| 外币财务报表折算差额 | 处置境外经营时按相应范围转损益；部分处置规则见外币折算章 |
| 现金流量套期储备 | 被套期项目影响损益时转入对应损益项目；形成非金融资产或负债的，调整其初始成本 |
| 自用房地产或存货转为公允价值模式投资性房地产时的增值 | 处置投资性房地产时转其他业务成本 |
| 指定为 FVOCI 的非交易性权益工具投资 | 终止确认时转留存收益，不进损益 |

| 指定为 FVTPL 的金融负债自身信用风险变动 | 已计入 OCI 的累计金额在终止确认时转留存收益，不进损益；损益错配例外见金融工具章 |

## 07｜非同一控制下买便宜时：成本法和权益法的营业外收入差异怎么理解？

**难度**：系统补齐　·　**更新**：2026-09-06

> **速览**：买便宜形成的收益：控股合并在合并报表确认；权益法和吸收合并在个别报表确认。

### 五、非同一控制下买便宜时：成本法和权益法的营业外收入差异

取得对价低于应享有的可辨认净资产公允价值份额时，先区分交易类型。

| 交易 | 收益确认位置 | 长投处理 |
| --- | --- | --- |
| 非同控控股合并 | 复核后在合并报表确认营业外收入 | 个别报表按适用规则确定初始成本，不因买便宜而调增 |
| 取得联营、合营企业投资，采用权益法 | 个别报表确认营业外收入 | 调增长投至应享有的可辨认净资产公允价值份额 |
| 非同控吸收合并 | 复核后在购买方个别报表确认营业外收入 | 直接确认取得的资产、负债，不形成长投 |

权益法补记差额：

```text
借：长期股权投资—投资成本
  贷：营业外收入
```

权益法初始成本高于应享有份额时不调整成本，差额内含于投资账面价值，不单独列示商誉。

## 08｜权益法确认净损益份额：潜在表决权和优先股股利扣除怎么理解？

**难度**：系统补齐　·　**更新**：2026-09-06

> **速览**：权益法份额不提前计入潜在表决权；归属普通股的利润须先扣除适用的优先股股利。

### 六、权益法确认净损益份额：潜在表决权和优先股股利扣除

判断重大影响，应考虑投资方及其他方当期可转换、可执行的潜在表决权；按权益法计算净损益、OCI 和其他权益变动份额时，不提前计入其对应的权益份额。

例：实际普通股持股 20%，另持有可转换为 10% 股权的可转债，不能直接按假设转换后的 30% 确认投资收益。

### 普通股股东的利润份额

投资收益＝（按权益法要求调整后的净利润－归属于其他股东所持权益类优先股的股利）×实际普通股权益比例。

| 优先股分类 | 应扣金额 |
| --- | --- |
| 权益类、可累计 | 当期应归属股利，无论是否宣告 |
| 权益类、非累计 | 本期已宣告的股利；未宣告不扣 |
| 金融负债 | 相关利息若已扣减净利润，不重复扣除 |

例：净利润已按权益法要求调整为 1,000，权益类优先股当期股利 100，普通股持股 30%。可累计，或非累计且已宣告时，投资收益＝(1,000－100)×30%＝270；非累计未宣告时为 300，单位万元。

```text
借：长期股权投资—损益调整 270（或300）
  贷：投资收益 270（或300）
```

## 09｜权益法超额亏损时，长期应收款、预计负债和备查簿怎么处理？

**难度**：高频易错　·　**更新**：2026-09-06

> **速览**：权益法亏损先冲长投及其他长期权益；额外义务须另行判断，未确认损失按来源备查。

### 七、权益法超额亏损：长期应收款、预计负债和备查簿

确认损失依次冲减长期股权投资、实质上构成净投资的其他长期权益；承担额外损失义务的按义务确认预计负债，其余未确认部分按来源备查。非日常购销形成、无清偿计划且可预见未来不准备收回的长期款项，可能构成其他长期权益；普通应收款不能仅因期限长而纳入。

后续净利润或 OCI 增加时，先弥补备查损失，再恢复其他长期权益、长期股权投资；预计负债依据现时义务重新估计，不能仅按“倒序”自动转回。

### 净亏损与 OCI 的来源不能混记

依《解释第9号》及证监会《会计类第3号》3-2，后续先按本期权益增加的性质确认相应项目，再按本期享有增加净额与未确认损失孰低，补确认原来源的损失。

例：持股 20%，长投账面价值 600，其他长期权益 120，无额外义务，被投资单位亏损 4,000，单位万元。

```text
应分担亏损＝4,000×20%＝800
借：投资收益 720
  贷：长期股权投资—损益调整 600
      长期应收款 120
```

余下 80 登记备查。以下后续情形各自独立，不连续计算：

| 后续 OCI 增加 | 享有份额 | 补确认原损失 | 恢复其他长期权益 | 期末未确认损失 |
| --- | ---: | ---: | ---: | ---: |
| 300 | 60 | 60 | 0 | 20 |
| 800 | 160 | 80 | 80 | 0 |

OCI 增加 300 时：

```text
借：长期股权投资—其他综合收益 60
  贷：其他综合收益 60
借：投资收益 60
  贷：长期股权投资—损益调整 60
```

OCI 增加 800 时，合并列示分录：

```text
借：长期应收款 80
    长期股权投资—其他综合收益 80
  贷：其他综合收益 160
借：投资收益 80
  贷：长期股权投资—损益调整 80
```

两种情形长投净额仍为零；补认原净亏损记投资损失，不是冲减本期 OCI。

### 原损失来自 OCI 的对照

若原来是 OCI 减少 4,000：借 OCI 720，贷长投—OCI 600、长期应收款 120，备查 80。后续 OCI 增加 700，享有 140；先弥补同来源的备查 80，再恢复长期应收款 60。抵并后：

```text
借：长期应收款 60
  贷：其他综合收益 60
```

不能把上述权益法分担亏损的限额，套用于顺流交易未实现收益抵销；后者长投不足抵销部分确认为递延收益，见内部交易一节。

依据：[财政部解释第9号](https://cwfwpt.ggj.gov.cn/zcfg/qykjzd/202306/P020230620600701914763.pdf)、[证监会会计类第3号](https://www.csrc.gov.cn/csrc/c105942/c7056669/content.shtml)。

## 10｜联营企业投资中，风险投资机构等间接持有部分能否不采用权益法？

**难度**：高频易错　·　**更新**：2026-09-06

> **速览**：联营投资通过风投等主体间接持有的部分可选 FVTPL，其余部分仍按权益法。

### 八、联营企业投资中，通过风险投资机构等间接持有部分的 FVTPL 选择

对联营企业投资，其中通过风险投资机构、共同基金、信托公司或包括投连险基金在内的类似主体间接持有的部分，可以选择 FVTPL；其余部分继续采用权益法。该选择不以这些主体自身是否具有重大影响为前提。

本项豁免允许的是 FVTPL，不是 FVOCI，也不允许任意切出普通直接持有部分。

## 11｜合营安排如何区分共同经营和合营企业？

**难度**：高频基础　·　**更新**：2026-09-06

> **速览**：合营企业享有净资产权利；共同经营享有资产权利并承担负债义务。

### 九、合营企业和共同经营的区别

合营安排须有合同约定的共同控制：相关活动决策需要分享控制权的参与方一致同意。

分类依次检查：是否通过单独主体达成 → 单独主体法律形式 → 合同条款 → 其他事实和情况。未通过单独主体达成的为共同经营；通过单独主体达成，也不能仅凭法律外形判为合营企业。

| 分类 | 参与方的权利、义务 | 合营方会计处理 |
| --- | --- | --- |
| 合营企业 | 对安排净资产享有权利 | 确认长期股权投资，采用权益法（适用豁免除外） |
| 共同经营 | 对相关资产享有权利，对相关负债承担义务 | 确认单独持有的资产、单独承担的负债，以及共同项目中自己的份额；确认相关收入、费用 |

例：甲乙共同控制 C 公司，仅享有其剩余净资产权利，通常为合营企业；若合同及实质表明甲乙各享有设备、产出并承担借款等义务的 50%，则按共同经营分别确认。不能把共同经营简化为“一项长投”，也不能机械将所有项目都乘同一个比例。

## 12｜共同经营中，合营方向共同经营出售固定资产的分录怎么做？

**难度**：高频易错　·　**更新**：2026-09-06

> **速览**：共同经营中，未实现资产交易损益按自己份额抵销；业务份额收购适用企业合并相关原则。

### 十、共同经营中合营方向共同经营出售固定资产的分录

对共同经营投出或出售不构成业务的资产，出售给第三方或消耗前，只确认其他参与方享有的损益；转让损失若属于真实减值，全额确认。自共同经营购入资产时，同样延后确认自己的未实现损益份额，但购入资产发生减值按承担份额确认，不能套用投出方全额确认规则。

### 出售设备例

A、B分别享有共同经营40%、60%。A出售设备，原价80、累计折旧20、售价100，忽略税费，单位万元。

```text
借：固定资产清理 60
    累计折旧 20
  贷：固定资产 80
借：银行存款／应收款项 100
  贷：固定资产清理 60
      资产处置损益 40
```

A按共同经营份额确认购入设备，并抵销自己尚未实现的收益(100－60)×40%＝16：

```text
借：固定资产 40
  贷：银行存款／应付款项 40
借：资产处置损益 16
  贷：固定资产 16
```

A最终确认设备24、处置收益24；B确认设备60，无须抵销A让渡给B份额的收益。

### 取得构成业务的共同经营利益份额

取得的组合构成业务时，按企业合并的相关原则处理，但不得与合营安排准则冲突。这里是业务收购，并不表示共同经营成为子公司。

例：支付1,200取得40%利益。可辨认资产、负债公允价值：存货200、固定资产2,000、无形资产300、负债500，净额2,000；取得净额份额800，商誉400。

```text
借：存货 80
    固定资产 800
    无形资产 120
    商誉 400
  贷：相关负债 200
      银行存款 1,200
```

另付审计评估等费用30：借管理费用30，贷银行存款30。例题忽略递延所得税等其他因素，不能将“取得业务份额”与“出售单项资产”混为同一交易。

## 13｜权益法下内部交易不构成业务：收益抵销和减值损失确认怎么理解？

**难度**：系统补齐　·　**更新**：2026-09-06

> **速览**：普通未实现内部交易损益按持股比例抵销；真实减值不抵销。

### 十一、权益法下内部交易不构成业务：收益抵销和减值损失确认

对联营、合营企业的不构成业务交易，普通未实现内部交易利得或损失按投资方享有比例抵销；真实资产减值损失不抵销。分录及计算见第十二节“顺流、逆流、存货和资产交易”。

## 14｜权益法下关联方交易：顺流、逆流、存货和资产交易怎么理解？

**难度**：系统补齐　·　**更新**：2026-09-06

> **速览**：权益法个别报表抵销自己份额的未实现损益，合并报表再按顺逆流调整列报项目。

### 十二、权益法下关联方交易：顺流、逆流、存货和资产交易

本节讨论不构成业务的资产交易，真实减值损失见第十一节“收益抵销和减值损失确认”。顺流为投资方卖给联营、合营企业，逆流方向相反；联营、合营企业不纳入投资方合并范围。

### 个别报表的共同计算

先按通常规则确认买卖，再计算归属投资方的未实现收益：

- 存货：U＝(售价－成本)×期末未对外出售比例×持股比例。
- 折旧、摊销资产：U＝(原内部收益－累计已通过折旧、摊销实现的部分)×持股比例。

当期新增未实现收益，借投资收益、贷长期股权投资—损益调整；以前已抵销收益在本期实现，作相反分录。分录金额为本期调整额，不能每年把期末累计U再全额冲一次。

顺流交易长投不足抵销的部分确认为递延收益，待损益实现再转出；不同于权益法分担被投资方亏损的备查规则。

### 交易当年的合并报表调整

在个别报表已抵销基础上，仅重新安排抵销影响所在项目，不重复减少利润。

| 交易 | 合并层面补充调整 |
| --- | --- |
| 顺流存货 | 借营业收入（内部售价×未出售比例×持股比例），贷营业成本（内部成本×同一比例）、投资收益U |
| 逆流存货 | 借长期股权投资U，贷存货U |
| 顺流固定资产、无形资产 | 借资产处置损益U，贷投资收益U |
| 逆流固定资产、无形资产 | 借长期股权投资U，贷相关资产U；按原价和累计折旧、摊销分别列示时保持净额一致 |

依据：[财政部顺逆流实施问答](https://kjs.mof.gov.cn/zt/kjzzss/sswd/cqgqtzzzsswd/202301/t20230103_3861811.htm)。

### 存货统一例题

持股30%，售价1,000、成本800，期末60%尚未对外出售，单位万元。U＝(1,000－800)×60%×30%＝36。

```text
个别报表（顺流、逆流相同）：
借：投资收益 36
  贷：长期股权投资—损益调整 36

合并报表补充调整（二选一）：
顺流：借：营业收入 180
        贷：营业成本 144
            投资收益 36
逆流：借：长期股权投资 36
        贷：存货 36
```

下一年剩余存货全部对外出售，个别报表恢复投资收益36；顺流合并报表将相应投资收益重新列回原交易收入、成本：借投资收益36、营业成本144，贷营业收入180。这是原被抵销项目的恢复，并非确认一笔新销售。

若逆流下一年只出售原剩余存货的60%，本期个别报表恢复21.6，期末仍未实现14.4；合并报表资产端调整为借长投14.4、贷存货14.4。

### 折旧资产统一例题

甲持股30%，将账面800的设备以1,000出售给联营企业，剩余10年、直线折旧、无残值，第一年按全年计提。第一年末U＝[200－200÷10]×30%＝54。

```text
个别报表：借：投资收益 54
            贷：长期股权投资—损益调整 54
合并补充：借：资产处置损益 54
            贷：投资收益 54
```

第二年折旧实现份额6：个别报表借长投—损益调整6、贷投资收益6；顺流合并层面将投资收益6转回资产处置损益。逆流则调整投资方自身资产期末仍未实现部分。

### 投出资产换取联营、合营企业股权

符合公允价值计量条件时，先按相应准则确定长投初始成本及资产处置损益，再按权益法处理归属于自己的未实现损益，不能因是“增资”就认定个别报表永远不抵销。

例：不构成业务的设备账面600、公允价值1,000，投出后持股30%，交易时尚未消耗：正常初始成本1,000，处置收益400，未实现份额120。权益法抵销借投资收益120、贷长投120；需编合并报表的，再借资产处置损益120、贷投资收益120。剩余5年、直线法、无残值时，每全年折旧实现份额24。

本节跨期恢复指资产对外出售或消耗；因处置、视同处置联营股权而实现的收益，按股权处置投资收益处理，不恢复此前抵销的收入、成本、资产处置损益。

## 15｜丧失控制权后成本法转权益法，完整分录和逻辑怎么理解？

**难度**：高频综合　·　**更新**：2026-09-06

> **速览**：丧控后仍用权益法：个别报表追溯剩余股权，合并报表按丧控日公允价值重计量。

### 十四、成本法转权益法：丧失控制权的完整分录和逻辑

本节前提：丧失控制后，剩余股权仍能施加重大影响或形成共同控制。

| 个别报表第一步 | 投资收益 | 例（万元） |
| --- | --- | --- |
| 主动出售 | 出售价款－出售部分长投账面价值 | 原100%成本600，卖60%收480：借银行存款480，贷长投360、投资收益120 |
| 被动稀释 | 增资额×新比例－原长投×比例下降额÷原比例 | 原60%成本900，增资800后降40%：320－300＝20，净调增长投20、投资收益20 |

第二步，按剩余比例视同取得时即采用权益法：

- 原成本超过取得日净资产公允价值份额的内含商誉不单列；低于份额的差额调整长投及留存收益或当期损益。
- 投资后经调整净利润扣除已宣告股利，按剩余比例调长投—损益调整：以前年度对应留存收益，当年对应投资收益；不得重复计入成本法已确认的股利收益。
- 投资后OCI、其他权益变动，分别调长投对应明细及投资方OCI、其他资本公积。

### 合并报表：视同全部处置，再按公允价值买回剩余股权

丧失控制权时，原子公司不再纳入合并范围。合并报表不照搬个别报表，而是按“全部处置”的思路计算投资收益：

```text
合并报表投资收益
= 出售部分对价 + 剩余股权丧失控制权日公允价值
- 原子公司自购买日持续计算的可辨认净资产账面价值份额
- 商誉
+ 可转损益的其他综合收益、其他资本公积等
```

教材例 6-19 中：

```text
出售 60% 对价 = 480
剩余 40% 公允价值 = 320
乙公司持续计算净资产 = 500 + 75 = 575
商誉 = 100

合并报表投资收益 = 480 + 320 - 575 - 100 = 125（万元）
```

个别报表已经确认投资收益 120 万元，合并报表还需要做两类调整。

#### 1. 剩余股权按公允价值重新计量

剩余 40% 股权在个别报表中的账面价值为：

```text
675 * 40% = 270（万元）
```

丧失控制权日公允价值为 320 万元，因此确认重计量收益 50 万元：

```text
借：长期股权投资 320
  贷：长期股权投资 270
      投资收益 50
```

#### 2. 调整个别报表部分处置收益的归属期间

个别报表确认的 120 万投资收益中，有 45 万其实是以前期间乙公司净资产增加形成的：

```text
乙公司净资产增加 = 净利润 50 + 其他综合收益 25 = 75（万元）
出售 60% 对应金额 = 75 * 60% = 45（万元）
```

合并报表认为，这 45 万不属于本期处置收益，而应归属于以前期间的留存收益和其他综合收益：

```text
借：投资收益 45
  贷：未分配利润 30（50 * 60%）
      其他综合收益 15（25 * 60%）
```

### OCI 转出的特殊处理

合并层面按原归母的全部相关 OCI 处理，不只按本次出售比例；具体去向见第四节来源总表。以下以其他权益工具投资和其他债权投资对照：

例如，原子公司持有其他权益工具投资形成 OCI 25 万元：

```text
借：其他综合收益 25
  贷：利润分配--未分配利润 25
```

如果改为其他债权投资等可转损益项目形成 OCI 25 万元：

```text
借：其他综合收益 25
  贷：投资收益 25
```

### 例题：其他债权投资 OCI 和权益结算股份支付资本公积的转出

甲公司原持有乙公司 90% 股权并控制乙公司。购买日乙公司可辨认净资产公允价值 9,000 万元，甲公司支付 8,100 万元，未形成商誉。

乙公司 2x25 年：

```text
实现净利润 2,400
购买日土地使用权评估增值 1,800，尚可使用 40 年
因其他债权投资公允价值上升确认其他综合收益 500
因权益结算的股份支付确认资本公积 400
```

2x26 年 1 月 1 日，甲公司出售乙公司 50% 股权，取得价款 6,200 万元；剩余 40% 股权公允价值为 4,960 万元。出售后丧失控制权，但仍能施加重大影响。

| 个别报表计算项目 | 金额（万元） |
| --- | ---: |
| 出售部分成本 | 8,100×50%÷90%＝4,500 |
| 处置投资收益 | 6,200－4,500＝1,700 |
| 剩余股权原成本 | 8,100×40%÷90%＝3,600 |
| 购买日净资产公允价值份额 | 9,000×40%＝3,600，与原成本相等，无须调整 |
| 评估增值年摊销 | 1,800÷40＝45 |
| 调整后净利润 | 2,400－45＝2,355 |
| 剩余股权损益调整 | 2,355×40%＝942 |
| 剩余股权其他综合收益 | 500×40%＝200 |
| 剩余股权其他权益变动 | 400×40%＝160 |
| 追溯权益法后长投账面价值 | 3,600＋942＋200＋160＝4,902 |

| 合并报表计算项目 | 金额（万元） |
| --- | ---: |
| 子公司持续计算净资产 | 9,000＋2,355＋500＋400＝12,255 |
| 原归母份额 | 12,255×90%＝11,029.5 |
| 基础处置差额 | 6,200＋4,960－11,029.5＝130.5 |

| 合并报表投资收益 | 130.5＋450＋360＝940.5 |

## 16｜被投资方增资导致持股比例下降但仍采用权益法，原其他综合收益和其他资本公积怎么处理？

**难度**：系统补齐　·　**更新**：2026-09-06

> **速览**：被动稀释后仍用权益法，稀释影响（含内含商誉结转）计入其他资本公积。

### 十三、被投资方增资导致持股比例下降但仍采用权益法

其他股东增资、自己未同比例认购，稀释后仍有重大影响或共同控制的，稀释影响计入资本公积—其他资本公积；原投资内含商誉也按稀释比例结转，不能全部保留。

调整额＝被投资方新增权益×新持股比例－增资前长投账面价值×(原比例－新比例)÷原比例。

若稀释显示减值迹象，应先测试并确认减值（如有），再计算稀释影响。负差额可使其他资本公积出现借方余额，不套用同控合并“不足冲留存”的规则。

### 含商誉及明细调整例

A取得D的20%支付260，取得日可辨认净资产1,000，内含商誉60。以后D实现经调整净利润1,000，A确认损益调整200，长投合计460。其他股东增资800，A被稀释为15%，单位万元。

| 项目 | 计算 |
| --- | --- |
| 新增权益份额 | 800×15%＝120 |
| 被稀释账面价值 | 460×5%÷20%＝115（含商誉15） |
| 资本公积增加 | 120－115＝5 |
| 增资后长投 | 460＋5＝465；亦等于2,800×15%＋60×15%÷20% |
| 长投投资成本明细 | (1,000＋800)×15%＋45＝315，较原260增加55 |
| 长投损益调整明细 | 1,000×15%＝150，较原200减少50 |

```text
借：长期股权投资—投资成本 55
  贷：长期股权投资—损益调整 50
      资本公积—其他资本公积 5
```

长投明细调整与投资方原权益项目结转须区分。[正保教学答疑](https://www.chinaacc.com/wenda/detail/wd/26398417)对被动稀释后仍采用权益法的解释为：原OCI、其他资本公积不结转。实际处置或终止权益法时另按处置规则处理；此处教学解释不等同于下列监管指引关于内含商誉的原文。

联营企业同控合并导致持股比例下降时，以合并日分段：先按重组前利润和原比例确认投资收益，再计算稀释影响，之后按重组后利润和新比例确认。投资方不随联营企业追溯其比较报表。合并日权益净变动按享有份额调整长投和其他资本公积；联营企业恢复历史权益时在资本公积、留存收益、OCI之间的重分类，不另调投资方长投。

依据：[证监会会计类第1号1-3](https://www.csrc.gov.cn/csrc/c105942/c1570917/content.shtml)、[财政部2026年6月18日实施问答](https://kjs.mof.gov.cn/zt/kjzzss/sswd/cqgqtzzzsswd/202606/t20260618_3991863.htm)。

## 17｜不丧失控制权处置子公司部分股权，合并底稿如何处理？

**难度**：高频综合　·　**更新**：2026-09-06

> **速览**：未丧控处置子公司股权为权益交易；按比例把含商誉的归母权益转给少数股东，差额调资本公积。

### 十六、不丧失控制权处置子公司部分股权：合并底稿逻辑

仍控制子公司时，合并层面为母公司与少数股东的权益交易，不确认处置收益，不减少合并资产、负债及商誉总额。

设出售对价为 P，转让的子公司持续计算净资产份额为 A，原归属于母公司的已确认商誉按本次转让比例划转的份额为 B：少数股东权益增加 A＋B，资本公积变动为 P－A－B。B 的比例为“出售股权比例÷出售前母公司持股比例”，不能把已确认的部分商誉再乘一次总股权出售比例。

以出售前合并报表为起点概括整笔交易：

```text
借：银行存款 P
  贷：少数股东权益 A＋B
      资本公积—资本溢价 P－A－B
```

负差额借记资本公积，不足冲减留存收益。

若以已入账的母公司个别报表为底稿起点，设已结转长投成本为 C：借记投资收益 P−C、借记长期股权投资 C，贷记资本公积 P（P＜C 时投资收益改记贷方）。按原持股比例完成常规合并抵销，再把 A＋B 从母公司资本公积转入少数股东权益。收款已入账，不再借记银行存款。

依据：[证监会2024年年报会计监管报告](https://www.csrc.gov.cn/csrc/c100028/c7577643/content.shtml)第二部分第六项明确要求按比例转移包含商誉的归母权益。
