## 01｜总额列报原则下，哪些净额列示不属于抵销？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：区分类似交易利损、备抵扣减及非日常同一交易净损益；这些净额列示不等于资产负债互抵。

### 一、总额列报原则与不属于抵销的净额列示

**列报版本：**本章现有项目名称及例题按尚未执行2026年修订列报准则的口径整理。新准则适用日期：境内外同时上市，以及境外上市并采用国际财务报告会计准则或企业会计准则编报的企业为2027年1月1日；其他境内上市企业为2029年1月1日；执行企业会计准则的非上市企业为2030年1月1日，均可提前执行。首次执行须相应调整列报和比较数据（不切实可行的除外），首年披露最近可比期间利润表项目调节信息。依据：[财会〔2026〕11号通知及第68—69条](https://kjs.mof.gov.cn/zhengcefabu/202608/t20260805_3994927.htm)。

财务报表原则上按总额列报，资产与负债、收入与费用不得相互抵销，准则另有规定的除外。下列净额列示不属于抵销：

| 情形 | 列示与例题 |
| --- | --- |
| 一组类似交易形成的利得和损失，具有重要性的除外 | 公允价值变动收益100、损失30，净收益70；重要项目不得被净额掩盖 |
| 资产或负债扣除备抵项目 | 如应收账款扣减坏账准备，是本项目的计量，不是资产负债互抵 |
| 非日常活动中，同一交易的收益扣减相关费用更能反映实质 | 固定资产售价100、账面价值80、清理费5，不考虑税项时，处置收益＝100－80－5＝15 |

**边界：**“准则允许抵销”与“本来不属于抵销”是不同情形。不能仅以业务非主营或发生偶然，就将不同交易的收入费用任意轧差；金融资产负债抵销仍须满足金融工具列报准则的条件。

## 02｜预计负债和可转换工具负债成分如何判断流动性列报？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：质保预计负债按适用条件拆分列报；单独确认为权益的转股选择权不影响负债成分的流动性。

### 二、预计负债和可转换工具负债成分的流动性列报

负债流动性按正常营业周期、交易目的、到期日及资产负债表日存在的推迟清偿权利等条件判断；仅预计以后才付款，不等于具备推迟清偿的权利。

### 保证类质量保证

账务仍按预计负债核算，例如：

```text
借：销售费用
    贷：预计负债
```

以下列报规则适用于**期限超过一年或一个营业周期**的保证类质量保证：

| 预计清偿情况 | 报表项目 |
| --- | --- |
| 能合理预计未来一年或一个营业周期以内清偿的部分 | 一年内到期的非流动负债 |
| 其余部分 | 预计负债 |
| 不能合理预计未来一年或一个营业周期以内清偿的金额 | 全部列其他流动负债 |

不能仅凭账上科目名决定列报，也不能将此特殊规则扩展为所有预计负债均无法拆分就全列流动。

### 可转换工具的负债成分

持有人可选择以企业自身权益工具结算，且选择权按金融工具列报准则分类为权益工具、作为复合金融工具的权益组成部分单独确认的，该条款不影响负债流动性划分。

仍须根据负债其他条款判断资产负债表日是否具有将清偿推迟至一年以上的实质性权利；企业是否打算行使该权利不改变分类。不能仅因可能转股就把负债列为流动，也不能把任何股份结算选择权都当作这一例外。

## 04｜预收购物卡、保洁服务和租金，如何区分负债项目与税额？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：准则范围决定合同负债或预收款项，纳税义务时点决定税额处理；租金不列合同负债，也不等于含税全列预收款。

### 四、预收购物卡、保洁服务和租金的报表项目列报

先区分准则范围，再判断增值税纳税义务：购物卡及保洁服务按收入准则列合同负债；经营租赁预收租金列预收款项，不能因此忽略租赁增值税。

### 例题：按2025年规则分析

百货商场1—2层自营，3—5层出租并提供保洁。12月31日售出一年有效期购物卡收56.5万元；预收下一年租金及服务费106万元，其中保洁10.6万元。金额均含税，一般计税税率分别为商品13%、保洁6%、租赁9%。假定当日尚未消费或开始提供租赁、保洁，未提前开具应税发票，无其他抵扣、缴税事项；购物卡与保洁按题设拆列未来税额。

| 项目 | 计算（万元） | 列报 |
| --- | --- | --- |
| 购物卡 | 56.5÷1.13＝50；未来税额6.5 | 合同负债50，其他流动负债6.5 |
| 保洁 | 10.6÷1.06＝10；未来税额0.6 | 合同负债10，其他流动负债0.6 |
| 经营租赁 | 含税款106－10.6＝95.4；不含税95.4÷1.09＝87.52；销项税7.88 | 预收款项87.52；已发生纳税义务的租赁税额计入应交税费，不并入待转销项税额 |

合计：预收款项87.52、合同负债60、其他流动负债7.1、租赁销项税7.88，合计162.5＝56.5＋106。应交税费项目最终余额还须结合实际抵扣、缴纳等情况确定。

预计购物卡放弃使用5%，对应不含税金额50×5%＝2.5万元；尚未消费时不提前确认该收入。符合预计未行使权利确认条件的，随客户行使权利的模式确认，详细规则见收入章。因此本例营业收入为0。

**期间边界：**本例按2025年租赁预收款收取日发生纳税义务的规则。2026年起服务预收价款的纳税时点规则已调整，须结合首次服务开始日、合同约定日及开票等事实重新判断，不能直接沿用本例时点结论。“租金未计入待转税额”不等于“租金不用拆税”。

## 06｜银行承兑汇票贴现取得现金，现金流量表列经营还是筹资？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：经营性票据贴现先看终止确认：终止列经营，不终止列筹资；后续无现金收付不虚列现金流。

### 六、银行承兑汇票贴现的现金流量表分类

以销售商品、提供服务取得的经营性票据为例：

| 贴现及后续事项 | 现金流量处理 |
| --- | --- |
| 满足金融资产终止确认条件 | 经营性应收票据变现，列经营活动现金流入 |
| 不满足终止确认条件 | 收款实质为借款，列筹资活动现金流入 |
| 后续票据到期、应收票据和借款结清，但企业未收付现金 | 不虚拟现金流入、流出 |

票据是否终止确认按金融资产转移准则判断，不能仅凭银行承兑或商业承兑名称决定。若票据源于投资活动等其他业务，终止确认后的现金流还须结合业务性质，不能把“终止即经营”推广至所有票据。

## 07｜以银行承兑汇票背书购买原材料，是否属于经营活动现金流出？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：票据背书采购未发生现金及现金等价物收付，不虚列经营现金流；另有实际现金支付的部分单独判断。

### 九、银行承兑汇票背书购买原材料的现金流量表处理

## 08｜定期存单质押和解除质押，什么时候产生现金流量？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：存单质押先判断现金等价物范围是否变化，再按行业与业务性质分类；不是见质押就列现金流。

### 七、定期存单质押和解除质押的现金流量表分类

先判断存单是否属于现金及现金等价物，再判断质押是否使其退出该范围。原本不属于的，单纯质押、解除质押均不产生现金流；原本属于的，质押后不再符合定义形成流出，解除后重新符合定义形成流入。

### 一般非金融企业例

12月1日将1000万元转为3个月期定期存单，题设该存单流动性强、易于转为已知现金且价值变动风险很小，符合现金等价物定义。12月20日以其质押借入800万元，质押后不能自由支取支付。忽略利息及费用。

| 事项 | 分类及金额（万元） |
| --- | --- |
| 购入该存单 | 现金与现金等价物内部转换，不列现金流 |
| 借入800 | 筹资流入800 |
| 质押使存单退出现金等价物范围 | 筹资流出1000 |
| 实际偿还借款800 | 筹资流出800 |
| 解除质押并重新符合现金等价物定义 | 筹资流入1000 |

## 11｜关联方关系如何系统判断？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：先识别控制、共同控制、重大影响与人员关系，再区分同一方连接的企业和共同投资者。

### 十一、关联方关系的认定框架

按控制、共同控制、重大影响及人员关系判断，不能仅凭持股比例或交易规模认定。

| 对象 | 关联范围及边界 |
| --- | --- |
| 控制关系 | 母公司、子公司、同受一方控制的企业，包括间接控制链条 |
| 共同控制、重大影响 | 对本企业实施共同控制或重大影响的投资方；本企业的合营、联营企业及其子公司 |
| 个人 | 主要投资者个人、本企业或其母公司的关键管理人员及关系密切家庭成员；本企业主要投资者个人、关键管理人员及其关系密切家庭成员控制、共同控制或重大影响的其他企业 |
| 特殊主体 | 本企业设立的企业年金基金；关键管理人员服务提供方。接受方将提供方作为关联方，提供方对接受方则按其他关联条件判断 |

主要投资者个人须能控制、共同控制或重大影响企业；关键管理人员须有权且负责计划、指挥、控制企业活动。关系密切家庭成员指在与企业交易时可能影响该个人或受其影响者。

### 同一企业A连接B、C的横向关系

| A对B、C的关系 | B、C是否关联 |
| --- | --- |
| 控制＋控制、控制＋共同控制、控制＋重大影响 | 是 |
| 共同控制＋共同控制、共同控制＋重大影响 | 是 |
| 重大影响＋重大影响 | 仅凭此关系不构成 |

集团边界及集团成员的联营企业案例见第十三节。上述横向关系不能反过来推断投资者彼此关联：A、B、C共同控制D，或分别对D有重大影响，投资者之间不因此自动关联。

### 持股与人员例题

甲持乙80%、持丙10%，乙持丙15%；丁向甲提供关键管理人员服务。题设简化为：低于20%无控制、共同控制或重大影响，20%至50%为重大影响，超过50%为控制。

| 关系 | 判断依据 |
| --- | --- |
| 甲与乙 | 甲控制乙 |
| 甲与丙 | 甲通过受控乙支配其15%表决权，加直接10%＝25%，形成重大影响；不按80%×15%计算 |
| 甲总经理的妻子与乙 | 属于乙母公司的关键管理人员的关系密切家庭成员 |
| 甲与丁 | 甲作为服务接受方，将丁列为关联方 |

比例是本题假设，实际仍须判断权力及参与决策的事实。

### 仅有以下关系，不足以认定

- 日常往来的资金提供者、公用事业部门、政府部门或机构；大量交易形成经济依存的客户、供应商、特许商、经销商或代理商。
- 仅有同一位关键管理人员的企业。投资者之间及同受重大影响企业的判断见上文横向关系。
- 仅同受国家控制，且不存在其他关联方关系的企业。

以上均以无其他关联关系为前提。披露要求统一见第十二节。

## 12｜编制合并报表时，与合并范围外关联方的交易还要披露吗？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：合并范围内交易不作关联交易披露，范围外关联交易仍披露；另行判断权益法调整。

### 十二、合并报表中与合并范围外关联方的交易披露

母子公司有关信息无论是否发生交易均须按规定披露；发生关联方交易时，披露关系性质、交易类型及交易要素。

甲控制乙，对丙具有重大影响；甲编制合并报表时，甲、乙纳入合并范围，丙为范围外联营企业。

| 交易 | 合并报表中的关联方交易披露 |
| --- | --- |
| 甲与乙 | 合并范围内企业之间的交易，不作为关联方交易披露 |
| 甲与丙、乙与丙 | 集团与范围外关联方的交易，仍须披露 |

“不披露内部关联交易”限于合并报表，不能据此免除个别报表的披露。范围外联营、合营企业不作子公司式全额合并抵销，但适用权益法的未实现内部交易损益仍按长期股权投资等准则调整；披露与计量调整分别判断。

## 13｜企业集团内成员单位的联营企业之间，是否自动构成关联方？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：集团按控制圈定，成员与其他成员的联营、合营企业关联，两个联营企业不自动关联。

### 十三、企业集团边界与集团成员联营企业之间的关联方判断

企业集团按控制关系圈定。集团成员与其他成员的合营、联营企业构成关联方；同一投资方连接两家被投资企业的判断见第十一节横向关系表。

例：甲控制乙、丙；乙对丁有重大影响，丙对戊有重大影响。集团成员为甲、乙、丙，丁、戊不因联营关系成为集团成员。

| 关系 | 是否关联及依据 |
| --- | --- |
| 甲与丁 | 是，丁是集团成员乙的联营企业 |
| 乙与丙 | 是，同受甲控制 |
| 丙与丁 | 是，丁是同一集团另一成员乙的联营企业 |
| 丁与戊 | 仅凭上述关系不构成，两家联营企业不会因各自投资方同属集团而自动关联 |

准则所称联营、合营企业包括其子公司；这种控制链延伸不意味着联营关系可以无限传递。

## 14｜年度财务报告和中期财务报告有哪些关键差异？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：中期按年初至期末累计计量；比较报表分时点、单期和累计，不能为平滑结果提前确认。

### 十四、年度财务报告与中期财务报告的组成和计量差异

| 项目 | 年度报告 | 中期报告 |
| --- | --- | --- |
| 最低组成 | 资产负债表、利润表、现金流量表、所有者权益变动表及附注 | 资产负债表、利润表、现金流量表及附注；三张表为完整报表，附注可重点说明重大变化 |
| 会计政策 | 按适用准则 | 与年度一致；年度将采用的政策变更，中期也应采用并按规定追溯处理 |
| 重要性 | 以年度财务数据判断 | 以中期财务数据判断，计量可更多依赖可靠估计 |
| 季节性、周期性、偶然性收入与不均匀费用 | 按准则确认 | 不得为平滑结果提前或递延；年度末允许预计、递延、预提或待摊的除外 |
| 所得税费用 | 按年度情况计算 | 通常按预计年度平均实际税率计算 |

中期计量以年初至本中期末为基础，报告频率不得改变年度结果。以前中期的估计在以后中期变更，反映在以后中期，不重编以前中期，并按规定披露。估计涉及存货、所得税、奖金、返利、质量保证、减值和预计负债等，不等于免做必要核实。

### 比较期间：以2×25年第三季度报告为例

| 报表 | 本期口径 | 上年比较口径 |
| --- | --- | --- |
| 资产负债表：本中期末对上年度末 | 2×25.9.30 | 2×24.12.31 |
| 利润表：本中期 | 2×25.7.1—9.30 | 2×24.7.1—9.30 |
| 利润表：年初至中期末 | 2×25.1.1—9.30 | 2×24.1.1—9.30 |
| 现金流量表：年初至中期末 | 2×25.1.1—9.30 | 2×24.1.1—9.30 |

半年报本中期与累计均为1—6月；第二季度报告本中期为4—6月、累计为1—6月。

### 履约进度确认与平滑收入

工程合同满足时段履约条件，履约进度能够合理确定，且假定交易价格1,000万元全部分配给该履约义务、无其他调整：截至6月30日已履约40%，累计收入＝1,000×40%＝400万元，属于正常确认。若已履约0%，仅预计全年完成60%，不能提前确认600万元。

## 15｜现金流量表投资活动各项目怎么填列？

### 十五、现金流量表投资活动项目填列

以下按一般非金融企业说明。投资活动包括长期资产购建及非现金等价物投资的取得、处置；属于现金等价物的投资与现金之间转换，不列现金流量。金融企业应结合行业特点分类。

| 项目 | 填列内容 | 易错点 |
| --- | --- | --- |

| 取得投资收益收到的现金 | 现金股利、利润分配、债权投资利息收入等实际收到的现金 | 股票股利不产生现金流量 |

| 收到其他与投资活动有关的现金 | 其他投资活动现金流入 | 金额较大的，应单独列示 |

| 投资支付的现金 | 购买交易性金融资产、债权投资、其他债权投资、其他权益工具投资、长期股权投资等支付的现金，以及相关佣金手续费 | 不包括取得子公司及其他营业单位支付的现金净额 |

| 支付其他与投资活动有关的现金 | 其他投资活动现金流出 | 金额较大的，应单独列示 |

取得、处置子公司净额项目按合并报表取得或丧失控制权的情形判断；未丧失控制权处置部分股权等权益交易，不套用处置子公司投资现金流项目。单项长期资产处置净额为负时，也转列“支付其他与投资活动有关的现金”。

## 17｜汇率变动影响和现金流量表补充资料怎么理解？

**难度**：高频提高　·　**更新**：2026-09-07

> **速览**：汇率影响单列调节；附注解释利润与经营现金流差异及重大非现金交易。

### 十七、汇率变动影响与现金流量表补充资料

### 汇率调节

外币及境外子公司现金流量用发生日即期汇率，或按系统合理方法确定的近似汇率折算；期末外币现金及现金等价物用期末即期汇率折算。

汇率影响额＝期末现金及现金等价物折算余额－期初折算余额－经营、投资、筹资现金流量净额合计。

该差额单列为调节项目，不是三类活动新增的现金收支。现金及现金等价物须与资产负债表相关项目勾稽，不能直接等同于“货币资金”总额。

### 附注与补充资料

| 内容 | 核心要求 |
| --- | --- |
| 净利润调节为经营活动现金流量 | 调整非现金项目、非经营损益及经营性资产负债变动，见下表 |
| 重大非现金投资和筹资活动 | 披露不涉及当期现金收支，但影响财务状况或未来现金流的交易 |
| 现金及现金等价物净变动 | 披露构成及资产负债表对应金额，并说明不能由母公司或集团其他子公司使用的大额现金及现金等价物 |
| 取得、处置子公司及其他营业单位 | 附注按总额披露价款、现金支付部分、取得或处置单位的现金，以及主要类别非现金资产负债；主表净额列示不免除附注披露 |

| 从净利润调整的项目 | 方向与边界 |
| --- | --- |
| 已计入损益的折旧、摊销、减值等非现金费用 | 加回；转回或收益相应扣除，不能把未影响净利润的数额再加一次 |
| 投资收益、长期资产处置损益等非经营损益 | 收益扣除、损失加回；财务费用只调整其中应剔除的部分，不整项机械加回 |
| 经营性资产负债变动 | 通常存货、经营应收减少加回，经营应付增加加回，反向则扣除；排除非经营和其他非现金变动影响，避免重复调整 |

调节表的终点为经营活动现金流量净额，不重新列入投资、筹资活动现金收支。
