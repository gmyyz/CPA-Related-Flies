## 01｜货币性资产怎么判断，为什么预付账款不算？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：货币性资产看固定或可确定资金收取权；采购预付款通常收货，确定退款权需另行判断。

### 一、货币性资产与预付账款

货币性资产是持有的货币资金，以及收取固定或可确定金额货币资金的权利；其他资产为非货币性资产。判断看权利实质，不看账面金额是否确定。

| 项目 | 判断依据 |
| --- | --- |
| 现金、银行存款 | 已持有的货币资金 |
| 应收账款、应收票据、其他应收款、债权投资等 | 若代表收取固定或可确定金额资金的权利，属货币性资产 |
| 用于取得商品、服务的预付账款 | 收回的是商品或服务，通常属非货币性资产；若合同变化形成确定的现金退款权，应重新判断 |

预付100万元采购材料：

```text
借：预付账款 100
  贷：银行存款 100
```

该100万元代表收取材料的权利，不因付款金额确定就成为货币性资产。

## 02｜不适用非货币性资产交换准则时，是不是只看换入资产？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：按交易性质及具体资产适用规则判断；存货换客户资产、企业合并、金融和租赁资产、权益性交易各有条件。

### 二、非货币性资产交换的适用范围

本准则规范主要以固定资产、无形资产、投资性房地产、长期股权投资等非货币性资产进行，且不涉及或只涉及少量货币性资产（补价）的交换。先识别交易性质，再判断具体资产适用的规则。

| 情形 | 适用范围与边界 |
| --- | --- |
| 以存货换取客户的非货币性资产 | 适用收入准则；不能省略“客户”条件，把所有换出存货的交易都当销售收入 |
| 涉及企业合并 | 适用企业合并、长期股权投资、合并财务报表准则；股权参与交换的分类及业务判断统一见第10节 |
| 涉及金融工具准则规范的金融资产 | 该金融资产的确认、终止确认及计量按金融工具和金融资产转移准则处理；不等于其余非金融资产一律排除本准则 |
| 涉及租赁准则规范的使用权资产、应收融资租赁款等 | 相关资产的确认、终止确认及计量按租赁准则处理 |
| 一方直接或间接持有另一方股权，且以股东身份交易 | 按权益性交易规定处理 |
| 双方受同一方或相同多方最终控制，且交换实质为权益分配或投入 | 按权益性交易规定处理；仅有共同控制关系不够 |

金融资产可能是非货币性资产，例如股权工具；“非货币性”分类与适用哪项准则是两个判断，不能相互替代。

## 03｜什么时候用公允价值计量，什么时候用账面价值计量？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：有商业实质且至少一方公允价值可靠才用公允价值；双方均可靠时原则以换出为基础。

### 三、公允价值与账面价值计量的选择

| 条件 | 计量基础 |
| --- | --- |
| 有商业实质，且换入或换出资产至少一方公允价值可靠 | 公允价值 |
| 无商业实质，或双方公允价值均不能可靠计量 | 账面价值，不确认交换损益 |

双方公允价值均可靠时，以换出资产公允价值为基础；有确凿证据证明换入资产公允价值更加可靠的，才改以换入资产为基础。商业实质的具体判断见后文，不能仅凭资产名称不同推定。

例：设备账面价值80万元、公允价值100万元，换入无形资产公允价值不能可靠计量，但交换有商业实质。仍以设备公允价值为基础；假设不含补价和相关税费且满足确认/终止确认条件，换入成本100万元，换出设备损益20万元。

## 04｜以换入公允计量和以换出公允计量时，换出资产处置损益怎么确认？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：多项换出按各项对价分别确认损益；换入公允价值更可靠时，按换出公允价值相对比例分摊对价。

### 四、单项和多项换出资产的处置损益

处置损益＝归属于换出资产的处置对价－其账面价值。以下先不考虑增值税等税费；涉及税费的计算见后续专题。

| 公允价值基础 | 换出资产损益 |
| --- | --- |
| 以换出资产公允价值为基础 | 各项公允价值减各自账面价值，在各项终止确认时计入损益 |
| 换入资产公允价值更加可靠 | 处置对价总额＝换入公允价值总额－支付补价公允价值＋收到补价公允价值；多项换出时，按各项换出公允价值的相对比例分摊该总额，再减各自账面价值 |
| 账面价值计量 | 各项换出资产均不确认交换损益 |

设备A公允价值100、账面价值70；设备B公允价值200、账面价值160。以换出公允价值为基础时，A损益100－70＝30，B损益200－160＝40，共70（金额单位一致）。

多项换出的分摊依据为准则第10条；缺少必要分摊资料时，不能自行编造单项对价。

## 05｜涉及补价时，怎么判断是否仍属于非货币性资产交换？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：少量补价通常以低于25%判断；区分资产价差与含税现金结算，甲乙设备例双方均20%。

### 五、补价比例：是否仍属于非货币性资产交换

按[2019年应用指南“定义”部分（转载）](https://www.webtax.com.cn/articles/147370)，通常以补价占整个资产交换金额的比例**低于25%**判断“少量”；达到25%不属此范围。以下为不含税、无其他结算差额的情形：

| 立场 | 比例 |
| --- | --- |
| 支付方 | 支付补价÷（换出资产公允价值＋支付补价） |
| 收取方 | 收到补价÷换出资产公允价值 |

甲换出设备公允价值100万元，换入乙设备公允价值80万元，收到20万元：甲20÷100＝20%；乙20÷(80＋20)＝20%，均低于25%。有现金不自动排除，仍须同时检查适用范围等条件。

涉及增值税等结算款时，先分清资产价差补价与税额差额，保持分子、分母口径一致，不能将所有银行收付直接套入上述不含税比例。

## 06｜涉及增值税、补价和相关税费时，换入资产成本和分录怎么做？

**难度**：高频综合　·　**更新**：2026-09-07

> **速览**：按计量基础计算成本，现金结算与税额差分清口径；保留三例97/123/64.6成本及10/20/0损益。

### 六、增值税和相关支出的成本计算

以下“现金净支付”指与交换对手实际结算的现金（支付为正、收到为负，包含所结算税额差额），不含另付安装等支出；资产公允价值不含增值税。切勿先剔除现金中的税差后又在公式重复加减税额。

| 计量基础 | 换入资产成本 |
| --- | --- |
| 换出公允价值 | 换出公允价值＋销项税额－可抵扣进项税额＋现金净支付＋应资本化相关支出 |
| 换入公允价值更可靠 | 换入公允价值＋应资本化相关支出；不得抵扣的进项税按适用规定计入成本 |
| 换出账面价值 | 换出账面价值＋销项税额－可抵扣进项税额＋现金净支付＋应资本化相关支出 |

可抵扣进项税单独确认；使设备达到预定可使用状态的必要安装、运输等支出计入成本，其可抵扣进项税不重复资本化。公允价值模式的换出损益按第4节确定，账面价值模式不确认交换损益。

### 七、三种计量基础的含税结算例

以下金额单位一致，均以换出旧设备取得新设备。题设进项税可全额抵扣；安装费为应资本化净额，无另需列示的税额；忽略减值及其他事项。安装完成达到预定可使用状态，以下为合并列示分录；实际需安装期间可先记在建工程。税额为题设，不作为现行适用税率说明。

| 资料 | 例1：换出公允可靠、有商业实质 | 例2：换入公允可靠、换出不可靠，有商业实质 | 例3：无商业实质 |
| --- | --- | --- | --- |
| 换出原价/累计折旧/账面价值 | 150/60/90 | 130/50/80 | 100/40/60 |
| 换出公允价值 | 100 | 不可靠 | 不用于会计计量 |
| 换出销项税额 | 13 | 13 | 9.1 |
| 换入公允价值 | 95 | 120 | 不用于会计计量 |
| 可抵扣进项税额 | 12.35 | 15.6 | 7.8 |
| 向对手现金结算 | 收到5.65 | 支付22.6 | 支付1.3 |
| 另付安装费 | 2 | 3 | 2 |
| 换入成本 | 100＋13－12.35－5.65＋2＝97 | 120＋3＝123 | 60＋9.1－7.8＋1.3＋2＝64.6 |
| 换出损益 | 100－90＝10 | 120＋15.6－13－22.6－80＝20 | 0 |

例2销项税额是题设税务金额，不能据此直接证明换出资产会计公允价值可靠。例3虽有增值税结算，仍不确认会计交换损益。

```text
例1：
借：固定资产 97
    应交税费——应交增值税（进项税额） 12.35
    银行存款 5.65
    累计折旧 60
  贷：固定资产 150
      应交税费——应交增值税（销项税额） 13
      银行存款 2
      资产处置损益 10

例2：
借：固定资产 123
    应交税费——应交增值税（进项税额） 15.6
    累计折旧 50
  贷：固定资产 130
      应交税费——应交增值税（销项税额） 13
      银行存款 25.6
      资产处置损益 20

例3：
借：固定资产 64.6
    应交税费——应交增值税（进项税额） 7.8
    累计折旧 40
  贷：固定资产 100
      应交税费——应交增值税（销项税额） 9.1
      银行存款 3.3
```

例2现金合计22.6＋3＝25.6，例3为1.3＋2＝3.3。例1实际现金差5.65中，设备价差为5、增值税差为0.65；比例判断与成本结算公式勿混用。

例2若仅将旧设备账面价值改为70，换入成本123和现金25.6不变，处置损益增加10至30；分录只调整旧设备原价、累计折旧及处置损益。

## 07｜同时换入或换出多项资产时，入账金额和处置损益怎么分摊？

**难度**：高频提高　·　**更新**：2026-09-07

> **速览**：先分交换对价、再加归属税费；换入公允更可靠时直接计量，账面模式的分摊优先公允比例。

### 八、换入多项资产的成本分摊

先确定待分摊的交换对价，再分配，最后分别加上应归入各项资产的相关税费；可直接归属于某项资产的安装等支出，不先混入共同分摊池。

| 计量基础 | 分摊顺序 |
| --- | --- |
| 换出公允价值 | 换出公允价值总额＋支付补价公允价值－收到补价公允价值，先扣除换入金融资产公允价值；其余按换入非金融资产公允价值相对比例分配 |
| 有确凿证据表明换入公允价值更加可靠 | 直接以各项换入资产公允价值加相关税费确定初始金额 |
| 账面价值 | 换出账面价值总额＋支付补价账面价值－收到补价公允价值，按各项换入资产公允价值相对比例分配；换入公允价值不可靠时，改用其原账面价值相对比例或其他合理比例 |

## 08｜非货币性资产交换中的商业实质怎么判断？

**难度**：高频基础　·　**更新**：2026-09-07

> **速览**：商业实质看现金流风险、时间或金额显著变化，或现值差额重大；资产类别不能代替判断。

### 九、商业实质：现金流量是否显著改变

满足下列任一条件即可：

1. 换入资产未来现金流量的风险、时间分布或金额与换出资产显著不同。
2. 使用换入资产与继续使用换出资产的预计未来现金流量现值不同，且差额相对换入、换出资产公允价值是重大的。

| 比较维度 | 理解例 |
| --- | --- |
| 风险 | 稳定出租资产换入高风险研发设备，现金流不确定性显著变化 |
| 时间分布 | 短期回款资产换为长期逐步产生现金流的资产 |
| 金额 | 换入资产预计收益能力明显提高，现金流规模显著变化 |

这些例子仍需题目信息支持。“不同类别”不自动有商业实质，“同类设备”也不自动没有；看实际用途、产能、风险及现金流变化。商业实质仅是公允价值计量条件之一，还须满足第3节的可靠计量要求。

## 09｜股权投资参与非货币性资产交换时，哪些适用非货币性资产交换准则？

**难度**：高频易错　·　**更新**：2026-09-07

> **速览**：股权交换先判断控制、业务及投资性质，再衔接合并、长投或金融工具规则。

### 十、股权参与交换的判断

| 换入权益性质 | 处理重点 |
| --- | --- |
| 取得控制，且取得组合构成业务 | 按企业合并、长期股权投资等准则；若不构成业务，另按资产购买等适用规定，不能只凭控股套企业合并 |
| 取得共同控制或重大影响，属于长期股权投资 | 不因取得合营/联营投资就构成企业合并；符合本准则范围的，以非货币性交换规则确定初始成本，再按长投准则衔接 |
| 不具有控制、共同控制或重大影响的普通股权 | 作为金融资产按金融工具准则处理；判断权力看实质，不只看持股比例 |
