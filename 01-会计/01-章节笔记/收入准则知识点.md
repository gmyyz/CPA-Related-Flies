## 一、收入确认五步法总览

### 核心结论

收入确认的核心时点是：客户取得相关商品或服务控制权时。

取得控制权可以简单抓三个要素：

```text
1. 现时权利；
2. 主导使用；
3. 获得几乎全部经济利益。
```

其中，“现时权利”强调客户现在已经有能力控制该商品，不是未来才可能控制；“获得几乎全部经济利益”强调商品带来的主要好处基本归客户。

### 判断逻辑

收入准则下，企业履行履约义务，本质上就是向客户转让商品或服务的控制权。

所以同一件事可以从两个角度理解：

```text
卖方角度：企业已经履行履约义务；
买方角度：客户已经取得控制权；
会计结果：企业确认收入。
```

判断收入确认时点时，不要只看发货、开票或收款，而要看客户是否已经取得控制权。

### 易错点

一是“现时权利”和“经济利益”不是同一个判断点。

```text
现时权利：看客户现在有没有控制商品的权利和能力；
经济利益：看商品带来的主要好处是否基本归客户。
```

二是发货、开票、收款都不必然等于收入确认。

如果客户尚未取得控制权，即使企业已经收款，也可能只是确认合同负债，而不是确认收入。

### 记忆口诀

```text
确认收入看控制，
控制抓三点：
现在能支配，
使用能主导，
好处基本拿走。
```

## 二、合同成立五条件的快速理解

### 核心结论

收入准则下，只有同时满足合同成立的五个条件，企业才按收入准则进行后续的收入确认和计量。

五个条件可以压缩成一句话：

```text
双方真要干，东西和钱说清楚，这事有商业意义，钱大概率收得回。
```

对应五个关键词：

```text
1. 批准并承诺履行；
2. 权利明确；
3. 付款条款明确；
4. 有商业实质；
5. 对价很可能收回。
```

### 判断逻辑

| 条件 | 快速理解 | 判断重点 |
| --- | --- | --- |
| 批准并承诺履行 | 双方都认可合同，并准备按合同办 | 不是草稿、意向书或随便说说 |
| 权利明确 | 双方知道各自能得到什么 | 卖什么、买什么、双方权利义务清楚 |
| 付款条款明确 | 钱怎么算、怎么付、什么时候付大致清楚 | 价格、结算方式、付款时间等清楚 |
| 有商业实质 | 交易会真实改变企业未来现金流 | 现金流金额、时间或风险会变化 |
| 对价很可能收回 | 企业判断客户大概率会付款 | 看客户支付能力和支付意愿 |

### 易错点

第二点、第三点和第五点容易混。

```text
权利明确：讲商品或服务，重点是卖什么、买什么。
付款条款明确：讲合同怎么收钱，重点是多少钱、怎么付、何时付。
对价很可能收回：讲客户能不能、愿不愿付钱，重点是信用和回款可能性。
```

“付款条款明确”不等于“钱一定能收回”。

合同可以把价款和付款时间写得很清楚，但如果客户明显没有支付能力，仍然可能不满足“对价很可能收回”。

“有商业实质”强调真实经济影响。如果交易只是为了做账、互相走形式，未来现金流没有实质变化，就不满足这一条件。

### 记忆口诀

```text
批、权、款、商、收。
```

也可以记成：

```text
批了合同，定了权；
说清款项，有商业；
钱能收回，才算数。
```

## 三、履行履约义务与取得控制权的关系

### 核心结论

“企业履行了履约义务”和“客户取得了控制权”，在收入确认中通常是同一件事的两个角度。

```text
企业履行履约义务
= 商品或服务控制权转移给客户
= 客户取得控制权
= 企业确认收入
```

### 判断逻辑

履约义务是企业向客户转让商品或服务的承诺。

因此，企业什么时候算履行了履约义务，关键看客户什么时候取得该商品或服务的控制权。

如果履约义务是在某一时点履行，则在控制权转移的那个时点确认收入。

如果履约义务是在某一时段内履行，则随着履约进度确认收入。

### 易错点

不要把“履约义务完成”理解成企业自己内部已经做完工作。

收入确认关注的是控制权是否已经转移给客户，而不是企业是否已经生产完成、发出商品、开具发票或收到款项。

### 记忆口诀

```text
卖方说履约，
买方说控制；
本质是一件事，
收入看控制转移。
```
