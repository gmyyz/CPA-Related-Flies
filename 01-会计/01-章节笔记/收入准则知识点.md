## 一、收入确认五步法总览

### 核心结论

收入确认的核心时点是：客户取得相关商品或服务控制权时。

取得控制权可以简单抓三个要素：

```text
1. 现时权利；
2. 主导使用；
3. 获得几乎全部经济利益。
```

其中，“现时权利”强调客户现在已经有能力控制该商品，不是未来才可能控制；“获得几乎全部经济利益”强调商品带来的主要好处基本归客户。

### 判断逻辑

收入准则下，企业履行履约义务，本质上就是向客户转让商品或服务的控制权。

所以同一件事可以从两个角度理解：

```text
卖方角度：企业已经履行履约义务；
买方角度：客户已经取得控制权；
会计结果：企业确认收入。
```

判断收入确认时点时，不要只看发货、开票或收款，而要看客户是否已经取得控制权。

### 易错点

一是“现时权利”和“经济利益”不是同一个判断点。

```text
现时权利：看客户现在有没有控制商品的权利和能力；
经济利益：看商品带来的主要好处是否基本归客户。
```

二是发货、开票、收款都不必然等于收入确认。

如果客户尚未取得控制权，即使企业已经收款，也可能只是确认合同负债，而不是确认收入。

### 记忆口诀

```text
确认收入看控制，
控制抓三点：
现在能支配，
使用能主导，
好处基本拿走。
```

## 二、合同成立五条件的快速理解

### 核心结论

收入准则下，只有同时满足合同成立的五个条件，企业才按收入准则进行后续的收入确认和计量。

五个条件可以压缩成一句话：

```text
双方真要干，东西和钱说清楚，这事有商业意义，钱大概率收得回。
```

对应五个关键词：

```text
1. 批准并承诺履行；
2. 权利明确；
3. 付款条款明确；
4. 有商业实质；
5. 对价很可能收回。
```

### 判断逻辑

| 条件 | 快速理解 | 判断重点 |
| --- | --- | --- |
| 批准并承诺履行 | 双方都认可合同，并准备按合同办 | 不是草稿、意向书或随便说说 |
| 权利明确 | 双方知道各自能得到什么 | 卖什么、买什么、双方权利义务清楚 |
| 付款条款明确 | 钱怎么算、怎么付、什么时候付大致清楚 | 价格、结算方式、付款时间等清楚 |
| 有商业实质 | 交易会真实改变企业未来现金流 | 现金流金额、时间或风险会变化 |
| 对价很可能收回 | 企业判断客户大概率会付款 | 看客户支付能力和支付意愿 |

### 易错点

第二点、第三点和第五点容易混。

```text
权利明确：讲商品或服务，重点是卖什么、买什么。
付款条款明确：讲合同怎么收钱，重点是多少钱、怎么付、何时付。
对价很可能收回：讲客户能不能、愿不愿付钱，重点是信用和回款可能性。
```

“付款条款明确”不等于“钱一定能收回”。

合同可以把价款和付款时间写得很清楚，但如果客户明显没有支付能力，仍然可能不满足“对价很可能收回”。

“有商业实质”强调真实经济影响。如果交易只是为了做账、互相走形式，未来现金流没有实质变化，就不满足这一条件。

### 记忆口诀

合同成立五条件可以直接记：

```text
批、权、款、商、收。
```

对应含义是：

| 口诀 | 对应条件 | 快速理解 |
| --- | --- | --- |
| 批 | 合同各方已批准合同，并承诺履行各自义务 | 双方认可并准备履行 |
| 权 | 合同明确了各方与所转让商品或服务相关的权利 | 卖什么、买什么清楚 |
| 款 | 合同有明确的与所转让商品或服务相关的支付条款 | 多少钱、怎么付、何时付清楚 |
| 商 | 合同具有商业实质 | 交易会真实改变未来现金流 |
| 收 | 企业因向客户转让商品而有权取得的对价很可能收回 | 客户大概率能付、愿意付 |

也可以记成：

```text
批了合同，定了权；
说清款项，有商业；
钱能收回，才算数。
```

考试时注意，“收”不是已经收款，而是判断对价是否很可能收回。

## 三、单项履约义务成立的两个条件

### 核心结论

一项商品或服务要作为单项履约义务，通常要同时满足两个条件：

```text
1. 客户能够从该商品本身，或从该商品与其他易于获得的资源一起使用中受益；
2. 企业向客户转让该商品的承诺，与合同中其他承诺可单独区分。
```

简单理解：

```text
条件 1：看商品本身能不能单独受益；
条件 2：看合同里这个承诺能不能单独区分。
```

不建议硬记成“客观”和“主观”。更稳的记法是：

```text
一个看商品功能上的可区分；
一个看合同承诺上的可区分。
```

### 判断逻辑

条件 1 问的是：离开这份合同，这个商品或服务有没有独立使用价值。

如果客户取得该商品后，可以单独使用、出售、消耗，或者和自己已有、市场上容易取得的资源一起使用并取得利益，通常说明条件 1 满足。

例如：

```text
普通设备；
标准软件；
一批原材料；
普通维修服务。
```

条件 2 问的是：放回这份合同里，企业是不是在单独承诺转让这个商品或服务。

如果企业承诺的实质是把多个商品或服务整合成一个整体成果，那么即使各部分本身有用，也可能不能作为单项履约义务。

例如：

```text
设备 + 普通安装服务：
安装服务不复杂，其他供应商也能安装，设备和安装通常可以单独区分。

设计 + 施工 + 调试，最终交付一条高度定制生产线：
各部分高度整合、彼此重大修改影响，通常不能单独区分。
```

### 易错点

不要只看商品本身有没有用。

商品本身有独立价值，只能说明条件 1 可能满足；还要继续看在本合同中，企业的承诺是否可以和其他承诺分开。

也不要把“能单独受益”和“可单独区分”混成一个条件。

```text
能单独受益：看客户拿到后能不能用、能不能获得利益；
可单独区分：看企业在合同中是不是单独交付这个承诺，而不是交付一个整合后的整体成果。
```

### 记忆口诀

```text
本身有用，合同可分，才是单项履约义务。
```

也可以记成：

```text
先看能不能单独受益；
再看合同里能不能单独交付。
```

## 四、合同合并与单项履约义务合并的区别

### 核心结论

合同合并和单项履约义务合并是两个层面的判断，不能混在一起。

```text
合同合并：决定几份合同是否应当作为一份合同处理；
履约义务合并：决定一份合同中的多个承诺是否应当作为一项履约义务处理。
```

所以：

```text
合同合并 ≠ 履约义务一定合并成一项。
```

正确顺序是：

```text
先判断合同边界：几份合同要不要合并；
再识别履约义务：合并后的合同里有几项单项履约义务。
```

### 判断逻辑

合同合并看的是合同之间的关系。

如果企业与同一客户同时或在相近时间订立多份合同，并且这些合同是基于同一商业目的、一揽子谈判、对价相互关联，或者各合同承诺构成一项单项履约义务，则可能需要合并为一份合同处理。

单项履约义务合并看的是承诺之间的关系。

即使几份合同已经合并成一份合同，也还要继续判断里面的商品或服务是否可明确区分。如果不同商品或服务本身可以单独受益，并且合同中承诺也能单独区分，就可能形成多项单项履约义务。

### 例子理解

例如，企业与同一客户同时签订两份合同：

```text
合同 A：销售 100 台标准电脑；
合同 B：提供 3 年标准售后维护服务。
```

如果这两份合同是一揽子谈判、价格互相关联，可能需要作为一份合同合并处理。

但合并以后，仍然可能识别出两项单项履约义务：

```text
1. 交付电脑；
2. 提供维护服务。
```

原因是：电脑本身客户可以单独受益，维护服务也可以单独受益；二者并不是高度整合成一个不可分割的整体。

再对比高度定制设备的例子：

```text
设备制造 + 复杂安装 + 重大修改整合
```

如果企业承诺的实质是交付一套能够与客户现有设备整合运行的整体系统，那么这些承诺高度整合、彼此重大影响，通常应作为一项单项履约义务。

此时，“一项履约义务”的原因不是因为合同合并本身，而是因为合并后的合同中，各承诺不能单独区分。

### 易错点

不要直接从“合同合并”推出“一项履约义务”。

```text
合同合并只是确定会计处理的合同范围；
单项履约义务识别才决定收入确认的核算单元。
```

也不要认为“合同没有合并”就一定不能有一项履约义务。关键仍然要看企业向客户承诺转让的商品或服务是否可明确区分。

### 记忆口诀

```text
先合合同，再拆义务；
合同看商业目的，义务看能否单独交付。
```

也可以记成：

```text
合同合并看合同之间；
义务合并看承诺之间。
```

## 五、履行履约义务与取得控制权的关系

### 核心结论

“企业履行了履约义务”和“客户取得了控制权”，在收入确认中通常是同一件事的两个角度。

```text
企业履行履约义务
= 商品或服务控制权转移给客户
= 客户取得控制权
= 企业确认收入
```

### 判断逻辑

履约义务是企业向客户转让商品或服务的承诺。

因此，企业什么时候算履行了履约义务，关键看客户什么时候取得该商品或服务的控制权。

如果履约义务是在某一时点履行，则在控制权转移的那个时点确认收入。

如果履约义务是在某一时段内履行，则随着履约进度确认收入。

### 易错点

不要把“履约义务完成”理解成企业自己内部已经做完工作。

收入确认关注的是控制权是否已经转移给客户，而不是企业是否已经生产完成、发出商品、开具发票或收到款项。

### 记忆口诀

```text
卖方说履约，
买方说控制；
本质是一件事，
收入看控制转移。
```

## 六、某一时段内履行履约义务的三个条件

### 核心结论

判断一项履约义务是在某一时段内履行，还是在某一时点履行，先看是否满足三个条件之一。

只要满足任意一个条件，就属于某一时段内履行履约义务；三个都不满足，才属于某一时点履行履约义务。

三个条件可以这样记：

```text
条件一：服务即时被客户消耗，重点是“边做边享受”；
条件二：在建资产被客户控制，重点是“边建边控制”；
条件三：资产不受客户控制，但企业被保护，重点是“专属定制 + 有权收款”。
```

最短口诀：

```text
边享受；
边控制；
专属定制且有权收款。
```

### 判断逻辑

条件一：客户在企业履约的同时即取得并消耗企业履约所带来的经济利益。

白话理解是：

```text
企业一边做，客户一边享受。
```

例子：保洁公司每天为客户办公室提供保洁服务。今天完成的保洁，客户今天就已经享受并消耗了；明天即使换另一家保洁公司，也不需要重新做昨天已经完成的服务。

判断条件一时，可以用一个辅助问题：

```text
如果更换新的企业继续履行剩余义务，新的企业是否无须重新执行原企业至今已经完成的工作？
```

如果答案是“无须重新做”，通常说明客户已经取得并消耗了前面履约带来的经济利益，更接近条件一。

因此，这类常规或经常性服务通常属于某一时段内履行。

条件二：客户能够控制企业履约过程中在建的商品。

白话理解是：

```text
企业一边建，客户一边控制这个在建资产。
```

例子：施工单位在客户自有土地上建造办公楼。楼还没完工，但在建工程位于客户土地上，客户通常能够控制该在建资产。

因此，这类在客户控制的资产上进行建造或改造的履约义务，通常属于某一时段内履行。

条件三：企业履约过程中所产出的商品具有不可替代用途，且企业在整个合同期间内有权就累计至今已完成的履约部分收取款项。

这个条件要拆成两个小条件，并且通常要同时满足：

```text
1. 无替代用途：东西是为这个客户专门做的，不能轻易改卖给别人；
2. 有权收款：客户如果中途取消，企业也有权收回已完成部分的成本和合理利润。
```

例子：企业按照客户特殊规格定制一台专用设备，该设备只能用于客户的生产线，不能不经过重大改造就卖给其他客户。合同还约定，如果客户中途取消合同，客户必须支付企业已完成部分的成本和合理利润。

此时，虽然客户可能尚未控制在建资产，但企业制造的是客户专属资产，并且已完成部分有收款保障，因此属于某一时段内履行。

### 易错点

条件三不是只看“定制”。

仅仅是客户定制，还不够；还要看企业是否在整个合同期间内，有权就累计至今已完成的履约部分收取款项。

```text
只专属定制，但无权收款：通常不能直接认定为某一时段履行；
专属定制 + 做多少有权收多少：才满足条件三。
```

条件二和条件三也不要混。

```text
条件二：客户控制在建资产；
条件三：客户不一定控制在建资产，但资产无替代用途，且企业有收款保护。
```

### 记忆口诀

```text
边做边享受；
边建边控制；
专属定制，做多少有权收多少。
```

考试判断顺序可以这样走：

```text
客户是否边接受边消耗？是 -> 时段履约；
否则，看客户是否控制在建商品？是 -> 时段履约；
否则，看是否无替代用途且有权收款？是 -> 时段履约；
三个都不是 -> 时点履约。
```
## 七、某一时点履行履约义务的控制权转移迹象

### 核心结论

如果一项履约义务不属于某一时段内履行，就属于某一时点履行。

某一时点确认收入时，关键仍然是判断客户是否已经取得商品控制权。

常见控制权转移迹象可以记：

```text
钱、权、物、险、收。
```

对应：

| 口诀 | 控制权转移迹象 | 快速理解 |
| --- | --- | --- |
| 钱 | 企业就该商品享有现时收款权利 | 企业现在有权收款 |
| 权 | 客户已拥有该商品的法定所有权 | 产权、所有权文件等已转移 |
| 物 | 企业已将该商品实物转移给客户 | 商品已经交付，客户能实际占有 |
| 险 | 企业已将该商品所有权上的主要风险和报酬转移给客户 | 毁损、价格波动、滞销等主要风险报酬已转给客户 |
| 收 | 客户已接受该商品 | 客户验收、签收或确认接受 |

### 判断逻辑

这些迹象都不是单独决定因素，而是帮助判断客户是否已经取得控制权。

最终仍要回到控制权本身：

```text
客户是否能够主导该商品的使用；
客户是否能够获得几乎全部经济利益。
```

例如，商品已经交付到客户指定地点，客户已经验收并签收，所有权上的主要风险和报酬也已经转移，同时企业享有现时收款权利，通常可以支持客户已经取得控制权。

但如果只是开具发票或收到预付款，客户还不能主导商品使用，也没有取得主要经济利益，则不能仅凭开票或收款判断控制权已经转移。

### 易错点

不要把这些迹象机械当作必须全部满足的条件。

```text
它们是判断控制权转移的迹象，不是五个必须同时满足的硬条件。
```

也不要把“发货、开票、收款”直接等同于收入确认。

```text
发货了，不一定控制权已转移；
开票了，不一定能确认收入；
收钱了，也可能只是合同负债。
```

### 记忆口诀

```text
钱权物险收。
```

也可以记成：

```text
能收钱，
转产权，
交实物，
风险走，
客户收。
```
## 八、确定交易价格：可变对价限制与知识产权提成的专门规则

### 核心结论

普通可变对价不是估计出多少，就一定能全部计入交易价格。

通常要分两步：

```text
第一步：估计可变对价金额；
第二步：判断计入交易价格的金额是否受到限制。
```

限制条件可以简单理解为：

```text
等以后不确定性消除时，已经确认的收入很可能不会发生重大转回，才可以计入交易价格。
```

但“按客户实际销售或使用情况收取的知识产权许可使用费”有专门规则：

```text
卖了再认，用了再认，不提前估。
```

### 判断逻辑

普通可变对价，例如奖励、罚款、折扣、返利、退款、价格折让、业绩奖金等，通常先按期望值法或最可能发生金额法估计，再判断是否满足“不会发生重大转回”的限制条件。

例如：

```text
合同价款 100 万，另有绩效奖金 20 万。
如果企业估计能拿到奖金，还要继续判断未来结果确定时，已经确认的收入是否很可能不会重大转回。
```

如果重大转回风险不大，可以将相关金额计入交易价格；如果重大转回风险较大，则不能把该部分可变对价计入交易价格。

知识产权许可使用费的专门规则不同。

如果企业向客户授予知识产权许可，并约定按客户实际销售或实际使用情况收取特许权使用费，通常不提前估计未来总销售额或总使用量并计入交易价格，而是在下列两项孰晚时确认收入：

```text
1. 客户后续销售或使用实际发生；
2. 企业履行相关履约义务。
```

例如，甲公司授权乙公司使用商标，约定乙公司每销售一件商品，向甲公司支付销售额的 5%。

即使甲公司能预计乙公司未来会卖很多商品，也通常不能一开始就估计未来特许权使用费总额并确认收入，而应当在乙公司实际销售发生时，再按实际销售额确认相关收入。

### 易错点

“可变对价限制不适用于知识产权销售或使用提成”不是说这类收入没有不确定性。

更准确地说，是这类情形已经由专门规则处理，不再走普通可变对价的路径。

```text
普通可变对价：估计金额 -> 判断限制 -> 计入交易价格；
知识产权销售或使用提成：不提前估未来 -> 等实际销售或使用发生 -> 确认收入。
```

不要把知识产权提成误认为“只要能估计，就可以提前确认”。

这类收入的触发点通常就是客户未来实际销售或实际使用，因此准则要求等实际销售或使用发生后再确认。

### 记忆口诀

```text
普通可变对价：能稳才先估；
知识产权提成：卖了再认，用了再认。
```

也可以记成：

```text
可变对价先看稳不稳；
IP 提成只看卖没卖、用没用。
```
## 九、确定交易价格：重大融资成分的判断

### 核心结论

合同中存在重大融资成分时，企业确定交易价格时，应当剔除融资影响。

可以简单理解为：

```text
交易价格 = 客户取得商品控制权时，如果立即以现金支付，应支付的金额；
交易价格与合同对价之间的差额 = 融资成分，按实际利率法摊销。
```

但不是所有“交货时间”和“收付款时间”不一致的情况，都存在重大融资成分。

判断重点是：

```text
这个时间差是不是为了向客户或企业提供融资利益。
```

如果合同开始日预计客户取得商品控制权与客户支付价款之间间隔不超过一年，企业可以不考虑合同中存在的重大融资成分。

### 判断逻辑

有时间差，不等于一定有融资。

重大融资成分关注的是合同安排中是否包含借钱或垫资的经济实质。

例如：

```text
客户很晚才付款：可能是企业向客户提供融资；
客户很早就付款：可能是客户向企业提供融资。
```

但下列情形虽然存在时间差，通常不认为合同包含重大融资成分。

第一类：客户预付，且客户可以自行决定商品或服务转让时间。

例如：

```text
储值卡；
奖励积分；
会员卡余额。
```

客户先付款，但什么时候消费、兑换或使用，由客户自己决定。时间差主要来自客户自己的选择，不是为了向企业提供融资。

第二类：对价大部分是可变的，金额或付款时间取决于未来事项。

例如：

```text
按实际销售量收取的特许权使用费；
根据客户未来使用量收费；
按未来业绩结果收取奖金。
```

这类款项晚收，不是因为企业给客户融资，而是因为金额或付款时间本来就要等未来事项发生后才能确定。

第三类：合同对价与现销价格的差额是由融资以外的其他原因导致的。

例如：

```text
预付款是为了保护企业，防止客户违约；
尾款或质保金是为了保护客户，防止企业未充分履约；
付款安排是为了确保双方按合同履行。
```

这类差额的目的不是提供融资利益，而是履约保障。

第四类：时间间隔来自履行必要程序，例如政府审批。

例如，新能源汽车销售中，企业取得的新能源车补贴款可能需要经过国家有关部门审批。即使补贴款收取时间与确认收入时间间隔超过一年，只要时间差主要来自审批所需的必要时间，而不是为了提供融资利益，通常不认为存在重大融资成分。

### 易错点

不要看到“超过一年收款”就直接判断存在重大融资成分。

应先问：

```text
时间差是不是为了给客户或企业提供融资利益？
```

如果时间差来自客户自主决定兑换时间、未来事项不确定、履约保障安排或政府审批程序，通常不按重大融资成分处理。

也不要把重大融资成分下的交易价格理解为“合同价款”。

存在重大融资成分时，交易价格应按现销价格口径确定；合同对价和交易价格之间的差额，本质是利息，应在合同期间内采用实际利率法摊销。

确认利息收入或利息支出，也不是一签合同就马上确认，而是要等相关的合同资产、应收款项或合同负债已经确认。

```text
客户晚付款：企业先确认合同资产或应收款项，再确认相应利息收入；
客户早付款：企业先确认合同负债，再确认相应利息支出。
```

原因是：利息本质上是相关余额随时间推移产生的融资影响。没有应收款项，就没有“客户欠企业钱”的融资余额；没有合同负债，就没有“企业欠客户履约”的融资余额。

例如，企业先交货、客户两年后付款，客户取得控制权时先确认收入和应收款项，之后再按实际利率法确认利息收入。

```text
借：长期应收款 / 应收账款
    贷：主营业务收入

借：长期应收款 / 应收账款
    贷：财务费用 / 利息收入
```

再如，客户先付款、企业两年后交货，企业收到款项时先确认合同负债，之后再按实际利率法确认利息支出。

```text
借：银行存款
    贷：合同负债

借：财务费用 / 利息支出
    贷：合同负债
```

### 记忆口诀

```text
有时间差，不一定有融资；
看目的，是融资还是别的原因。
```

也可以记成：

```text
一年内可简化；
客户自选时间不算；
未来事项不算；
履约保障不算；
审批流程不算。
```
## 十、确定交易价格：非现金对价

### 核心结论

非现金对价，就是客户不是用现金付款，而是用其他资产或服务来支付对价。

常见形式包括：

```text
实物资产；
无形资产；
股权；
客户提供的广告服务；
其他非现金资源。
```

原则上，企业应当按照非现金对价在合同开始日的公允价值确定交易价格。

如果非现金对价的公允价值不能合理估计，则参照企业承诺向客户转让商品或服务的单独售价间接确定交易价格。

### 判断逻辑

第一步：先确定交易价格。

```text
能可靠估计非现金对价公允价值：按合同开始日公允价值确定交易价格；
不能可靠估计非现金对价公允价值：按企业转让商品或服务的单独售价确定交易价格。
```

例如，企业向客户销售设备，客户以股票支付。合同开始日股票公允价值为 100 万元，则交易价格通常按 100 万元确定。

第二步：看合同开始日后，非现金对价公允价值变动的原因。

如果公允价值变动是因为非现金对价本身的形式导致，例如股票、股权投资等自身市场价格涨跌，该变动不调整交易价格。

```text
客户给股票 10 万股；
合同开始日每股 10 元，交易价格为 100 万元；
后来每股涨到 12 元。
```

这时股票涨价属于企业持有该金融资产后的公允价值变动，不再调整收入交易价格。

如果公允价值变动不是因为非现金对价本身涨跌，而是因为合同条款、企业履约情况等导致能取得的非现金对价数量或权利发生变化，则按可变对价处理。

例如：

```text
客户承诺最多给企业 10 万股股票；
但实际给多少，取决于企业是否提前完工或是否达到业绩指标。
```

这时变化的核心不是股票价格自己涨跌，而是企业最终能取得多少对价存在不确定性，本质类似奖励、罚款或业绩奖金，应按可变对价处理，并考虑可变对价限制。

### 易错点

不要把非现金对价后续所有公允价值变动都拿来调整收入。

```text
非现金资产自己涨跌：不调整交易价格；
合同条件导致能拿多少变了：按可变对价处理。
```

也不要忘记计量时点。

非现金对价通常按合同开始日的公允价值确定交易价格，而不是按后续结算日或资产处置日的公允价值重新确定收入金额。

### 记忆口诀

```text
非现金对价，先看合同日公允；
后续变动看原因：
资产自己涨跌，不调收入；
合同条件变动，按可变对价。
```

也可以记成：

```text
股票涨跌归股票，
能拿多少归可变对价。
```
## 十一、确定交易价格：应付客户对价的处理

### 核心结论

应付客户对价，就是企业卖商品或服务给客户，但反过来还要向客户支付款项、返款、补贴、进场费等。

判断核心是：

```text
这笔钱是不是企业向客户购买了可明确区分的商品或服务？
```

处理分三类：

| 情况 | 会计处理 |
| --- | --- |
| 客户提供可明确区分商品或服务，且支付金额不超过公允价值 | 作为购买商品或服务处理 |
| 客户提供可明确区分商品或服务，但支付金额超过公允价值 | 公允价值内作为采购处理，超过部分冲减交易价格 |
| 客户没有提供可明确区分商品或服务 | 全额冲减交易价格 |

### 判断逻辑

应付客户对价不能一律作为销售费用，也不能一律冲减收入。

先看企业给客户的钱，是否换来了客户提供的可明确区分商品或服务。

如果客户确实向企业提供了广告、推广、陈列、物流等可明确区分服务，且企业支付的金额不超过该服务公允价值，那么企业是在采购服务，应按采购服务处理。

如果客户没有提供可明确区分商品或服务，只是因为客户购买企业商品，企业给予返款、补贴或进场费，这笔钱本质是给客户的让利，应冲减交易价格。

如果客户提供了服务，但企业支付金额超过该服务公允价值，则只有公允价值部分是采购服务；超过部分没有买到额外服务，本质仍是让利，应冲减交易价格。

### 例题一：客户提供服务，且对价等于公允价值

甲公司向大型超市销售商品，合同价款 100 万元。同时，甲公司另向超市支付 5 万元，超市需要在门店入口为甲公司商品提供专门广告展示服务。

假设该广告服务可明确区分，且公允价值为 5 万元，不考虑增值税。

判断：

```text
甲公司支付的 5 万元，是购买超市提供的广告服务；
不冲减销售收入；
作为销售费用等处理。
```

销售商品时：

```text
借：应收账款 100
    贷：主营业务收入 100
```

确认广告服务费用时：

```text
借：销售费用 5
    贷：银行存款 / 应付账款 5
```

### 例题二：客户提供服务，但企业多付了

仍以上例为基础，甲公司向超市支付 5 万元广告费，但该广告服务的公允价值只有 3 万元。

判断：

```text
3 万元：确实购买了广告服务，作为销售费用等处理；
2 万元：超过广告服务公允价值，没有买到额外服务，应冲减交易价格。
```

处理思路：

```text
借：销售费用 3
借：主营业务收入 2
    贷：银行存款 / 应付账款 5
```

也可以理解为：当前销售交易价格应减少 2 万元。

### 例题三：客户没有提供可明确区分服务

甲公司向超市销售商品，合同价款 100 万元。为了让超市采购自己的商品，甲公司向超市支付 5 万元“进场费”。超市没有额外提供可明确区分的广告、陈列、推广等服务，只是同意采购甲公司的商品。

判断：

```text
这 5 万元没有换来可明确区分商品或服务；
本质是给客户的让利；
应全额冲减交易价格。
```

交易价格为：

```text
100 - 5 = 95 万元
```

销售时可理解为：

```text
借：应收账款 100
    贷：主营业务收入 95
    贷：应付客户对价 5
```

以后支付进场费时：

```text
借：应付客户对价 5
    贷：银行存款 5
```

如果企业在确认相关收入之后才支付或承诺支付客户对价，应在承诺支付时冲减当期收入。

### 易错点

不要把“付给客户的钱”直接等同于销售费用。

只有企业确实从客户取得了可明确区分商品或服务，并且支付金额不超过其公允价值时，才按采购处理。

也不要把“客户帮企业做了点事”就直接全部作为费用。

如果支付金额超过客户提供商品或服务的公允价值，超过部分仍然是对客户的让利，应冲减交易价格。

### 记忆口诀

```text
给客户的钱，先问买没买到东西；
真买了，按采购；
没买到，冲收入；
多付了，多付部分也冲收入。
```

也可以记成：

```text
可明确区分看服务，
公允价值看上限，
超过部分冲收入。
```

## 十二、交易价格分摊：后续变动与可变对价归属

### 核心结论

交易价格分摊解决的是：已经确定的交易价格，要分给合同中的哪些单项履约义务。

普通规则是：

```text
按照各单项履约义务所承诺商品或服务的单独售价相对比例分摊交易价格。
```

但可变对价和交易价格后续变动有两个特别需要记住的点：

```text
1. 可变对价能明确归属于某项履约义务的，满足条件时可以只分摊给该项；
2. 交易价格后续发生变动的，原则上沿用合同开始日的分摊基础，不因后续单独售价变动而重新分摊。
```

### 判断逻辑

第一，可变对价可能和整个合同有关，也可能只和某一项履约义务有关。

如果可变对价明确是针对某一项履约义务，且分摊给该项后符合分摊交易价格的目标，可以只分摊给该项履约义务。

例如：

```text
甲公司销售设备并提供安装服务；
设备单独售价 100 万元；
安装服务单独售价 10 万元；
合同约定，如果安装提前完成，额外奖励 5 万元。
```

这 5 万元奖励是因为安装服务提前完成，不是因为设备本身，因此在满足相关条件时，可以只分摊给安装服务。

如果可变对价不能明确归属于某一项履约义务，就回到一般分摊原则，按单独售价比例分摊给合同中的各项单项履约义务。

第二，交易价格后续发生变动时，原则上按合同开始日确定的分摊基础处理。

例如，合同中有两个履约义务：

```text
A 商品单独售价 100；
B 服务单独售价 300；
合计单独售价 400。
```

合同开始日的分摊比例为：

```text
A：100 / 400 = 25%；
B：300 / 400 = 75%。
```

如果后来交易价格增加 40，原则上仍按原比例分摊：

```text
A 增加 40 x 25% = 10；
B 增加 40 x 75% = 30。
```

不能因为合同开始日之后 A、B 的市场单独售价发生变化，就重新计算分摊比例。

### 例题：合同变更后可变对价后续变动的二次分摊

甲公司与乙公司签订合同，向乙公司销售 A 产品和 B 产品。A、B 均为可明确区分商品，单独售价相同，并且均属于在某一时点履行的履约义务。

原合同约定：

```text
固定对价：1,000 元；
可变对价：200 元；
交易价格：1,200 元。
```

因为 A、B 单独售价相同，原合同交易价格平均分摊：

```text
A：1,200 / 2 = 600 元；
B：1,200 / 2 = 600 元。
```

2x24 年 11 月 1 日，A 产品交付给客户，确认收入：

```text
A 产品收入 = 600 元。
```

2x24 年 12 月 1 日，双方变更合同，乙公司追加采购 C 产品，合同价格增加 300 元。C 产品与 A、B 产品可明确区分，但新增价格不反映 C 产品的单独售价。

这项合同变更不能作为单独合同处理。由于 A 已经交付，B 尚未交付，B 和新增的 C 可以与已交付的 A 区分，因此属于：

```text
原合同终止；
未履约的 B + 新增的 C 合并作为新合同处理。
```

新合同包括 B 产品和 C 产品，交易价格为：

```text
原来分摊给 B 的 600 + 新增 C 的对价 300 = 900 元。
```

由于 B、C 单独售价相同，新合同中平均分摊：

```text
B：900 / 2 = 450 元；
C：900 / 2 = 450 元。
```

2x24 年 12 月 31 日，甲公司预计有权收取的原合同可变对价金额从 200 元变为 240 元，增加 40 元。

关键判断：这 40 元是原合同可变对价的后续变动，和合同变更前已经承诺的 A、B 有关，不是新增 C 自己产生的可变对价。

所以第一步要先回到原合同 A、B 的分摊基础。由于 A、B 单独售价相同，40 元先平均分给 A、B：

```text
A：20 元；
B：20 元。
```

A 已经交付，分摊给 A 的 20 元应在交易价格发生变动的当期确认为收入。

```text
2x24 年 12 月 31 日追加确认 A 产品收入 20 元。
```

分摊给 B 的 20 元不能直接全部留给 B。原因是：12 月 1 日合同变更后，B 已经不再单独作为原合同剩余部分核算，而是和新增 C 一起组成新合同。

因此第二步要把 B 的 20 元放入新合同 B + C 中再次分摊。由于 B、C 单独售价相同：

```text
B：20 / 2 = 10 元；
C：20 / 2 = 10 元。
```

最终各产品确认收入为：

```text
A：600 + 20 = 620 元；
B：450 + 10 = 460 元；
C：450 + 10 = 460 元。
```

按时间点看：

```text
2x24 年 11 月 1 日：A 产品交付，确认收入 600 元；
2x24 年 12 月 31 日：可变对价增加，A 已履约部分追加确认收入 20 元；
2x25 年 3 月 31 日：B 产品交付，确认收入 460 元；
2x25 年 6 月 30 日：C 产品交付，确认收入 460 元。
```

这道题最关键的理解是：

```text
40 先按旧合同找来源；
分到已履约 A 的，马上确认收入；
分到未履约 B 的，进入新合同 B + C 再分摊。
```

不要把增加的 40 元直接分给 B 和 C；也不要把分给旧合同 B 的 20 元全部留给 B。
### 易错点

不要把“交易价格后续变动”和“单独售价后续变动”混在一起。

```text
交易价格后续变动：要处理，通常按原分摊基础分摊；
单独售价后续变动：不重算合同开始日的分摊比例。
```

也不要机械地把所有可变对价都分摊给全部履约义务。

如果可变对价确实只和某一项履约义务或一系列可明确区分商品中的某一项有关，并且分摊结果合理，可以只分摊给相关项目。

如果已履行的履约义务分摊到可变对价的后续变动额，应当调整变动当期的收入，不回到以前期间改账。

合同变更导致的交易价格后续变动，则不能简单套用原分摊基础，而应按合同变更的相关规则处理。

### 记忆口诀

```text
可变对价先看归属：
能明确归某项，就分给某项；
不能明确归某项，就按普通比例分。
```

交易价格后续变动可以记：

```text
价格后续变，按原比例分；
单独售价后续变，不重算比例。
```

## 十三、销售返利与重大权利的区分

### 核心结论

销售返利不要先背分录，先判断返利的实质。

通常分两类：

```text
1. 返的是本次交易的钱或货价优惠：通常作为可变对价，冲减交易价格；
2. 给的是未来额外购买机会：判断是否构成重大权利。
```

如果只是普通促销，所有客户都能享受，通常不构成重大权利。

如果客户是因为签订当前合同才获得该优惠，且该优惠明显优于普通客户能取得的优惠，则可能构成重大权利。构成重大权利时，该选择权本身是一项单项履约义务，需要分摊交易价格。

### 判断逻辑

普通促销的本质是企业未来销售商品时给客户一个普通折扣。

这类折扣不是当前合同额外给客户的特殊利益，因此当前销售时通常不分摊交易价格，也不确认合同负债；未来客户实际使用优惠时，按实际收款确认未来销售收入。

重大权利的本质是企业在当前合同中额外给了客户一个未来购买的有利选择权。

客户取得该权利，是因为当前购买行为；而且该权利让客户未来能以明显低于普通客户的价格购买商品或服务。因此，当前收取的价款中有一部分实质上是为这个未来权利收取的，应确认为合同负债，等客户未来行使权利或权利失效时再确认收入。

### 例题一：普通促销，不构成重大权利

商场公开促销，所有顾客下月都可以领取 9 折券。甲客户今天购买商品 100 元，也拿到一张 9 折券，但该折扣并不是因为甲客户签订当前合同才独享，其他顾客也可以取得。

假设不考虑增值税，当前商品成本 60 元。

判断：

```text
该 9 折券属于普通促销；
不构成重大权利；
当前销售不分摊交易价格。
```

当前销售时：

```text
借：银行存款 100
    贷：主营业务收入 100

借：主营业务成本 60
    贷：库存商品 60
```

以后客户使用 9 折券购买标价 100 元的商品，实际付款 90 元，商品成本 55 元：

```text
借：银行存款 90
    贷：主营业务收入 90

借：主营业务成本 55
    贷：库存商品 55
```

### 例题二：明显优惠，构成重大权利

甲客户今天购买商品 100 元，企业承诺：只有本次购买客户，未来可以用 60 元购买一件市场正常售价 100 元的商品。普通客户最多只能以 90 元购买。

客户因当前合同额外获得的优惠为：

```text
90 - 60 = 30
```

假设预计客户使用该权利的概率为 80%，则该选择权的单独售价估计为：

```text
30 x 80% = 24
```

当前商品单独售价为 100 元，客户今天实际付款 100 元。

交易价格分摊：

```text
当前商品分摊收入 = 100 x 100 / (100 + 24) = 80.65
重大权利分摊金额 = 100 x 24 / (100 + 24) = 19.35
```

当前销售，商品成本 60 元：

```text
借：银行存款 100
    贷：主营业务收入 80.65
    贷：合同负债 19.35

借：主营业务成本 60
    贷：库存商品 60
```

以后客户行使权利，用 60 元购买该商品，商品成本 50 元：

```text
借：银行存款 60
借：合同负债 19.35
    贷：主营业务收入 79.35

借：主营业务成本 50
    贷：库存商品 50
```

如果客户最终没有使用该重大权利，权利到期时：

```text
借：合同负债 19.35
    贷：主营业务收入 19.35
```

### 例题三：客户奖励积分，后续估计兑换数量变化

客户奖励积分通常属于“客户因当前购买而取得的未来优惠”。如果该优惠明显优于普通客户能够取得的优惠，积分本身构成重大权利，应作为一项单项履约义务分摊交易价格。

甲公司启动奖励积分计划。客户每消费 10 元可获得 1 个积分，每个积分未来可以抵减 1 元。客户 2024 年 1 月 1 日购买商品并支付 100 000 元，取得 10 000 个积分。根据历史经验，甲公司预计积分兑换率为 95%。假设不考虑增值税。

合同开始日，商品的单独售价为 100 000 元；积分的单独售价为：

```text
10 000 × 1 × 95% = 9 500 元
```

因此，交易价格 100 000 元应在商品和积分之间按相对单独售价分摊：

```text
分摊给商品的交易价格 = 100 000 ÷ (100 000 + 9 500) × 100 000 = 91 324 元
分摊给积分的交易价格 = 9 500 ÷ (100 000 + 9 500) × 100 000 = 8 676 元
```

商品控制权转移时：

```text
借：银行存款 100 000
    贷：主营业务收入 91 324
        合同负债 8 676
```

这里的合同负债 8 676 元，就是分摊给积分这项履约义务的“总池子”。

截至 2024 年 12 月 31 日，客户已兑换 4 500 个积分。甲公司重新估计后，仍预计客户总共将兑换 9 500 个积分。

积分应确认的累计收入：

```text
4 500 ÷ 9 500 × 8 676 = 4 110 元
```

确认积分收入：

```text
借：合同负债 4 110
    贷：主营业务收入 4 110
```

剩余未兑换积分对应合同负债：

```text
8 676 - 4 110 = 4 566 元
```

截至 2025 年 12 月 31 日，客户累计兑换 8 500 个积分。甲公司重新估计，预计客户总共将兑换 9 700 个积分。

注意：9500 变成 9700，不是重新分摊商品和积分的交易价格，而是积分这项履约义务内部履约进度的估计变化。

因此，仍然以合同开始日分摊给积分的 8 676 元为基础，重新计算积分累计应确认收入：

```text
8 500 ÷ 9 700 × 8 676 = 7 603 元
```

2025 年应确认的积分收入：

```text
7 603 - 4 110 = 3 493 元
```

分录：

```text
借：合同负债 3 493
    贷：主营业务收入 3 493
```

剩余未兑换积分对应合同负债：

```text
8 676 - 4 110 - 3 493 = 1 073 元
```

这道题最重要的理解是：

```text
合同开始日：商品和积分之间分摊交易价格，形成积分总池子 8 676；
后续期间：预计兑换数量变化，只影响积分池子内部的收入确认进度；
不会因为 9 500 变成 9 700，就重新分摊商品和积分的比例。
```

也可以压缩记忆为：

```text
分摊比例锁在合同开始日；
兑换估计变在履约进度里。
```
### 易错点

不要把所有优惠券、折扣券都当作重大权利。

```text
普通促销：所有客户都能享受，不是当前合同额外给的利益，通常不是重大权利；
重大权利：因当前合同才取得，且优惠明显优于普通客户，可能是一项单项履约义务。
```

也不要把构成重大权利的优惠直接作为销售费用。

构成重大权利时，当前收款的一部分应分摊给该权利，先确认为合同负债，未来客户行使权利或权利失效时再确认收入。

### 记忆口诀

```text
普通促销：不分摊，未来按实际卖价确认；
重大权利：先分摊，形成合同负债，未来使用或失效再确认。
```

也可以记成：

```text
人人都有，不是重大权利；
因本次购买才有明显优惠，才看重大权利。
```
## 十四、合同履约成本：为履约购买资产与折旧摊销

### 核心结论

企业为了履行客户合同而购买硬件、软件、设备等资产时，不是直接看“交不交付给客户”，而是先看该资产本身是否适用其他准则。

```text
硬件、设备符合固定资产定义：先按固定资产处理；
软件符合无形资产定义：先按无形资产处理；
存货、固定资产、无形资产等有自己的准则，先回自己的准则。
```

合同履约成本更像兜底规则：

```text
不属于其他准则范围；
与合同直接相关；
增加企业未来用于履约的资源；
预计能够收回。
```

满足这些条件时，才考虑确认为合同履约成本资产。

### 判断逻辑

第一步：先判断资产本身进哪里。

如果企业为履约购买服务器、设备等硬件，且符合固定资产确认条件，应确认为固定资产。

```text
借：固定资产
    贷：银行存款
```

如果企业为履约购买软件，且符合无形资产确认条件，应确认为无形资产。

```text
借：无形资产
    贷：银行存款
```

这些资产不因为“是为了履行客户合同而买”，就直接计入合同履约成本。

第二步：后续折旧或摊销看用途。

如果设备或软件专门用于履行客户合同、提供相关服务，折旧或摊销通常计入合同服务成本。

可以直接计入主营业务成本：

```text
借：主营业务成本
    贷：累计折旧 / 累计摊销
```

也可以先归集为合同履约成本，再随收入确认结转：

```text
借：合同履约成本
    贷：累计折旧 / 累计摊销

借：主营业务成本
    贷：合同履约成本
```

如果设备或软件用于行政管理，折旧或摊销计入管理费用。

```text
借：管理费用
    贷：累计折旧 / 累计摊销
```

如果设备或软件用于销售活动，折旧或摊销计入销售费用。

```text
借：销售费用
    贷：累计折旧 / 累计摊销
```

### 例子理解

甲公司为向乙公司提供 5 年信息中心管理服务，购买服务器硬件 300 万元、管理软件 200 万元，并发生平台设计、搭建、测试成本 120 万元，另支付项目员工工资 50 万元。

硬件和软件有自己的准则：

```text
借：固定资产 300
    贷：银行存款 300

借：无形资产 200
    贷：银行存款 200
```

平台设计、搭建、测试成本与合同直接相关，增加未来履约资源，预计能够收回，可以确认为合同履约成本：

```text
借：合同履约成本 120
    贷：银行存款 / 应付账款等 120
```

项目员工工资如果只是当期人工消耗，没有增加未来用于履约的资源，应在发生时计入当期损益：

```text
借：管理费用 / 主营业务成本 50
    贷：应付职工薪酬 50
```

后续提供服务时，合同履约成本 120 万元在 5 年内摊销，每年 24 万元：

```text
借：主营业务成本 24
    贷：合同履约成本 24
```

如果硬件、软件专门用于该客户服务，折旧和摊销也通常计入服务成本。例如硬件 5 年折旧、软件 5 年摊销：

```text
借：主营业务成本 / 合同履约成本 60
    贷：累计折旧 60

借：主营业务成本 / 合同履约成本 40
    贷：累计摊销 40
```

### 易错点

不要用“是否交付给客户”作为第一判断标准。

```text
交不交付不是核心；
先看是否有其他准则管；
再看是否形成未来履约资源。
```

也不要把为合同购买的固定资产、无形资产直接计入合同履约成本。

固定资产、无形资产本身先按各自准则确认；它们后续的折旧或摊销，再根据用途计入主营业务成本、合同履约成本、管理费用或销售费用。

项目人工也不是一定资本化。只有能够增加未来履约资源、预计能够收回的成本，才可能确认为合同履约成本资产；单纯当期人工消耗通常计入当期损益。

### 记忆口诀

```text
买来的资产先找自己的准则；
资产后续折旧摊销，再按用途进成本或费用。
```

也可以记成：

```text
固定资产、无形资产先回自己家；
没有明确归属但形成未来履约资源，才进合同履约成本。
```
### 建造合同例题：40% 收入进度下，哪些进成本，哪些留在合同履约成本

甲公司为客户建造一栋大楼，属于某一时段内履行的履约义务。合同价款 1 000 万元，预计总成本 700 万元。年末经第三方测量，工程已完成 40%。

本年发生支出如下：

| 项目 | 金额 | 判断 |
| --- | ---: | --- |
| 已投入并形成已完成工程的材料、人工、机械费 | 280 万元 | 对应已履约部分，确认主营业务成本 |
| 为后续施工购买的专属构件，年末尚未安装 | 60 万元 | 服务于未来履约，满足条件时留在合同履约成本 |
| 非正常浪费的材料 | 10 万元 | 异常损耗，费用化 |
| 总部管理人员工资，且不由客户承担 | 20 万元 | 管理费用 |

第一步：确认收入。

```text
收入 = 1 000 × 40% = 400 万元
```

```text
借：合同资产 / 应收账款 400
    贷：主营业务收入 400
```

第二步：处理已经用于已完成工程的成本。

这 280 万元已经形成客户取得的工程成果，属于已经履约部分，应结转主营业务成本。

实际发生时可以先归集：

```text
借：合同履约成本 280
    贷：原材料 / 应付职工薪酬 / 累计折旧等 280
```

确认收入时结转成本：

```text
借：主营业务成本 280
    贷：合同履约成本 280
```

这里的重点是：这 280 万元已经被用掉了，客户已经取得对应工程成果，所以不能继续留作资产。

第三步：处理尚未安装的专属构件。

这 60 万元虽然已经发生支出，但尚未形成已履约部分，而是将来继续建楼要用的资源。如果该构件专门用于这个合同，且预计能通过合同收回，可以确认为合同履约成本。

```text
借：合同履约成本 60
    贷：银行存款 / 原材料等 60
```

年末暂时不结转主营业务成本。以后安装并随工程履约转移给客户时，再结转：

```text
借：主营业务成本 60
    贷：合同履约成本 60
```

第四步：处理非正常浪费。

非正常浪费没有形成未来履约资源，也不是正常履约代价，不能确认为合同履约成本。

```text
借：主营业务成本 / 管理费用 10
    贷：原材料等 10
```

第五步：处理总部管理费用。

总部管理人员工资如果不是客户明确承担的，不属于合同履约成本，直接计入管理费用。

```text
借：管理费用 20
    贷：应付职工薪酬 20
```

年末结果可以这样看：

| 项目 | 金额 |
| --- | ---: |
| 主营业务收入 | 400 万元 |
| 主营业务成本 | 280 万元 |
| 合同履约成本余额 | 60 万元 |
| 当期费用 / 损失 | 30 万元 |

核心记忆：

```text
40% 是收入确认进度，不是把所有支出都乘 40%。
成本看支出对应已履约部分，还是还能服务于未来履约。
已履约消耗掉的，进主营业务成本；
还能支持未来履约的，才可能留在合同履约成本。
```

### 合同资产、合同履约成本和合同取得成本的减值

这个知识点最容易混在“资产减值损失”这个科目名上。要把两件事分开：

```text
适用哪套准则：决定怎么判断、能不能转回；
计入哪个科目：决定分录怎么写。
```

#### 1. 合同资产减值

合同资产是企业已经履约，但收款权利还取决于时间流逝以外的其他因素。它面临的风险既有信用风险，也可能有履约风险。

合同资产的减值计量、列报和披露，按金融工具相关准则处理，不按资产减值准则处理。

但教材口径下，合同资产发生减值时，分录计入资产减值损失：

```text
借：资产减值损失
    贷：合同资产减值准备
```

以后如果减值因素改善，可以转回：

```text
借：合同资产减值准备
    贷：资产减值损失
```

注意：这里虽然用的是“资产减值损失”科目，但不代表它适用《资产减值》准则中长期资产减值不得转回的逻辑。

#### 2. 合同履约成本和合同取得成本减值

合同履约成本和合同取得成本，是收入准则下的合同成本资产。它们的减值适用收入准则中的合同成本减值规定，不适用资产减值准则。

判断减值时，核心比较：

```text
合同成本资产的账面价值
vs
企业因转让与该资产相关的商品预计能够取得的剩余对价 - 为转让该相关商品估计将要发生的成本
```

如果账面价值更高，超出部分计提减值：

```text
借：资产减值损失
    贷：合同履约成本减值准备 / 合同取得成本减值准备
```

以后减值因素消失，可以转回原已计提的减值准备：

```text
借：合同履约成本减值准备 / 合同取得成本减值准备
    贷：资产减值损失
```

但转回有上限：

```text
转回后的账面价值
不得超过假定以前没有计提减值准备情况下该资产在转回日的账面价值。
```

#### 3. 对比记忆

| 项目 | 减值适用规则 | 减值科目 | 是否可以转回 |
| --- | --- | --- | --- |
| 合同资产 | 金融工具相关准则 | 资产减值损失 | 可以转回 |
| 合同履约成本 | 收入准则的合同成本减值规定 | 资产减值损失 | 可以转回，但有上限 |
| 合同取得成本 | 收入准则的合同成本减值规定 | 资产减值损失 | 可以转回，但有上限 |

可以压缩记忆为：

```text
合同资产：方法走金融工具，科目走资产减值损失，可以转回；
合同成本：方法走收入准则，科目也走资产减值损失，可以转回但受上限限制。
```

再提醒一句：

```text
不要看到“资产减值损失”科目，就误以为适用资产减值准则；
科目名称和准则归属不是一回事。
```
### 综合例题：亏损建造合同的收入、成本、合同结算和预计负债

这个例题把四个知识点放在一起考：

```text
1. 某一时段履约：用成本法确认履约进度；
2. 合同结算：收入结转和价款结算分别登记；
3. 亏损合同：没有可减值标的资产时，对未履约部分确认预计负债；
4. 质保金：收款权利取决于质量保证结果时，先列合同资产，期满后再转应收账款。
```

甲公司签订固定造价建造合同，合同总价 580 万元，不考虑增值税。采用成本法确定履约进度。相关资料如下：

| 项目 | 2018 年 | 2019 年 | 2020 年 | 2021 年 | 2022 年 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 年末累计实际发生成本 | 154 | 300 | 488 | 610 | - |
| 年末预计完成合同尚需发生成本 | 396 | 300 | 122 | - | - |
| 本期结算合同价款 | 174 | 196 | 180 | 30 | - |
| 本期实际收到价款 | 170 | 190 | 190 | - | 30 |

其中 30 万元为工程质保金，需要等 2022 年底质保期结束且未发生重大质量问题后才能收取。

#### 1. 2018 年

履约进度：

```text
154 ÷ (154 + 396) = 28%
```

累计收入和本年收入：

```text
580 × 28% = 162.4 万元
```

实际发生成本：

```text
借：合同履约成本 154
    贷：原材料 / 应付职工薪酬等 154
```

确认收入并结转成本：

```text
借：合同结算——收入结转 162.4
    贷：主营业务收入 162.4

借：主营业务成本 154
    贷：合同履约成本 154
```

结算和收款：

```text
借：应收账款 174
    贷：合同结算——价款结算 174

借：银行存款 170
    贷：应收账款 170
```

2018 年末，合同结算贷方余额：

```text
174 - 162.4 = 11.6 万元
```

说明已经向客户结算但尚未履约的金额更多，列示为合同负债。

#### 2. 2019 年

本年实际发生成本：

```text
300 - 154 = 146 万元
```

履约进度：

```text
300 ÷ (300 + 300) = 50%
```

累计收入：

```text
580 × 50% = 290 万元
```

本年收入：

```text
290 - 162.4 = 127.6 万元
```

实际发生成本：

```text
借：合同履约成本 146
    贷：原材料 / 应付职工薪酬等 146
```

确认收入并结转成本：

```text
借：合同结算——收入结转 127.6
    贷：主营业务收入 127.6

借：主营业务成本 146
    贷：合同履约成本 146
```

2019 年预计总成本为 600 万元，大于合同总收入 580 万元，预计总亏损 20 万元。已履约 50%，其中 10 万元已经通过当期损益反映，剩余未履约部分预计亏损为：

```text
20 × (1 - 50%) = 10 万元
```

本题期末没有尚未费用化的合同履约成本等标的资产余额，因此直接确认预计负债：

```text
借：主营业务成本 10
    贷：预计负债 10
```

结算和收款：

```text
借：应收账款 196
    贷：合同结算——价款结算 196

借：银行存款 190
    贷：应收账款 190
```

2019 年末，合同结算贷方余额：

```text
11.6 + 196 - 127.6 = 80 万元
```

列示为合同负债。

#### 3. 2020 年

本年实际发生成本：

```text
488 - 300 = 188 万元
```

履约进度：

```text
488 ÷ (488 + 122) = 80%
```

累计收入：

```text
580 × 80% = 464 万元
```

本年收入：

```text
464 - 290 = 174 万元
```

实际发生成本：

```text
借：合同履约成本 188
    贷：原材料 / 应付职工薪酬等 188
```

确认收入并结转成本：

```text
借：合同结算——收入结转 174
    贷：主营业务收入 174

借：主营业务成本 188
    贷：合同履约成本 188
```

2020 年预计总成本调整为 610 万元，预计总亏损为：

```text
610 - 580 = 30 万元
```

已履约 80%，已经反映在损益中的亏损为：

```text
30 × 80% = 24 万元
```

剩余未履约部分预计亏损应保留为预计负债：

```text
30 × (1 - 80%) = 6 万元
```

2019 年已经确认预计负债 10 万元，因此本年转回 4 万元：

```text
借：预计负债 4
    贷：主营业务成本 4
```

结算和收款：

```text
借：应收账款 180
    贷：合同结算——价款结算 180

借：银行存款 190
    贷：应收账款 190
```

2020 年末，合同结算贷方余额：

```text
80 + 180 - 174 = 86 万元
```

列示为合同负债。

#### 4. 2021 年

本年实际发生成本：

```text
610 - 488 = 122 万元
```

工程完工，累计收入为合同总价 580 万元。本年收入：

```text
580 - 464 = 116 万元
```

实际发生成本：

```text
借：合同履约成本 122
    贷：原材料 / 应付职工薪酬等 122
```

确认收入并结转成本：

```text
借：合同结算——收入结转 116
    贷：主营业务收入 116

借：主营业务成本 122
    贷：合同履约成本 122
```

工程已经完工，剩余未履约部分预计亏损为 0，转回剩余预计负债 6 万元：

```text
借：预计负债 6
    贷：主营业务成本 6
```

2021 年 6 月 30 日，合同结算借方余额：

```text
116 - 86 = 30 万元
```

这 30 万元是工程质保金，能否收取取决于 2022 年底质保期结束且未发生重大质量问题。因此，列示为合同资产，而不是应收账款。

#### 5. 2022 年

质保期结束且未发生重大质量问题，30 万元收款权利变成无条件收款权利：

```text
借：应收账款 30
    贷：合同结算 30
```

实际收到质保金：

```text
借：银行存款 30
    贷：应收账款 30
```

#### 6. 这题的几个关键结论

第一，收入不是按结算金额确认，而是按履约进度确认。

```text
本年收入 = 合同总价 × 年末累计履约进度 - 以前年度累计已确认收入
```

第二，合同履约成本不是期末一定有余额。本题每年实际发生的合同履约成本，都随着当年履约进度结转入主营业务成本，所以年末没有留下可减值的合同履约成本资产。

```text
借：主营业务成本
    贷：合同履约成本
```

第三，亏损合同如果存在尚未费用化的标的资产，应先对标的资产计提减值；超过标的资产金额的部分，才确认预计负债。

```text
有标的资产：
借：资产减值损失
    贷：合同履约成本减值准备 / 存货跌价准备等

超过标的资产的亏损，或没有标的资产：
借：主营业务成本
    贷：预计负债
```

这里的“标的资产”通常不是合同资产，而是为未来履约持有的资产，例如专门存货、尚未结转的合同履约成本等。合同资产是已经履约形成的收款权利，不是未来履约要消耗的资产。

第四，质保金不一定直接确认为应收账款。如果收款权利还取决于质保期内是否发生重大质量问题，应先列合同资产；等条件满足后，再转为应收账款。

```text
合同资产：已经履约，但收款权利还有附加条件；
应收账款：已经取得无条件收款权利，只差时间流逝。
```

记忆口诀：

```text
收入看进度，结算看账单；
亏损先看资产，没资产进负债；
质保未到期，先合同资产，期满转应收。
```
## 十五、合同履约成本中运费的处理

### 核心结论

运费怎么处理，先看这笔运输是不是为了履行与客户的合同，再看商品控制权是在运输前还是运输后转移。

可以按四类记：

```text
1. 控制权转移前发生的运输费：通常是销售合同的履约成本，结转营业成本；
2. 控制权转移后发生的运输费：可能构成单项履约义务，作为运输服务的履约成本；
3. 不是为履行客户合同发生的运输费：通常计入当期损益；
4. 使存货达到当前位置和状态的必要运输费：计入存货成本。
```

### 判断逻辑

第一类：商品控制权转移之前发生的运输费。

如果合同约定企业必须把商品运到客户指定地点，客户到达该地点后才取得控制权，那么运输只是企业完成销售合同的一部分，通常不构成单项履约义务。

```text
控制权还没转，运输是为了完成卖货。
```

因此，相关成本作为合同履约成本，最终结转入营业成本，通常是主营业务成本，而不是销售费用。

第二类：商品控制权转移之后发生的运输费。

如果客户已经取得商品控制权，企业又承诺继续提供运输服务，这时运输服务可能是一项单独的履约义务。

```text
控制权已经转，后续运输可能是在给客户提供另一项服务。
```

此时，运输服务发生的成本作为该运输服务的履约成本；在确认运输服务收入时，将相应运输成本结转至营业成本。如果运输服务不是企业主营业务活动，收入和成本可能分别计入其他业务收入、其他业务成本。

第三类：不是为履行客户合同发生的运输费。

如果企业发生运输费并不是为了履行与客户的合同，通常不属于合同履约成本，而应按费用性质计入当期损益。

例如：

```text
企业内部调拨存货发生的运输费：通常计入管理费用等；
为参展、展会布置发生的运输费：通常计入销售费用等。
```

第四类：使存货达到当前位置和状态的必要运输费。

如果运输费属于采购存货、生产存货过程中，为使存货达到当前场所和状态所必需的支出，则适用存货成本的逻辑，计入存货成本。

这不是收入准则下“合同履约成本”的判断，而是存货准则的判断。

### 易错点

不要看到“运费”就直接计入销售费用。

在收入准则下，如果运输发生在商品控制权转移之前，且是履行销售合同所必需的活动，通常应作为合同履约成本并结转营业成本。

也不要看到“运费”就一律作为单项履约义务。

只有当商品控制权已经转移，企业又向客户提供后续运输服务时，运输才可能构成单项履约义务。

判断顺序可以压缩成：

```text
先看是不是客户合同；
再看控制权何时转移；
最后看运输是不是单独服务。
```

### 记忆口诀

```text
转控前运输：卖货成本；
转控后运输：可能是单独服务；
非客户合同运输：进期间费用；
入库存货必要运输：进存货成本。
```

也可以记成：

```text
运费不急着进销售费用，
先问控制权转没转。
```

## 十六、特殊交易：附有销售退回条款的销售

### 核心理解

附有销售退回条款的销售，本质是：

```text
商品已经交给客户，但客户未来可能退货。
```

所以会计处理要分两条线：

```text
收入线：只确认预计不会退货的部分；
成本线：预计会退回的商品，不是真的卖掉了，要确认应收退货成本。
```

也可以记成：

```text
不退的部分确认收入；
要退的钱确认负债；
能收回的货确认资产；
真正耗掉的成本进主营业务成本。
```

### 收入线：确认预计不会退货的收入

企业销售商品时，如果预计部分商品会退回，不能把全部销售价款都确认为收入。

```text
主营业务收入 = 预计不会退货部分对应的对价
预计负债——应付退货款 = 预计将退还给客户的金额
```

分录一般是：

```text
借：应收账款 / 银行存款
    贷：主营业务收入
        预计负债——应付退货款
        应交税费——应交增值税（销项税额）
```

这里的预计负债，可以理解为：客户未来退货时，企业预计要把钱退给客户。

### 成本线：确认应收退货成本

预计会退回来的商品，企业未来有权收回，所以不能把这部分商品成本全部当成本费用消耗掉。

但应收退货成本不是简单等于退回商品的原账面成本，而是退回商品预计能给企业带来的净经济利益。

```text
应收退货成本
= 预计退回商品转让时的账面价值
- 收回该商品预计发生的成本
- 退回商品预计发生的价值减损
```

所以成本分录一般是：

```text
借：主营业务成本
    应收退货成本
    贷：库存商品
```

这里要特别注意：

```text
预计退回商品本身还能收回的净价值，确认为应收退货成本；
为收回退货商品预计要发生的运费、检测费、重新包装费等，会挤进主营业务成本。
```

### 例子

甲公司销售商品 100 件，每件售价 100 元，单位成本 60 元，增值税税率 13%。根据历史经验，预计有 10 件会被退回。预计退货时，甲公司还需承担退货运费 50 元、检测和重新包装费 30 元。

收入线：

```text
总售价 = 100 × 100 = 10 000 元
销项税额 = 10 000 × 13% = 1 300 元
预计退货金额 = 10 × 100 = 1 000 元
预计不会退货的收入 = 90 × 100 = 9 000 元
```

销售时确认收入：

```text
借：应收账款 11 300
    贷：主营业务收入 9 000
        预计负债——应付退货款 1 000
        应交税费——应交增值税（销项税额） 1 300
```

成本线：

```text
库存商品总成本 = 100 × 60 = 6 000 元
预计退回商品原成本 = 10 × 60 = 600 元
预计收回退货商品还要发生的成本 = 50 + 30 = 80 元
应收退货成本 = 600 - 80 = 520 元
主营业务成本 = 6 000 - 520 = 5 480 元
```

销售时结转成本：

```text
借：主营业务成本 5 480
    应收退货成本 520
    贷：库存商品 6 000
```

这里的 5 480 元可以拆开理解：

```text
预计不会退货的 90 件成本：90 × 60 = 5 400 元
预计收回退货商品还要发生的成本：50 + 30 = 80 元
合计主营业务成本：5 480 元
```

所以，从分录结果看，为收回退货商品预计发生的运费、检测费、重新包装费，确实进入了主营业务成本。

### 特殊例题：无法合理估计退货率时，收入先不确认

附有销售退回条款，本质上会导致对价可变。因为客户可能退货，企业最终能够取得多少对价并不确定。

正常情况下，如果企业能够合理估计退货率，就按预计不会退货的部分确认收入；但如果企业缺乏退货历史数据，也没有其他可参考的市场信息，无法判断未来退货情况，就不能满足可变对价计入交易价格的限制条件。

```text
有退货权：对价可变；
能估计退货率：确认预计不会退货部分的收入；
不能估计退货率：收入先按 0 处理，等退货期满再确认。
```

例：乙公司向客户销售 A 产品。客户在合同开始日即取得 A 产品控制权，并在 90 天内有权退货。乙公司没有销售此类产品的历史数据，也没有其他可参考市场信息。合同对价为 12 100 元，客户在第二年年末付款；A 产品合同开始日现销价格为 10 000 元，成本为 8 000 元。不考虑税费。

合同开始日，虽然商品控制权已经转移，但由于退货情况无法合理估计，不能将可变对价计入交易价格，所以不确认收入。

此时只把预计未来可能收回的商品成本，从库存商品转为应收退货成本：

```text
借：应收退货成本 8 000
    贷：库存商品 8 000
```

90 天退货期内，因为尚未确认收入、合同资产或应收款项，所以也不需要确认重大融资成分的影响。

退货期满后，未发生退货。此时不确定性消除，企业可以确认收入。由于合同约定第二年年末付款，合同对价 12 100 元与现销价格 10 000 元之间的差额，属于重大融资成分。

```text
借：长期应收款 12 100
    贷：主营业务收入 10 000
        未实现融资收益 2 100
```

同时结转成本：

```text
借：主营业务成本 8 000
    贷：应收退货成本 8 000
```

这个例题的重点不是“有退货权就一定不确认收入”，而是：

```text
有退货权，并且无法合理估计退货情况，才导致合同开始日收入先不确认。
```

如果企业能够合理估计退货率，就回到普通附退回条款销售的处理：确认预计不会退货部分的收入，同时确认预计负债和应收退货成本。
### 实际退货时

如果未来实际退回 10 件，并退还客户 1 000 元：

```text
借：预计负债——应付退货款 1 000
    贷：银行存款 / 应收账款 1 000
```

收回退货商品时：

```text
借：库存商品 520
    贷：应收退货成本 520
```

如果实际退货情况与原估计不同，企业应在每一资产负债表日重新估计未来销售退回情况，并作为会计估计变更处理。

### 易错点

第一，不要把全部销售价款都确认为收入。

```text
预计会退的钱，不是收入，而是预计负债。
```

第二，不要把全部库存商品成本都确认为主营业务成本。

```text
预计会退回且还能带来经济利益的商品，确认为应收退货成本。
```

第三，应收退货成本要扣除预计收回商品还要发生的成本和价值减损。

```text
应收退货成本不是原成本，而是净价值。
```

### 记忆口诀

```text
收入只认不退的；
退款确认预计负债；
退货商品确认应收退货成本；
收回成本和减值，挤进主营业务成本。
```

## 十七、特殊交易：主要责任人与代理人的区分

### 核心判断

主要责任人和代理人的核心区别是：

```text
企业在商品或服务转给客户之前，是否控制该商品或服务。
```

如果企业先控制商品或服务，再转让给客户，是主要责任人；如果企业只是安排第三方向客户提供商品或服务，是代理人。

```text
主要责任人：按总额确认收入；
代理人：按净额确认收入。
```

### 记忆口诀

```text
先控后卖是主责；
只撮合拿佣是代理。

主责看三点：
担主责、担存货风险、能定价。

主责总额确认；
代理净额确认。
```

### 主要责任人的判断信号

主要责任人的本质是：企业自己向客户提供商品或服务，并在转让前控制该商品或服务。

常见判断信号包括：

```text
1. 企业对客户承担主要责任；
2. 企业在商品转让前后承担存货风险；
3. 企业有权自主决定交易价格。
```

这些只是辅助信号，最根本还是看控制权：

```text
商品转给客户之前，企业是否已经控制该商品？
```

例：甲公司先从厂家买入手机，再销售给客户。手机卖不出去的风险由甲公司承担，售价由甲公司决定，客户售后也找甲公司。

此时甲公司是主要责任人。假设售价 1 000 元，进货成本 700 元：

```text
借：银行存款 1 000
    贷：主营业务收入 1 000

借：主营业务成本 700
    贷：库存商品 700
```

这里收入按总额 1 000 元确认。

### 代理人的判断信号

代理人的本质是：企业没有在商品或服务转给客户之前控制该商品或服务，只是帮助客户和第三方完成交易。

常见判断信号包括：

```text
1. 企业只是安排第三方提供商品或服务；
2. 企业不对商品或服务承担主要责任；
3. 企业通常不承担存货风险；
4. 企业收入通常是固定佣金、手续费或净差额。
```

例：平台帮助商家销售手机。客户付款 1 000 元，平台只收取 100 元佣金，商品由商家发货，售后主要由商家负责。

平台没有控制手机，只是撮合交易，因此是代理人。

如果平台只确认佣金收入：

```text
借：银行存款 / 应收账款 100
    贷：主营业务收入 100
```

如果平台先代收客户全部价款 1 000 元，再扣除佣金 100 元后支付给商家，可以理解为：

```text
借：银行存款 1 000
    贷：其他应付款 900
        主营业务收入 100
```

这里收入按净额 100 元确认。

### 易错点

第一，不是看企业有没有参与交易，而是看企业有没有在转让前控制商品或服务。

```text
参与交易不等于主要责任人；
撮合交易通常只是代理人。
```

第二，不是收到了客户全部款项就一定按总额确认收入。

```text
代收代付的金额，不是企业自己的收入。
```

第三，主要责任人和代理人的三个信号不是机械打勾题。

```text
担主责、担存货风险、能定价，是判断控制权的辅助迹象；
最终落脚点仍然是转让前是否控制商品或服务。
```

### 对比总结

| 项目 | 主要责任人 | 代理人 |
| --- | --- | --- |
| 核心 | 转让前控制商品或服务 | 只是安排第三方提供商品或服务 |
| 责任 | 对客户承担主要责任 | 第三方承担主要责任 |
| 风险 | 通常承担存货风险 | 通常不承担存货风险 |
| 定价 | 通常能自主定价 | 通常收取佣金或手续费 |
| 收入确认 | 总额法 | 净额法 |

一句话记：

```text
控制商品的是卖方，确认总额；
安排交易的是中介，确认净额。
```

## 十八、特殊交易：授予知识产权许可

### 核心理解

授予客户知识产权许可时，先判断这个许可本身是否构成单项履约义务；如果构成，再判断收入是在某一时点确认，还是在某一时段确认。

最重要的区分是：

```text
静态 IP：客户取得的是使用企业现有知识产权的权利，通常某一时点确认收入；
动态 IP：客户取得的是持续接入企业不断维护、运营、改变的知识产权，通常某一时段确认收入。
```

也可以记成：

```text
授权的是现成 IP：时点确认；
授权的是持续运营中的 IP：时段确认。
```

### 某一时点确认：现成 IP

如果客户拿到许可后，就可以使用该知识产权，企业后续不需要持续从事会重大影响该知识产权价值的活动，通常属于某一时点履约。

例：甲公司授权乙公司使用一张已经完成的插画，授权期 2 年。甲公司后续不会更新插画，也不会持续宣传或维护该插画形象。乙公司拿到授权后即可用于商品包装。

此时乙公司取得的是使用现有知识产权的权利，通常在客户能够使用该许可时确认收入：

```text
借：银行存款 / 应收账款
    贷：主营业务收入
```

### 某一时段确认：持续运营中的 IP

如果企业后续会持续从事活动，并且这些活动会重大影响知识产权的价值，客户取得的不是一个静态权利，而是在授权期间持续接入该知识产权。

例：甲公司授权乙公司使用热门动漫角色 3 年。甲公司在 3 年内会继续更新动画、运营粉丝活动、推出电影和周边宣传，这些活动会显著影响该角色的热度和商业价值。

此时客户享受的是持续运营中的 IP，通常在授权期间按时间进度确认收入：

```text
借：合同负债 / 应收账款
    贷：主营业务收入
```

### 判断为某一时段履约的三个条件

知识产权许可同时满足下列条件时，通常作为某一时段内履行的履约义务确认收入：

```text
1. 合同要求或客户能够合理预期企业将从事对该知识产权有重大影响的活动；
2. 这些活动会对客户产生有利或不利影响；
3. 这些活动不会导致向客户转让某项商品。
```

可以把三个条件翻译成更直白的话：

```text
企业会继续养这个 IP；
客户会受这个 IP 热度变化影响；
企业不是另外交付一个新成果给客户。
```

### “不会导致向客户转让某项商品”怎么理解

这句话的意思是：企业后续做的活动，只是在维护、运营、提升 IP 的价值，而不是另外交给客户一个可控制、可使用的新东西。

#### 1. 不转让商品：只是维护 IP 热度

甲公司把一个动漫角色授权给乙公司做玩具，授权期 3 年。甲公司承诺继续播出新动画、投放宣传、经营粉丝社群。

这些活动会让动漫角色更火，乙公司的玩具更好卖。但是甲公司没有把新动画片、宣传物料、粉丝社群账号交给乙公司。乙公司只是享受到角色热度提高带来的好处。

所以这些活动：

```text
不会向客户转让某项商品；
只是影响授权 IP 的价值。
```

这类活动支持把 IP 许可判断为某一时段履约。

#### 2. 转让商品：可能出现新的单项履约义务

如果合同除了授权 IP，还要求企业向客户交付具体成果，比如：

```text
10 条专属广告视频；
100 张专属设计图；
一套包装方案；
一个定制软件模块；
一套专属源代码。
```

这些东西本身就是客户能控制、能使用的商品或服务。此时企业后续活动就不只是维护 IP 热度，而是在向客户转让新的商品或服务。

如果这些成果可明确区分，通常要单独识别为单项履约义务。

例如：

```text
IP 授权 + 交付 10 张专属设计图
```

可能存在两项履约义务：

```text
1. 授予 IP 使用许可；
2. 交付专属设计图。
```

再比如：

```text
IP 授权 + 为客户制作广告片
```

可能存在两项履约义务：

```text
1. 授予 IP 使用许可；
2. 广告片制作服务。
```

判断时仍然要回到单项履约义务的两个条件：客户能否从该商品本身或与其他资源一起受益，以及该商品在合同中是否可明确区分。

### 不要被时间、地域、用途限制带偏

判断知识产权许可是在某一时点还是某一时段确认收入时，不要主要看这些限制：

```text
授权 1 年还是 3 年；
只能在中国使用还是全球使用；
只能用于服装还是玩具。
```

这些只是限制客户使用权的范围，不决定企业是否在持续履约。

真正要看的是：

```text
企业后续是否持续从事会重大影响 IP 价值的活动；
客户是否会受到这些活动影响；
这些活动是否只是维护 IP，而不是交付新商品。
```

但有一个重要限制：如果合同明确规定客户只能从未来某个时点开始使用知识产权，企业不能早于该时点确认收入。

例：1 月 1 日签合同，但合同约定客户从 4 月 1 日起才能使用该 IP。即使合同已经签订，收入确认也不能早于 4 月 1 日。

### 例题：固定授权费 + 销售提成

知识产权许可合同中，经常同时包含两类对价：

```text
固定授权费：金额固定，按 IP 许可本身的履约方式确认收入；
销售提成 / 使用费：金额取决于客户后续销售或使用，适用知识产权许可的特殊规则。
```

例：甲公司拥有某动漫角色 IP。2024 年 1 月 1 日，甲公司授权乙公司在 2024 年全年使用该动漫角色生产和销售玩具。

合同约定：

```text
固定授权费：100 万元；
销售提成：乙公司按玩具实际销售额的 5% 支付；
乙公司每季度结算一次提成。
```

假设该动漫角色是一个持续运营中的 IP，甲公司在 2024 年全年还会继续更新动画、宣传角色、举办粉丝活动，这些活动会显著影响乙公司玩具销售。

#### 1. 固定授权费 100 万元

固定授权费不是销售提成，不适用“客户销售发生和企业履约孰晚确认收入”的特殊规则。

它要先判断这个 IP 许可是某一时点履约，还是某一时段履约。

本例中，甲公司持续运营该 IP，属于某一时段履约，所以固定授权费 100 万元应在 2024 年全年确认收入。

收到固定授权费时：

```text
借：银行存款 100
    贷：合同负债 100
```

如果按月平均确认收入，每月确认：

```text
100 ÷ 12 = 8.33 万元
```

```text
借：合同负债 8.33
    贷：主营业务收入 8.33
```

#### 2. 销售提成 5%

销售提成属于与知识产权许可相关的特许权使用费，适用专门规则：

```text
客户后续销售或使用实际发生；
企业履行相关履约义务；
两者孰晚确认收入。
```

假设乙公司第一季度玩具销售额为 600 万元。

销售提成为：

```text
600 × 5% = 30 万元
```

如果甲公司在第一季度也持续履行了运营 IP 的义务，则第一季度末确认提成收入：

```text
借：应收账款 30
    贷：主营业务收入 30
```

收到提成款时：

```text
借：银行存款 30
    贷：应收账款 30
```

#### 3. 客户先卖了，但企业还没履约

假设合同规定甲公司必须在 4 月 1 日正式开放 IP 授权，乙公司 3 月提前预售了一批玩具，销售额 200 万元。

虽然客户销售已经发生，但甲公司 3 月还没有履行授权义务，所以 3 月不能确认提成收入。

等 4 月 1 日甲公司履约后，才确认：

```text
200 × 5% = 10 万元
```

```text
借：应收账款 10
    贷：主营业务收入 10
```

#### 4. 企业已经履约，但客户还没卖

如果甲公司 1 月 1 日已经授权并持续运营 IP，但乙公司第一季度没有销售，则销售提成还没有实际发生，不能提前估计确认收入。

```text
客户没有销售额：不确认销售提成收入。
```

等乙公司第二季度实际销售 600 万元时，再确认：

```text
借：应收账款 30
    贷：主营业务收入 30
```

#### 5. 固定授权费和销售提成为什么分开处理

两者适用的规则不同：

```text
固定授权费 100 万元：金额固定，看 IP 许可本身是时点履约还是时段履约；
销售提成 5%：金额取决于客户未来销售，不能提前估计，等客户销售和企业履约二者孰晚确认。
```

所以不能把整个合同简单混在一起处理。

可以这样记：

```text
固定费看 IP 是时点还是时段；
销售提成看客户卖没卖 + 企业履约没履约，二者孰晚确认。
```

这个场景还有一个很重要的边界：

```text
一项 IP 许可履约义务，不代表所有对价都按同一个节奏确认收入；
固定费跟着 IP 许可本身走，销售/使用提成走 IP 提成的专门规则。
```

也可以压缩记成：

```text
一项履约义务，两类对价，两种收入确认节奏。
```
### 记忆口诀

```text
现成 IP，时点认；
持续养 IP，时段认；
只养热度不交货；
交付成果另拆分。
```

再压缩一句：

```text
后续活动只是养 IP，放进许可判断；
后续活动交成果，就看是否拆成新的履约义务。
```

## 十九、特殊交易：售后回购

### 核心理解

售后回购是指：企业把商品卖给客户后，又承诺或可能要把商品买回来。

核心问题不是“合同写了销售”，而是要判断：

```text
这是真卖货，还是借销售形式包装成租赁或融资？
```

如果客户并没有真正取得商品控制权，企业就不能按普通销售确认收入。

### 判断顺序

第一步：看企业是否有回购义务，或者客户是否有权要求企业回购。

```text
企业有义务回购；
或客户有权要求企业回购。
```

如果存在这些安排，说明客户可能没有真正承担商品的主要风险，企业也可能没有真正转移控制权。

第二步：看客户是否有行使回售权的重大经济动因。

如果回购价格明显高于资产回购时的市场价值，客户就有很强动力要求企业回购。

例：客户买入设备，未来市场价预计为 80 万元，但合同约定客户可以要求企业以 100 万元回购。

客户当然更愿意让企业 100 万元买回去，而不是在市场上 80 万元卖掉。因此，客户具有行权的重大经济动因。

```text
回购价明显高于回购时市场价
→ 客户有重大经济动因
→ 不按普通销售处理。
```

第三步：如果客户有重大经济动因，再比较回购价格和原售价。

```text
回购价格低于原售价：作为租赁交易；
回购价格不低于原售价：作为融资交易。
```

为什么这样分？

如果回购价低于原售价，客户实质上是支付一笔差额来使用资产一段时间，像租赁。

```text
原售价 100 万元，未来回购价 80 万元；
客户付出的净额是 20 万元，像使用资产的租金。
```

如果回购价不低于原售价，企业现在收到钱，未来又以不低于原售价的金额买回，实质上像企业向客户融资。

```text
原售价 100 万元，未来回购价 105 万元；
企业现在拿到 100 万元，未来还 105 万元，像融资并支付利息。
```

第四步：如果客户没有重大经济动因。

如果客户没有明显动力要求企业回购，说明回购权更像普通退货权或保障，不一定影响客户取得控制权。

此时通常按附有销售退回条款的销售处理。

```text
确认预计不会退货部分的收入；
确认预计负债——应付退货款；
确认应收退货成本。
```

### 分录思路

#### 1. 作为租赁交易

如果实质是租赁，企业不应确认商品销售收入，而应按租赁准则确认租赁相关收入。

```text
不按普通销售确认主营业务收入和主营业务成本；
按租赁交易确认相关租赁收入。
```

#### 2. 作为融资交易

如果实质是融资，企业收到客户款项时，不确认销售收入，而是确认金融负债。

```text
借：银行存款
    贷：其他应付款 / 金融负债
```

后续回购价格高于原售价的差额，通常作为融资费用在期间内确认。

```text
借：财务费用
    贷：其他应付款 / 金融负债
```

回购时：

```text
借：其他应付款 / 金融负债
    贷：银行存款
```

#### 3. 作为附有销售退回条款的销售

如果客户没有重大经济动因，则按附销售退回条款处理。

```text
借：银行存款 / 应收账款
    贷：主营业务收入
        预计负债——应付退货款
        应交税费——应交增值税（销项税额）

借：主营业务成本
    应收退货成本
    贷：库存商品
```

### 记忆口诀

```text
有回购，先看行权动力；
回购价高于市场价，客户有动力；
有动力，再比原售价；
低于原售价是租赁；
不低于原售价是融资；
没动力，按销售退回。
```

再压缩一句：

```text
客户强烈会退回来，就不是真销售；
退回像使用，是租赁；退回像还钱，是融资。
```

## 二十、特殊交易：客户未行使的权利

### 核心理解

客户未行使的权利，指的是客户已经付款取得权利，但后来可能不会使用全部或部分权利。

典型例子：

```text
储值卡；
会员卡；
预付课程；
预付健身卡；
充值点券；
过期未使用的优惠券。
```

客户付款时，企业还没有提供对应商品或服务，所以先确认合同负债：

```text
借：银行存款
    贷：合同负债
```

后续处理的核心是：企业什么时候可以把合同负债转为收入。

### 三种情况

#### 1. 客户实际使用权利

客户使用储值卡、会员卡、课程等权利时，企业履行了相关履约义务，应确认收入。

```text
借：合同负债
    贷：主营业务收入
```

例如，客户用储值卡消费 300 元：

```text
借：合同负债 300
    贷：主营业务收入 300
```

#### 2. 客户未使用，但企业预计有权取得相关金额

如果企业预计客户会放弃部分合同权利，且企业有权取得与客户放弃权利相关的金额，可以按照客户行使合同权利的模式，按比例确认这部分收入。

这部分未使用的权利，常称为 breakage。

例：客户充值 1 000 元，企业根据历史经验预计其中 100 元永远不会被使用，且无需退还。客户本期实际消费 450 元。

预计会被客户使用的金额：

```text
1 000 - 100 = 900 元
```

客户本期使用进度：

```text
450 ÷ 900 = 50%
```

因此，预计不会被使用的 100 元中，也可以按 50% 确认收入：

```text
100 × 50% = 50 元
```

本期合计确认收入：

```text
客户实际消费 450 + 未行使权利收入 50 = 500 元
```

分录：

```text
借：合同负债 500
    贷：主营业务收入 500
```

这里的逻辑是：客户实际使用权利的过程，也反映了企业逐步有权取得客户最终不会使用部分金额的过程。

#### 例题：储值卡含税处理，收入和销项税按同一进度结转

甲公司经营连锁面包店。2025 年，甲公司向客户销售 5 000 张储值卡，每张面值 200 元，总额 1 000 000 元。客户可以在甲公司任意门店使用该储值卡消费。根据历史经验，甲公司预计客户购买的储值卡中，将有 50 000 元不会被使用。截至 2025 年 12 月 31 日，客户使用储值卡消费的金额为 400 000 元。甲公司为增值税一般纳税人，适用增值税税率 13%，在客户使用储值卡消费时发生增值税纳税义务。

销售储值卡时，客户只是预付款，企业尚未履约，因此先确认合同负债和待转销项税额。

```text
不含税合同负债 = 1 000 000 ÷ (1 + 13%) = 884 956 元
待转销项税额 = 1 000 000 - 884 956 = 115 044 元
```

分录：

```text
借：库存现金 1 000 000
    贷：合同负债 884 956
        应交税费——待转销项税额 115 044
```

客户实际消费 400 000 元时，企业不仅要确认实际消费部分收入，还要按照客户行使权利的进度，确认预计不会使用部分的收入。

预计会被客户使用的金额：

```text
1 000 000 - 50 000 = 950 000 元
```

客户使用进度：

```text
400 000 ÷ 950 000
```

本期可确认的含税销售金额：

```text
400 000 + 50 000 × 400 000 ÷ 950 000 = 421 053 元
```

对应不含税收入：

```text
421 053 ÷ (1 + 13%) = 372 613 元
```

对应销项税额：

```text
421 053 ÷ (1 + 13%) × 13% = 46 018 元
```

分录：

```text
借：合同负债 372 613
    应交税费——待转销项税额 46 018
    贷：主营业务收入 372 613
        应交税费——应交增值税（销项税额） 46 018
```

这里的关键是：收入和销项税额的结转比例，与客户可确认的销售进度一致。

```text
确认比例 = 客户实际使用金额 ÷ (总金额 - 预计不会使用部分)
```

也就是：

```text
400 000 ÷ (1 000 000 - 50 000)
```

可以这样记：

```text
客户实际消费多少，不只确认实际消费收入；
还要按实际消费进度确认预计不会使用部分；
收入和待转销项税额，都按同一个含税销售进度结转。
```
#### 3. 客户未使用，企业暂时不能确定有权取得

如果企业不能确定客户是否会放弃权利，或者不能确定这部分金额是否无需退还，就不能提前确认未使用部分收入。

只有在客户要求企业履行剩余履约义务的可能性极低时，才能将相关合同负债确认为收入。

例如，预付课程长期未使用，但仍在有效期内，客户仍可能来上课，企业不能提前确认收入。等权利到期且客户要求履约的可能性极低时，再确认收入：

```text
借：合同负债
    贷：主营业务收入
```

### 法律规定必须交给其他方的情况

如果相关法律规定，企业收取的与客户未行使权利相关的款项必须转交给其他方，例如无人认领财产需要上交政府，则企业不能将其确认为收入。

```text
借：合同负债
    贷：其他应付款
```

### 易错点

第一，客户预付款不是收入，先是合同负债。

```text
客户先付款，企业还没履约：合同负债。
```

第二，客户没使用的部分不一定马上确认收入。

```text
预计有权取得：按客户使用模式确认；
暂时不能确定：等客户要求履约的可能性极低时确认。
```

第三，如果法律规定必须上交，企业不能确认收入。

```text
不是企业能留下的钱，就不是企业收入。
```

### 记忆口诀

```text
客户用了，转收入；
预计不用且能留下，按使用进度转收入；
不能确定能留下，等基本不会再履约时转收入；
法律规定要上交，不能转收入。
```

## 二十一、特殊交易：无需退回的初始费

### 核心理解

无需退回的初始费，指客户在合同开始时支付的一笔入门费、开户费、加盟费、入会费、接入费等，而且合同约定这笔钱不退。

但会计上不能因为“不退”就马上确认收入。关键要问：

```text
这笔初始费到底对应企业已经交付了什么，还是只是未来履约的预收款？
```

判断顺序可以压缩成两问：

```text
第一问：是否与合同中已承诺的某项商品或服务相关？
第二问：如果相关，该商品或服务是否构成单项履约义务？
```

### 三种情况

#### 1. 与已承诺商品或服务无关：作为未来商品或服务的预收款

如果初始费本身没有对应企业已经承诺并转让的具体商品或服务，它通常只是客户为未来取得商品或服务预先支付的款项。

处理：

```text
先确认为合同负债；
未来转让相关商品或服务时确认收入。
```

例：甲公司经营会员制平台。客户支付 600 元不可退还的入门费后，未来 12 个月可以在平台购买服务。甲公司在收取入门费时没有向客户转让任何可明确区分的商品或服务。

收款时：

```text
借：银行存款 600
    贷：合同负债 600
```

未来 12 个月提供平台服务时，按月确认收入：

```text
借：合同负债 50
    贷：主营业务收入 50
```

这里的重点是：

```text
不退不等于已经赚到；
没有现在交付，就先作为未来履约的预收款。
```

#### 2. 与某项商品或服务相关，且该商品或服务构成单项履约义务：转让该商品或服务时确认收入

如果初始费对应一项可明确区分的商品或服务，客户能够从该商品或服务本身或与其他资源一起受益，并且该商品或服务在合同中可明确区分，则该商品或服务构成单项履约义务。

处理：

```text
将交易价格分摊给该单项履约义务；
在转让该商品或服务时确认收入。
```

例：甲公司向客户收取 1 000 元不可退还的初始费，其中包含交付一台客户可单独使用的专用设备。该设备单独售价为 800 元，并且客户取得设备后可以与其他服务商提供的服务一起使用。

如果分摊给设备的交易价格为 800 元，在设备交付时：

```text
借：合同负债 / 银行存款 800
    贷：主营业务收入 800
```

同时结转设备成本，假设成本 500 元：

```text
借：主营业务成本 500
    贷：库存商品 500
```

这里的重点是：

```text
初始费不是按“收款时”确认收入；
而是按其对应的单项履约义务何时履行来确认收入。
```

#### 3. 与某项商品或服务相关，但该商品或服务不构成单项履约义务：并入相关履约义务确认收入

如果企业收取初始费后只是做了一些准备活动，例如建档、开户、办卡、系统录入、开通账户等，客户不能从这些活动本身单独受益，这些活动通常不构成单项履约义务。

处理：

```text
不单独确认收入；
并入相关商品或服务，在相关履约义务履行时确认收入。
```

例：健身房向客户收取 1 200 元年费和 300 元不可退还的入会费。入会费对应的建档、办卡、系统录入等活动，只是为了让客户以后使用健身服务，客户不能单独从这些活动中受益。

收款时：

```text
借：银行存款 1 500
    贷：合同负债 1 500
```

健身房在 12 个月会员期内提供健身服务，按月确认收入：

```text
借：合同负债 125
    贷：主营业务收入 125
```

这里的重点是：

```text
开户、建档、办卡通常只是准备活动；
不是客户真正购买的单独服务；
所以初始费随后续会员服务确认收入。
```

### 对比总结

| 情况 | 判断 | 会计处理 |
| --- | --- | --- |
| 与已承诺商品或服务无关 | 没有对应当前交付内容 | 作为未来商品或服务的预收款，未来履约时确认收入 |
| 相关，且构成单项履约义务 | 客户能单独受益，且合同中可明确区分 | 分摊交易价格，在转让该商品或服务时确认收入 |
| 相关，但不构成单项履约义务 | 只是准备活动或辅助活动 | 并入相关履约义务，随相关商品或服务确认收入 |
