# 借款费用知识点

## 一、开始资本化：三项条件与资产支出

开始资本化须同时满足：**资产支出已发生、借款费用已发生、必要购建或生产活动已开始**。仅签合同或借入款项不够。

| 为符合资本化条件的资产发生的事项 | 资产支出的确认时点 |
| --- | --- |
| 支付现金、转移非现金资产 | 支付或转移时 |
| 承担带息债务，如签发带息票据购买工程物资 | 承担带息债务时 |
| 普通不带息赊购 | 实际付款时；取得材料或确认应付账款时暂不计入 |

例：1月1日支付工程款500万元、2月1日签发带息票据购料300万元，分别从发生日起计入资产支出；3月1日不带息赊购200万元、6月1日付款的，从6月1日起计入。计算利息还须落在资本化期间，并区分资金来源，不能重复计息。

上述200万元赊购及付款分录：

```text
赊购：借：工程物资／在建工程  200
        贷：应付账款          200
付款：借：应付账款          200
        贷：银行存款          200
```

## 二、一般借款：加权支出乘资本化率

```text
一般借款资本化金额
＝累计资产支出超过专门借款部分的资产支出加权平均数×所占用一般借款资本化率

资本化率＝相关一般借款当期实际利息之和÷一般借款本金加权平均数
加权支出＝Σ（占用一般借款的每笔资产支出×符合资本化条件的占用时间÷当期时间）
```

无专门借款且支出均占用一般借款时，无须扣除专门借款覆盖部分。利率与时间权数的期间口径须一致，资本化金额不得超过当期相关借款实际利息。

例：全年存在两笔一般借款：2,000万元、年利率6%；10,000万元、年利率8%。工程全年符合资本化条件且无专门借款，1月1日支出1,500万元，7月1日支出2,500万元。按每年360天、半年180天的题设计算：

| 步骤 | 计算（万元） |
| --- | --- |
| 资本化率 | (2,000×6%＋10,000×8%)÷12,000＝7.666…% |
| 加权支出 | 1,500＋2,500×180/360＝2,750 |
| 资本化金额 | 2,750×(920/12,000)＝210.83 |
| 上限检查 | 210.83＜实际利息920 |

不要用支出总额4,000乘全年利率；7月支出只占用半年。计算中保留利率精度，最后再四舍五入。

## 三、溢价发行专门借款债券：面值与实收资金

**面值用于算票面应付利息；实际可动用资金用于算闲置收益及一般借款占用；实际利息按摊余成本和实际利率算。** 本例无交易费用，实际可动用资金等于发行价格。

题设：1月1日发行三年期债券，面值2,000万元、票面年利率6%、市场利率5%，每年末付息，到期还本，用于建造生产线；当日开工并支出1,800万元，10月1日再支出1,500万元，年末未完工。专门借款闲置资金月收益率0.5%；另有全年一般借款3,000万元、年利率8%。全年持续符合资本化条件。

| 步骤 | 计算（万元） |
| --- | --- |
| 发行价 | 120×2.7232＋2,000×0.8638＝2,054.384（采用题给现值系数） |
| 专门借款实际利息 | 2,054.384×5%＝102.7192 |
| 1—9月闲置收益 | (2,054.384－1,800)×0.5%×9＝11.44728 |
| 专门借款资本化 | 102.7192－11.44728＝91.27192 |
| 10—12月一般借款资本化 | (3,300－2,054.384)×8%×3/12＝24.91232 |
| 年末在建工程 | 3,300＋91.27192＋24.91232＝3,416.18 |

发行时：

```text
借：银行存款                2,054.384
  贷：应付债券——面值        2,000
      应付债券——利息调整       54.384
```

票面利率高于市场利率使本例溢价发行；误用面值会低估可动用专门借款、高估一般借款占用。有交易费用时，应进一步按第五节区分净筹资额。

## 四、土地使用权：自用建筑与开发出售

| 用途 | 借款费用资本化的资产支出基础 |
| --- | --- |
| 自建厂房等自用建筑物 | 土地使用权取得时通常已可使用，不将全部购地款作为厂房资本化基础；以建造支出为基础，包括建造期间计入在建工程的土地使用权摊销 |
| 房地产开发企业建房出售 | 土地使用权支出计入房屋开发成本，与其他建造支出一起作为计算基础 |

两类情形均须满足第1节的开始资本化条件。

依据：[财政部土地使用权实施问答](https://kjs.mof.gov.cn/zt/kjzzss/sswd/jkwd/202012/t20201211_3634037.htm)。

## 五、交易费用与资本化起点的综合例题

题设：1月1日发行三年期专门借款债券，面值3,000万元、票面年利率6%，每年末付息；发行价2,965.28万元，当日另付交易费用120万元，题给实际年利率8%。3月1日生产线开工并支出1,500万元，7月1日再支出1,000万元，年末尚未达到预定可使用状态；此后持续符合资本化条件。闲置资金月收益率0.5%，按月分摊年度实际利息。

本例债券按摊余成本计量，直接相关交易费用扣减初始确认金额；**不能推广为所有金融负债的交易费用都扣成本**。

| 项目 | 计算（万元） |
| --- | --- |
| 初始摊余成本及本例净可动用资金 | 2,965.28－120＝2,845.28 |
| 票面应付利息 | 3,000×6%＝180 |
| 全年实际利息 | 2,845.28×8%＝227.6224 |
| 资本化期间 | 3月1日至12月31日，共10个月；三项条件至3月才同时满足 |
| 资本化期间实际利息 | 227.6224×10/12＝189.6853 |
| 3—6月闲置收益 | (2,845.28－1,500)×0.5%×4＝26.9056 |
| 7—12月闲置收益 | (2,845.28－2,500)×0.5%×6＝10.3584 |
| 资本化金额 | 189.6853－26.9056－10.3584＝152.42 |
| 年末在建工程 | 2,500＋152.4213＝2,652.42 |
| 1—2月财务费用净额 | 227.6224×2/12－2,845.28×0.5%×2＝9.48 |

依据：[《企业会计准则第17号——借款费用》](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/200806/t20080618_46231.htm)。
