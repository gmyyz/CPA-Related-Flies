# 资产减值损失知识点

## 一、不论是否存在减值迹象都应进行减值测试的资产

### 核心结论

资产减值准则中，有三类资产不论是否存在减值迹象，都至少每年进行减值测试：

1. 使用寿命不确定的无形资产；
2. 尚未达到可使用状态的无形资产；
3. 因企业合并形成的商誉。

### 报表项目对应

从报表项目角度，可以对应记忆为：

| 报表项目 | 对应内容 |
| --- | --- |
| 无形资产 | 使用寿命不确定的无形资产 |
| 开发支出 | 尚未达到预定可使用状态的内部研发资本化支出 |
| 商誉 | 因企业合并形成的商誉 |

### 易错点

准则原话通常是按资产类型表述，不是按报表项目表述。

例如，内部研发形成的无形资产，在尚未达到预定可使用状态前，账上还没有转入“无形资产”，而是通过“研发支出--资本化支出”核算，并在报表中列示为“开发支出”。

因此，考试中如果问“哪些资产不论是否存在减值迹象都应测试”，应回答：

1. 使用寿命不确定的无形资产；
2. 尚未达到可使用状态的无形资产；
3. 因企业合并形成的商誉。

如果问“反映在哪些报表项目”，可以对应为：

1. 无形资产；
2. 开发支出；
3. 商誉。

### 记忆口诀

无形资产看两类：寿命不确定、尚未可使用。

商誉单独记：企业合并形成的商誉，每年都要测。

## 二、内部研发尚未达到预定可使用状态的列报

### 核心结论

内部研发形成的无形资产，在尚未达到预定可使用状态时，不能转入“无形资产”。

对应关系如下：

| 项目 | 名称 |
| --- | --- |
| 会计科目 | 研发支出--资本化支出 |
| 报表项目 | 开发支出 |

达到预定可使用状态时，才从“研发支出--资本化支出”转入“无形资产”。

会计分录为：

```text
借：无形资产
  贷：研发支出--资本化支出
```

### 易错点

不要看到“内部研发形成的无形资产”，就直接认为报表项目一定是“无形资产”。

如果题目强调“尚未达到预定可使用状态”，报表列示应抓“开发支出”。

## 三、公允价值减去处置费用后的净额中，处置费用不包括什么

### 核心结论

“公允价值减去处置费用后的净额”中的处置费用，是指可以直接归属于资产处置的增量成本。

处置费用不包括：

1. 财务费用；
2. 所得税费用。

### 判断逻辑

资产减值中计算可收回金额，关注的是资产本身能够收回的金额。

处置费用只扣除为了处置资产本身直接发生的增量成本，例如法律费、相关税费、搬运费、销售佣金等。

财务费用属于融资决策产生的成本，不是处置资产本身必然发生的直接成本。

所得税费用属于企业纳税结果，受税法、税率、计税基础等影响，也不是资产本身价值的一部分。

### 易错点

不要把“卖资产之后企业最终少拿到多少钱”都理解为处置费用。

减值测试中的处置费用看的是“卖资产本身直接多花的钱”，不看钱从哪里来，也不看卖完以后交多少所得税。

### 记忆口诀

处置费用扣直接处置成本。

不扣财务费用，不扣所得税费用。

## 四、预计资产未来现金流量要以资产当前状况为基础

### 核心结论

预计资产未来现金流量，应当以资产的当前状况为基础。

意思是：站在减值测试日，看这项资产“现在这个样子”未来能够带来多少现金流，而不是把未来改造、扩建、升级后的好处提前算入。

### 应当考虑的现金流量

预计资产未来现金流量通常包括：

1. 资产持续使用过程中预计产生的现金流入；
2. 为实现资产持续使用过程中产生现金流入所必需的预计现金流出；
3. 资产使用寿命结束时，处置资产所收到或者支付的净现金流量。

其中，如果资产尚未达到预定可使用状态，为使资产达到预定可使用状态所发生的必要现金流出，应当考虑。

### 不应当提前考虑的现金流量

以资产当前状况为基础，意味着通常不应当考虑：

1. 未来改良资产、扩建资产、升级资产性能后产生的额外现金流入；
2. 与未来改良、扩建、升级相关的现金流出；
3. 筹资活动产生的现金流量；
4. 所得税收付产生的现金流量。

### 例子

一台设备目前每年可以生产 10 万件产品。管理层计划明年花钱改造，改造后每年可以生产 15 万件产品。

做减值测试时，预计未来现金流量应按当前设备每年生产 10 万件的能力估计。

不能按改造后每年生产 15 万件估计。

原因是，多出来的 5 万件产能，是未来改造投资带来的，不是资产在减值测试日当前状况本身带来的。

## 五、已承诺重组和未来改良资产的区分

### 核心结论

已承诺的重组影响可以考虑。

未来改良、扩建、升级资产带来的额外现金流，不能提前考虑。

这两个事项容易混淆，但判断口径不同。

### 对比表

| 事项 | 是否纳入预计未来现金流量 | 理由 |
| --- | --- | --- |
| 尚未作出承诺的未来重组 | 不纳入 | 只是管理层计划，尚未形成较确定安排 |
| 已经作出承诺的重组 | 纳入 | 企业已经承担相关义务，未来现金流应反映其影响 |
| 维持资产当前状态的维修维护 | 纳入 | 是资产按当前状况持续使用所必需的支出 |
| 使尚未完工资产达到可使用状态的必要支出 | 纳入 | 是当前资产形成使用能力所必需的支出 |
| 未来改良、扩建、升级资产性能 | 不纳入 | 属于未来新投入带来的好处，不是当前资产本身的现金流 |

### 重点区分

已承诺重组，通常是企业经营结构、业务安排、成本结构发生变化，例如关闭亏损业务、调整组织架构、减少相关成本等。只要已经作出承诺，预计未来现金流量时可以考虑其影响。

未来改良资产，是对资产本身进行改造、扩建或升级，使资产性能提高、产能增加或效率提升。即使管理层已经批准或明确承诺，只要在减值测试日资产还没有完成改造，就不能把改造后的增量现金流提前算入。

### 例子

设备当前每年产量为 10 万件。管理层已经批准并承诺明年改造设备，改造后每年产量为 15 万件。

减值测试时仍按 10 万件估计。

原因是，改造后增加的 5 万件产能，属于未来改良资产产生的增量，不属于资产当前状况下的现金流量。

如果是已经承诺的重组导致未来成本下降、亏损业务关闭或现金流结构改变，则应当在预计未来现金流量中考虑该重组的影响。

### 记忆口诀

重组：已承诺才考虑。

改良：即使计划明确，也不能提前算未来增量。

## 六、预计未来现金流量现值的折现率口径

### 核心结论

资产减值中计算预计未来现金流量现值，使用的是税前折现率。

口径要一致：

| 项目 | 口径 |
| --- | --- |
| 预计未来现金流量 | 税前口径，通常不考虑所得税收付 |
| 折现率 | 税前折现率 |

### 折现率体现什么

折现率应当反映：

1. 当前市场货币时间价值；
2. 资产特定风险。

折现率不应直接体现：

1. 企业实际借款利率；
2. 财务费用；
3. 所得税影响；
4. 已经在现金流量中调整过的风险。

### 易错点

现金流量不考虑财务费用，不是说折现率要加上或扣掉财务费用。

正确理解是：现金流量不按融资口径算，折现率也不能直接按企业融资成本或借款利率算，而应按资产自身的税前风险和时间价值确定。

### 记忆口诀

税前现金流，税前折现率。

现金流不含财务费用，折现率也不按融资成本定。

## 七、外币未来现金流量现值的折算

### 核心结论

外币未来现金流量，应当先用外币折现，再按即期汇率折算为记账本位币。

处理顺序：

1. 预计以外币表示的未来现金流量；
2. 用该外币适用的折现率折现；
3. 得到外币现金流量现值；
4. 按计算现值当日的即期汇率折算为记账本位币。

### 用哪个汇率

使用计算资产未来现金流量现值当日的即期汇率。

考试中通常理解为：

```text
减值测试日 / 资产负债表日的即期汇率
```

### 易错点

不要先把未来每期外币现金流量按预计未来汇率换成本位币再折现。

### 记忆口诀

外币现金流：先外币折现，后即期汇率折算。

## 八、资产组账面价值与负债的关系

### 核心结论

资产组账面价值和可收回金额的口径要一致。

资产组账面价值通常不包括已确认负债的账面价值。

原因是，预计资产组可收回金额时，通常也不包括与已确认负债有关的现金流量。

### 什么时候要扣负债

如果不考虑某项负债，就无法确定资产组可收回金额，则资产组账面价值中应扣除该负债。

典型情形：

```text
处置资产组时，购买方要求同时承担环境恢复负债等相关义务。
```

此时可收回金额本身是“资产 + 相关负债”一起形成的净额，所以账面价值也要扣除该负债，保证比较口径一致。

### 记忆口诀

负债通常不进资产组。

但可收回金额带了负债，账面价值也要扣负债。

## 九、资产组减值损失的分摊

### 核心结论

资产组发生减值后，减值损失按以下顺序分摊：

1. 首先抵减分摊至资产组中商誉的账面价值；
2. 剩余减值损失，再按资产组中除商誉外其他资产的账面价值比例分摊。

### 单项资产的减值底线

分摊后，单项资产的账面价值不得低于以下三者中的最高者：

1. 该资产公允价值减去处置费用后的净额；
2. 该资产预计未来现金流量的现值；
3. 零。

### 超过底线怎么办

如果某项资产已经减到下限，不能继续承担减值，则多出来不能分给它的减值，继续分摊给其他尚未触底的资产。

继续分摊时，在其他还能承担减值的资产之间，按账面价值比例分摊。

一般不必纠结第一次分摊前还是分摊后，因为只要剩余资产此前是按比例同步减值，它们之间的比例通常不变。

### 记忆口诀

资产组减值：先商誉，后资产。

资产按比例，不能破底线。

谁触底谁退出，剩下继续按比例分。

## 十、总部资产的两层减值测试

### 核心结论

总部资产不能单独产生现金流，减值测试时要看能否合理分摊至资产组。

如果既有能够分摊的总部资产，又有不能分摊的总部资产，应分两层处理：

1. 能够分摊的总部资产，先分摊至各资产组，和各资产组一起测试；
2. 不能分摊的总部资产，放到包含相关资产组的最小资产组组合中，再整体测试。

### 第一步：能分摊的总部资产先分摊

例如，总部资产包括：

| 总部资产 | 能否分摊 | 处理 |
| --- | --- | --- |
| 办公大楼 | 能合理分摊 | 分摊到 A、B、C 资产组 |
| 研发中心 | 不能合理分摊 | 暂不分摊，留到第二层组合测试 |

如果办公大楼能够按合理标准分摊，应先把办公大楼分摊到 A、B、C。

然后分别测试：

```text
A资产组自身资产 + 分摊的办公大楼
B资产组自身资产 + 分摊的办公大楼
C资产组自身资产 + 分摊的办公大楼
```

如果某个资产组发生减值，减值损失在该资产组自身资产和分摊进入的办公大楼之间分摊。

### 第二步：不能分摊的总部资产进入组合测试

第一层测试完成后，再把不能分摊的研发中心放入包含 A、B、C 的最小资产组组合中测试。

这一步的账面价值应当包括：

1. A、B、C 各资产组第一层测试后的账面价值；
2. 能够分摊的总部资产第一层测试后的账面价值；
3. 不能分摊的总部资产账面价值。

然后用这个组合账面价值和资产组组合的可收回金额比较。

### 关键口径：办公大楼是否要再加一次

第二层测试时，办公大楼不能漏掉，也不能重复计算。

关键看题目中 A、B、C 的账面价值是什么口径：

| 题目口径 | 第二层账面价值 |
| --- | --- |
| A、B、C 已经包含分摊后的办公大楼 | A、B、C 调整后账面价值 + 研发中心 |
| A、B、C 只是各资产组自身资产，不含办公大楼 | A、B、C 自身资产调整后账面价值 + 办公大楼调整后账面价值 + 研发中心 |

如果题目把“办公大楼”单独列出来，通常说明 A、B、C 是自身资产口径，不含办公大楼，第二层要单独加办公大楼。

如果题目说的是“含分摊总部资产后的资产组账面价值”，则不能再单独加办公大楼，否则会重复计算。

### 例题口径

题目中，办公大楼可以分摊，研发中心不能分摊。

第一层测试后：

| 项目 | 调整后账面价值 |
| --- | ---: |
| 资产组 A 自身资产 | 200 |
| 资产组 B 自身资产 | 238.55 |
| 资产组 C 自身资产 | 394 |
| 办公大楼 | 274.95 |
| 研发中心 | 100 |

因此，第二层最小资产组组合的账面价值为：

```text
200 + 238.55 + 394 + 274.95 + 100 = 1,207.50
```

这里之所以单独加办公大楼，是因为题目中的 A、B、C 是各资产组自身资产的账面价值，不含办公大楼。

如果该组合的可收回金额高于 1,207.50，则不需要进一步确认包括研发中心在内的组合层面减值。

### 记忆口诀

总部资产先分类：能分摊的先分，不能分摊的后测组合。

第二层看口径：办公大楼单独列，就单独加；已经含在资产组里，就不能再加。

## 十一、资产组减值选择题易错点

### 题目结论

关于资产组减值的表述，正确选项为：

```text
A、D、E、G
```

### 选项判断

| 选项 | 判断 | 核心理由 |
| --- | --- | --- |
| A | 正确 | 认定资产组最关键的因素是资产组能否独立产生现金流入 |
| B | 错误 | 即使产品仅供内部使用，只要存在活跃市场，也可能说明该组合能独立产生现金流入 |
| C | 错误 | 顺序反了。应先以单项资产为基础估计可收回金额；难以估计单项资产可收回金额时，再以资产组为基础 |
| D | 正确 | 认定资产组时，应考虑管理层对生产经营活动的管理方式，以及对资产使用、处置是否一体化决策 |
| E | 正确 | 如果资产组可收回金额口径不包括已确认负债，则资产组账面价值中也应扣除该负债，保持口径一致 |
| F | 错误 | 资产组减值先冲减商誉，再按比例分摊给其他适用资产，不是直接分摊给资产组中所有资产 |
| G | 正确 | 分摊减值后，单项资产账面价值不得低于三者最高者 |

### E 选项重点

E 选项容易误判。

它的核心不是“所有负债都要扣”，而是：

```text
可收回金额和账面价值的比较口径要一致。
```

如果资产组可收回金额没有包括某项已确认负债，资产组账面价值中也应扣除该负债。

### F 选项重点

资产组减值损失不是分摊给资产组中的所有资产。

正确顺序是：

1. 先抵减商誉；
2. 剩余减值再按账面价值比例分摊给其他适用资产；
3. 存货、金融资产等适用其他准则的资产，通常不参与资产减值准则下的资产组减值分摊；
4. 单项资产还要受减值底线限制。

### 记忆口诀

资产组认定看独立现金流，也看管理层一体化决策。

账面价值和可收回金额，口径必须一致。

资产组减值先商誉，后资产；不是所有资产都能分。
