# 持有待售的非流动资产、处置组和终止经营知识点

## 一、持有待售一年期限例外中的意外设定条件

一般要求预计一年内完成出售。一年期限例外须先满足：**非关联方之间的交易**因企业无法控制的原因延期，且有充分证据表明企业仍承诺出售。

买方或其他方意外增加成交条件时，企业须已及时行动，并预计从该条件设定日起一年内化解延期因素。不能以延期例外弥补原本不符合划分条件的问题。

| 污染情形 | 判断（其余划分条件均满足） |
| --- | --- |
| 签约后才发现，买方新增补救要求 | 若原已划分为持有待售，符合上述前提且及时处理、预计条件设定日起一年内解决，可继续划分 |
| 签约前已知，卖方须先清污后买方才接受 | 当前状态不能立即出售，不能划分；不属于后来意外延期 |
| 签约前已知，买方接受现状，价格已反映污染 | 污染本身不妨碍立即出售，可划分 |

“可立即出售”按同类交易的惯常条款判断；不是要求不存在任何交割手续，也不能仅凭污染这一事项名称下结论。

依据：[财政部《企业会计准则第42号》第6、8条](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694145.htm)。


## 二、意外设定条件和发生罕见情况的区别

两类延期均须满足第一节“持有待售一年期限例外”中的非关联方、企业无法控制及持续出售承诺等前提。

| 类型 | 障碍与行动 | 一年口径 |
| --- | --- | --- |
| 意外设定条件 | 买方或其他方新增条件；企业及时行动 | 预计自条件设定日起一年内化解 |
| 发生罕见情况 | 原预计一年内出售未完成；企业针对新情况采取必要措施，重新满足划分条件 | 措施及重新满足条件须在首次划分后的最初一年内，不是事件发生后重新给一年 |

例：A于2X24年12月6日与B签约出售写字楼，预计10个月完成且当日满足持有待售条件。2X25年全球金融危机使价格大跌，B退出并支付违约金；A降价重新营销，于2X25年12月1日与C签约，预计9个月完成。

假设交易非关联、危机造成的延期非A可控且A始终承诺出售：A在最初一年内采取措施、重新满足条件，可按罕见情况例外继续划分。这里“最初一年”从2X24年12月6日起算，不是会计年度，也不是从危机发生日重算。

金融危机、灾害或价格下跌不自动满足例外，仍须逐项核对上表条件。


## 三、持有待售的长期股权投资

### 分类及权益法

下表以拟出售投资已满足持有待售划分条件为前提；单有出售意向不足以划分。

| 投资及出售影响 | 持有待售范围 | 后续处理 |
| --- | --- | --- |
| 子公司：出售将丧失控制权 | 个别报表将对子公司投资整体划分；合并报表将子公司全部资产、负债划分 | 不论出售后是否保留部分权益；控制丧失前仍纳入合并 |
| 子公司：出售不丧失控制权 | 拟出售部分及投资整体均不划分 | 合并层面按权益交易处理，具体见长期股权投资章 |
| 联营、合营：全部拟出售 | 全部划分 | 停止权益法 |
| 联营、合营：部分拟出售 | 仅拟出售部分划分 | 出售部分停止权益法；剩余部分在实际出售前继续权益法 |

### 四组比例例

- 子公司持股80%，出售60个百分点、剩20%并丧失控制：个别报表将原80%投资整体划分，合并报表划分子公司全部资产负债。
- 子公司持股80%，出售10个百分点、剩70%且仍控制：部分及整体均不划分。
- 联营企业持股45%，出售20个百分点、剩25%且仍有重大影响：拟售20%划分，余25%继续权益法。
- 联营企业持股30%，出售20个百分点、余10%暂不卖：划分时仅拟售20%停权益法；余10%在出售前仍用权益法。出售后再按是否保有共同控制或重大影响决定继续权益法还是转金融工具准则。

比例只是题设，控制、共同控制和重大影响须按实质判断，不能单凭持股百分比确定。

原权益法累计其他综合收益等，在终止确认时按长期股权投资处置规则处理，不在划分持有待售时提前结转。处置差额通常计入投资收益；适用长期股权投资准则，不等于该权益性投资不具有金融资产性质。债务FVOCI、权益FVOCI等不同类别的处置处理见金融工具章，不能统一概括为都进投资收益。

依据：[财政部《关于持有待售准则有关问题的解读》](https://kjs.mof.gov.cn/zhengcejiedu/201803/t20180312_2834556.htm)。


## 四、拟结束使用而非出售的非流动资产或处置组

拟结束使用而非出售的资产或处置组不划分为持有待售；仅暂停使用、闲置或准备报废，也不证明企业将主要通过出售收回账面价值。

| 情形 | 持有待售 | 终止经营 |
| --- | --- | --- |
| 单项资产停用、报废 | 不因停用或报废而划分 | 单项资产停用本身不构成可单独区分的经营组成部分 |
| 拟结束使用的处置组，尚未停止使用 | 不划分 | 不因计划停用而列报 |
| 处置组已停止使用 | 仍不因停用而划分 | 符合终止经营规定的组成部分条件时，自停止使用日起列报 |
| 后来改变计划，确实决定出售 | 满足全部划分条件时再判断 | 是否终止经营另按本章末节判断 |

使用寿命结束不是独立分类标准：按原使用计划用尽寿命后报废、回收残值，不等于持有待售；若形成真实出售计划，仍须判断账面价值主要通过出售收回、当前状态可立即出售及出售极可能发生等条件。不能把任何残值变卖都认定为持有待售。


## 五、取得日即划分为持有待售的初始计量

取得日已满足划分条件且适用本准则计量的，初始金额取以下两者孰低：**假定不划分为持有待售的初始计量金额、公允价值减出售费用净额**。普通取得产生的减记计入当期损益；差额处理见第六节“企业合并中新取得资产划分为持有待售”。

| 普通购买例（万元） | 出售净额 | 初始金额 | 损失 |
| --- | --- | --- | --- |
| 成本2000 | 1900 | 1900 | 100 |
| 成本1850 | 1900 | 1850 | 0 |

第一例按净额直接列示初始分录：

```text
借：持有待售资产——长期股权投资 1900
    资产减值损失 100
    贷：银行存款 2000
```

已有资产首次划分前，须先按原准则计量，再按持有待售规则减记并计提准备；不能由本例推出“任何初始划分都不用减值准备”。


## 六、企业合并中新取得资产划分为持有待售

符合取得日划分条件的资产或处置组，仍依第五节“取得日即划分为持有待售的初始计量”的孰低原则；先确定未划分时的计量基础。

| 取得方式 | 未划分时的基础 | 持有待售初始计量 |
| --- | --- | --- |
| 非同一控制下企业合并 | 适用项目通常以公允价值计量 | 公允价值减出售费用净额 |
| 同一控制下企业合并 | 按同控合并规则确定的账面价值 | 该账面价值与出售净额孰低 |

同控合并的账面基础须结合最终控制方合并报表口径等确定，不能无条件照抄被合并方法人账簿。合并中取得的初始差额不套普通购买“差额直接进当期损益”，应结合企业合并准则处理。处置组内不适用持有待售计量的项目，按第七节“哪些项目真正适用持有待售准则计量”所列专门准则处理。


## 七、哪些项目真正适用持有待售准则计量

### 分类范围与计量范围

列入持有待售处置组，不等于全部资产负债都改用同一计量规则。

| 项目 | 计量规则 |
| --- | --- |
| 固定资产、在建工程、无形资产、符合资产确认条件的开发支出、成本模式投资性房地产、使用权资产、长期股权投资等 | 适用持有待售计量；商誉随处置组处理 |
| 公允价值模式投资性房地产；按公允价值减出售费用净额计量的生物资产 | 分别适用投资性房地产、生物资产准则 |
| 职工薪酬形成的资产、递延所得税资产 | 分别适用职工薪酬、所得税准则 |
| 金融工具准则规范的金融资产、保险合同准则规范的权利 | 继续适用相应准则 |
| 存货及处置组负债 | 继续按存货及有关负债准则计量 |

### 处置组减值与转回

1. 首次划分前，先按相关准则计量全部资产、负债；后续重计处置组时，先更新不适用本准则计量项目的账面价值。
2. 比较处置组账面价值与公允价值减出售费用净额，发生减值时先抵减商誉，再按账面价值比例分摊给适用本准则计量的其他非流动资产。
3. 不将该项减值分给存货、金融资产、递延所得税资产或负债；适用资产不减至负数。原准则要求的存货跌价、金融资产减值等仍须计提。

| 后续出售净额回升 | 转回限制 |
| --- | --- |
| 单项非流动资产 | 限于划分后确认的持有待售减值；划分前减值不得转回 |
| 处置组 | 限于划分后适用本准则的非流动资产减值；已抵减商誉及划分前减值不得转回 |
| 处置组内转回分摊 | 按除商誉外、适用本准则计量的各非流动资产账面价值比例增加 |

持有待售非流动资产停止折旧或摊销；处置组负债的利息及其他费用继续确认。最终出售并终止确认处置组时，相关资产负债一并转销，不能把“不分摊持有待售减值”误解为“不转销”。

依据：[财政部《企业会计准则第42号》第3、12—20条](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694145.htm)。


## 八、不再继续划分为持有待售时的计量

### 退出的一般计量

不再满足划分条件，或非流动资产从持有待售处置组中移除时，按下列两者孰低计量：

- 划分前账面价值，按假定未划分时本应确认的折旧、摊销及减值等调整后的金额；
- 可收回金额。

确定转回金额后，再与当前持有待售账面价值比较，确认调整损益；不能只做孰低比较而漏记差额。此项是退出分类的计量调整，不与仍在持有待售期间的减值转回规则混同。

例：划分前账面价值100，持有待售期间减至80，假定未划分时应折旧10，调整后账面价值90。

| 退出时可收回金额 | 转回金额 | 与当前80相比的调整 |
| --- | --- | --- |
| 95 | min(90,95)＝90 | 增加10 |
| 85 | min(90,85)＝85 | 增加5 |

第一种情形按净额示意：

```text
借：固定资产 90
    贷：持有待售资产 80
        资产减值损失 10
```

实际科目有原价、累计折旧或减值准备明细时，同步结转。退出的账面调整列为持续经营损益；子公司、共同经营、合营企业、联营企业及部分联营合营投资退出时，按准则要求调整划分后各可比期间比较数据。联营合营投资恢复权益法的追溯处理，不能机械套本节单项固定资产分录。

### 持有待售与持有待分配互转

按教材的互转口径，处置计划未发生本质变化时，按重分类后类别计量，不按退出规则处理，最初分类日期不重置。例如1月1日划为持有待售、6月1日转为持有待分配，一年期限仍从1月1日观察。该互转细则须与一般取消出售计划的退出区分。

依据：[财政部《企业会计准则第42号》第21、31条](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694145.htm)。互转细则为教材口径，非上述条文原文。


## 九、终止经营的判断

### 定义与列报

对象须是**能够单独区分的组成部分**，已经处置或划分为持有待售，并满足以下任一项：

1. 代表一项独立主要业务或一个单独主要经营地区。
2. 属于处置上述主要业务或地区的相关联计划的一部分。
3. 是专为转售而取得的子公司。

第三项不额外要求该子公司达到主要业务规模。停用资产及拟结束使用处置组的判断见第四节。

| 报表事项 | 处理 |
| --- | --- |
| 当期首次划为持有待售 | 资产负债表分别以流动资产、流动负债列示，不抵销；比较期资产负债表不重新划分 |
| 当期列报终止经营 | 利润表比较期相关损益重列为终止经营 |
| 持有待售但不构成终止经营 | 减值、转回及处置损益仍列持续经营 |
| 原终止经营不再满足持有待售条件 | 比较期原终止经营信息重列为持续经营，并披露 |

### 停业例

集团C的子公司H经营一项独立主要业务——药品批发。至2X25年10月13日已处置全部存货、辞退全部员工并停止业务，尚有债权待收及营业网点租约未到期。H自该日起符合终止经营定义；仅剩清理事项不意味着药品批发业务仍持续。

### 出售天然气子公司例（万元）

甲有焦煤、天然气两项主要业务，天然气由全资子公司乙经营。2X24年12月31日批准并签订出售全部乙股权的协议，价款13500，预计次年3月末过户；假设当日满足全部持有待售条件，价格代表公允价值，无出售费用、税费及其他调整，且有足够适用本准则的资产承担减值。

乙年末资产26000、负债12000，2X23年净利润1000、2X24年净利润800。乙同时构成持有待售处置组及终止经营：

| 计算或列示 | 结果 |
| --- | --- |
| 减值前净资产 | 26000−12000＝14000 |
| 处置组减值 | 14000−13500＝500 |
| 2X24年终止经营损益 | 800−500＝300 |
| 2X23年利润表比较信息 | 1000重列为终止经营损益 |
| 2X24年末持有待售资产、负债 | 资产25500、负债12000，分别列示 |
| 2X23年末资产负债表比较信息 | 不重列为持有待售 |

依据：[财政部《企业会计准则第42号》第4、23—28、32条](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694145.htm)。
