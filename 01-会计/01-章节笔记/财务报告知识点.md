# 财务报告知识点

## 一、总额列报原则与不属于抵销的净额列示

### 核心结论

财务报表项目原则上应当总额列报，资产和负债、收入和费用不能互相抵销后按净额列报。

但是，有些项目虽然以净额列示，准则认为其本质不是抵销，而是更好地反映交易实质。

```text
原则：资产和负债、收入和费用不得互相抵销。
例外：准则允许或交易实质要求净额反映的，不属于抵销。
```

### 三类不属于抵销的情形

| 情形 | 白话理解 | 典型例子 |
| --- | --- | --- |
| 一组类似交易形成的利得和损失以净额列示，但具有重要性的除外 | 同类交易本来就看净影响，逐笔列示反而不清楚 | 交易性金融资产公允价值变动收益和损失轧差 |
| 资产或负债项目按扣除备抵项目后的净额列示 | 备抵不是另一项负债或资产，而是原项目的估计抵减 | 应收账款扣减坏账准备后列示 |
| 非日常活动、偶然发生、不是企业主要业务的交易，净额列示更能反映交易实质 | 企业赚的不是总流水，而是处置差额 | 固定资产处置收益、投资处置收益 |

### 第 1 类：类似交易利得和损失为什么可以净额

一组类似交易形成的利得和损失，关注点通常不是每一笔收入和费用的总流水，而是该类交易对利润的净影响。

例如：

```text
交易性金融资产公允价值上升 100；
交易性金融资产公允价值下降 30。
```

报表可以反映：

```text
公允价值变动收益 70
```

这不是违法抵销，而是把同类公允价值变动的净影响列示出来。

但如果某项利得或损失金额重大，不能藏在净额里，应当单独列示或披露。

### 第 3 类：非日常偶发交易为什么更适合净额

非日常活动、偶然发生、并非企业主要业务的交易，企业通常不是靠总交易额体现经营规模，而是通过差额体现交易结果。

典型例子：处置固定资产。

```text
售价 100；
账面价值 80；
清理费用 5。
```

真正影响利润的是：

```text
资产处置收益 = 100 - 80 - 5 = 15
```

如果把售价 100 列作收入、把账面价值和清理费用 85 列作费用，反而容易让人误以为企业有一项 100 的日常经营收入。

所以净额列示 15，更能反映这项偶发交易的经济实质。

### 易错点

1. 不能把“净额列示”直接等同于“抵销”；准则认可的净额列示不属于抵销。
2. 第 1 类看的是同类交易的净影响，但重要项目不能被净额掩盖。
3. 第 3 类常见于资产处置等非主营、偶发交易，报表关注处置损益，而不是处置价款总额。
4. 资产或负债扣除备抵项目后列示，例如应收账款扣坏账准备，是资产计量口径，不是资产负债互抵。

### 记忆口诀

```text
报表原则列总额；
类似利损看净额；
备抵扣减不是抵；
偶发处置看差额。
```

## 二、预计负债和可转换工具负债成分的流动性列报

### 核心结论

财务报告中，负债列报为流动负债还是非流动负债，核心看企业是否预计或有权在一年或一个营业周期以后清偿。

两个容易混淆的特殊点：

```text
质量保证预计负债：能估计一年内清偿多少，就按清偿期限拆；
不能合理估计一年内清偿金额，就全部列入其他流动负债。

可转换工具负债成分：如果交易对手方可以选择企业用自身权益工具清偿，
且该选择权按金融工具准则分类为权益工具，
通常不影响该负债成分的流动性划分。
```

### 一、保证类质量保证形成的预计负债

企业销售产品并提供保证类质量保证，通常会形成预计负债。

账上科目可能是：

```text
借：销售费用
    贷：预计负债
```

但是列报时不能只看账上科目名字，而要看预计清偿时间。

| 情形 | 报表列报 |
| --- | --- |
| 预计未来一年或一个营业周期内清偿的金额 | 一年内到期的非流动负债 |
| 预计超过一年或一个营业周期以后清偿的金额 | 预计负债 |
| 不能合理估计未来一年或一个营业周期内清偿金额 | 全部列入其他流动负债 |

这里的逻辑是：

```text
能拆，就按期限拆；
不能拆，就全部作为流动列示。
```

### 二、可转换工具负债成分的流动性

可转换债券等工具可能同时包含：

```text
负债成分；
权益成分。
```

如果合同条款导致交易对手方可以选择企业通过交付自身权益工具清偿，而且该选择权按《企业会计准则第 37 号——金融工具列报》分类为权益工具，那么这个选择权通常不影响负债成分的流动性划分。

也就是说，不能因为持有人可能选择转股，就直接把负债成分列为流动负债。

判断负债成分流动性时，仍然看企业是否具有递延现金清偿义务超过一年或一个营业周期的权利。

### 易错点

1. 账上用“预计负债”科目，不代表报表上一定全列非流动负债。
2. 保证类质量保证预计负债能估计一年内清偿金额时，要拆分列报。
3. 不能合理估计一年内清偿金额时，不是全列“预计负债”，而是全部列入“其他流动负债”。
4. 可转债持有人可以转股，不等于负债成分自动变成流动负债；转股权分类为权益工具时，不影响负债成分的流动性划分。

### 记忆口诀

```text
质量保证看清偿；
能拆一年内，不能拆全流动。

可转债看现金义务；
权益转股权，不改负债流动性。
```

## 三、会计科目在资产负债表中的报表项目名称对照

### 核心结论

这里讨论的是资产负债表报表项目，不是账务处理中的会计科目名称。

```text
先看账上科目，再看财务报表格式要求填到哪个项目；
不能把会计科目名称和报表项目名称机械等同。
```

### 对照表

| 会计科目或余额 | 流动资产/负债项目名称 | 非流动资产/负债项目名称 | 关键说明 |
| --- | --- | --- | --- |
| 自资产负债表日起一年内到期的长期债权投资 | 一年内到期的非流动资产 | 不适用 | 原本按长期资产管理，后来临近到期，转列“一年内到期的非流动资产” |
| 购入时剩余期限不超过一年的以摊余成本计量的债权投资 | 其他流动资产 | 不适用 | 一开始买入时就是短期项目，列“其他流动资产”，不列“一年内到期的非流动资产” |
| 自资产负债表日起一年内到期的长期其他债权投资 | 一年内到期的非流动资产 | 不适用 | 原本属于长期其他债权投资，后来临近到期，转列“一年内到期的非流动资产” |
| 购入时剩余期限不超过一年的以公允价值计量且其变动计入其他综合收益的债权投资 | 其他流动资产 | 不适用 | 一开始买入时就是短期债权类投资，列“其他流动资产” |
| 递延收益 | 不适用 | 递延收益 | 摊销期限只剩一年或预计一年内摊销的部分，仍列“递延收益”，不转“一年内到期的非流动负债” |
| 合同资产科目借方净额 | 合同资产 | 其他非流动资产 | 同一合同下合同资产和合同负债先净额列示；借方净额按流动性填列，且要扣除相关合同资产减值准备 |
| 合同负债科目贷方净额 | 合同负债 | 其他非流动负债 | 同一合同下贷方净额按流动性填列 |
| 预计负债科目余额 | 一年内到期的非流动负债 / 其他流动负债 | 预计负债 | 长期部分列“预计负债”；期限一年以上的保证类质量保证预计负债，能估计一年内清偿金额的，短期部分列“一年内到期的非流动负债”；不能合理估计一年内清偿金额的，全部列“其他流动负债” |

### 补充提醒

一年内到期的非流动资产，是报表项目名称，不是说它仍列在非流动资产部分。它专门反映从长期资产项目转入、资产负债表日起一年内到期的长期债权投资等。

```red
债权投资和其他债权投资的短期列报，关键不是看科目名称，而是看来源：原本是长期、资产负债表日起一年内到期，列“一年内到期的非流动资产”；购入时剩余期限就不超过一年，列“其他流动资产”。
```

递延收益比较特殊：即使预计一年内摊销，也仍在“递延收益”项目填列。不要把一年内摊销部分转到“一年内到期的非流动负债”。

合同资产、合同负债先看同一合同下净额是借方还是贷方，再按表格列报。

### 易错点

1. “一年内到期的非流动资产”是报表项目名称，列在流动资产部分。
2. <span class="text-danger">长期债权投资或长期其他债权投资临近一年内到期，列“一年内到期的非流动资产”；买入时剩余期限就不超过一年的债权投资或其他债权投资，列“其他流动资产”。</span>
3. 递延收益一年内摊销的部分，仍列“递延收益”，不转“一年内到期的非流动负债”。
4. 合同资产、合同负债不是简单按科目余额原样列，要先看同一合同下净额是借方还是贷方。
5. 合同资产长期部分列“其他非流动资产”，合同负债长期部分列“其他非流动负债”。
6. 预计负债科目不一定只对应报表项目“预计负债”，短期或无法合理拆分的质量保证义务可能列其他流动负债或一年内到期的非流动负债。

### 记忆口诀

```text
递延收益就填递延收益；
债投看来源，长期转短列到期，一开始短列其他；
合同借方看资产，合同贷方看负债；
合同长期进其他非流动；
预计负债看清偿，质保短期有特殊列报。
```

## 四、预收购物卡、保洁服务和租金的报表项目列报

### 核心结论

同样是预收款，要先判断适用哪个准则：

```text
购物卡、保洁服务：适用收入准则；
出租商场铺位收取租金：适用租赁准则。
```

收入准则下的预收款，通常拆成：

```text
不含税履约义务 -> 合同负债；
待转销项税额 -> 其他流动负债。
```

租赁准则下出租人预收租金，通常作为：

```text
含税预收租金 -> 预收款项。
```

因此，租赁部分的增值税不并入收入准则下“其他流动负债——待转销项税额”的计算。

### 例题拆解

甲公司经营百货商场：

```text
1 至 2 层：自营销售商品；
3 至 5 层：出租给教育培训机构和餐饮企业，并提供保洁服务。
```

2X25 年 12 月 31 日：

```text
出售购物卡收到 56.5 万元，含增值税，税率 13%；
预收 1 年租金和服务费 106 万元，含增值税；
其中保洁服务费 10.6 万元，税率 6%；
租赁税率 9%。
```

### 第一步：购物卡

购物卡属于收入准则，先确认为合同负债，不含税金额：

```text
56.5 / 1.13 = 50（万元）
```

待转销项税额：

```text
56.5 - 50 = 6.5（万元）
```

列报：

```text
合同负债 50；
其他流动负债 6.5。
```

预计客户放弃使用 5%：

```text
50 * 5% = 2.5（万元）
```

但这不是售卡当日直接确认收入。预计未行使权利收入应当随着客户实际使用权利的模式确认；题目没有发生消费，因此不确认营业收入 2.5。

### 第二步：预收租金和保洁服务费

先拆业务性质：

```text
租赁部分含税金额 = 106 - 10.6 = 95.4（万元）
保洁服务含税金额 = 10.6（万元）
```

租赁部分适用租赁准则：

```text
预收款项 95.4
```

这里按题目列报口径，不把租赁部分再拆成合同负债和待转销项税额。

保洁服务适用收入准则：

```text
10.6 / 1.06 = 10（万元）
```

待转销项税额：

```text
10.6 - 10 = 0.6（万元）
```

列报：

```text
合同负债 10；
其他流动负债 0.6。
```

### 汇总结果

| 报表项目 | 金额 | 来源 |
| --- | --- | --- |
| 预收款项 | 95.4 | 租赁部分含税预收租金 |
| 合同负债 | 60 | 购物卡不含税 50 + 保洁服务不含税 10 |
| 其他流动负债 | 7.1 | 购物卡待转销项税额 6.5 + 保洁服务待转销项税额 0.6 |
| 营业收入 | 0 | 购物卡预计放弃部分不能在售卡日直接确认收入 |

### 易错点

1. 不要把租赁准则下的预收租金列入合同负债。
2. 不要把租赁部分的增值税加入收入准则下“其他流动负债——待转销项税额”的金额。
3. 购物卡预计 breakage 不是售卡日直接确认收入，而是随客户实际使用权利的模式确认。
4. 同一笔收款里既有租赁又有服务时，要先拆准则范围，再做报表项目列报。

### 记忆口诀

```text
购物卡、保洁，收入准则拆税；
不含税进合同负债，待转税进其他流动；
租金走租赁，含税进预收款项；
breakage 不在售卡日一把进收入。
```

## 五、收入准则和金融工具相关科目的资产负债表项目列报

### 核心结论

这段主要讲收入准则和金融工具准则下若干特殊科目在资产负债表上的项目名称。

```text
合同取得成本：看摊销期，列其他流动资产或其他非流动资产；
合同履约成本：短期通常列存货，长期列其他非流动资产；
应收退货成本：看相关商品预计出售期限，列其他流动资产或其他非流动资产；
应付退货款：看预计清偿期限，列其他流动负债或预计负债；
贷款承诺、财务担保损失准备：列预计负债；
企业发行的权益工具：分类为权益工具列其他权益工具，分类为金融负债列应付债券。
```

### 报表项目对照表

| 账上科目或事项 | 流动资产/负债项目名称 | 非流动资产/负债项目名称 | 判断口径 |
| --- | --- | --- | --- |
| 合同取得成本 | 其他流动资产 | 其他非流动资产 | 根据初始确认时摊销期限是否超过一年或一个正常营业周期判断；已计提减值的，扣减合同取得成本减值准备后的余额列示 |
| 合同履约成本 | 存货 | 其他非流动资产 | 根据初始确认时摊销期限是否超过一年或一个正常营业周期判断；短期履约成本通常列存货，长期履约成本列其他非流动资产；已计提减值的，扣减合同履约成本减值准备 |
| 合同负债 | 合同负债 | 其他非流动负债 | <span class="text-danger">长期合同负债快到期时，从“其他非流动负债”转列“合同负债”，不转入“一年内到期的非流动负债”。</span> |
| 应收退货成本 | 其他流动资产 | 其他非流动资产 | 根据相关商品预计是否在一年或一个正常营业周期内出售判断 |
| 预计负债——应付退货款 | 其他流动负债 | 预计负债 | 根据预计是否在一年或一个正常营业周期内清偿判断 |
| 贷款承诺、财务担保合同计提的损失准备 | 通常不适用 | 预计负债 | 按金融工具准则确认的损失准备，在预计负债项目列示 |
| 企业发行在外、分类为权益工具的金融工具 | 不适用 | 其他权益工具 | 反映普通股以外分类为权益工具的金融工具期末账面价值 |
| 企业发行的金融工具，分类为金融负债 | 一年内到期的非流动负债等 | 应付债券 | 优先股、永续债如果分类为金融负债，在应付债券项目下分别列示；一年内到期的部分按流动负债列示 |
| 企业发行的优先股、永续债，分类为权益工具 | 不适用 | 其他权益工具 | 在其他权益工具项目下的优先股、永续债项目分别列示 |

### 补充提醒

合同履约成本短期通常更接近为履约而持有的资产，所以列“存货”；合同取得成本不是为生产或交付商品形成的存货，通常列其他流动资产或其他非流动资产。

优先股、永续债要先判断分类为金融负债还是权益工具，再分别列“应付债券”或“其他权益工具”。

### 易错点

1. 合同取得成本不列“合同资产”，而是列其他流动资产或其他非流动资产。
2. 合同履约成本短期通常列“存货”，不是一律列合同资产或其他非流动资产。
3. 应收退货成本是资产，预计负债——应付退货款是负债，方向不要反。
4. 贷款承诺、财务担保合同的损失准备列“预计负债”，不要放到坏账准备或合同负债。
5. 优先股、永续债不能只看名称，要先判断分类为金融负债还是权益工具。

### 记忆口诀

```text
取得成本看摊销，其他流动或非流动；
履约成本短存货，长期其他非流动；
退货成本是资产，退货款项是负债；
担保承诺进预计；
永续优先先分类，负债应付债券，权益其他权益工具。
```

## 六、银行承兑汇票贴现的现金流量表分类

### 核心结论

银行承兑汇票贴现的现金流量分类，关键看贴现时应收票据是否满足金融资产终止确认条件。

```text
满足终止确认条件：本质是经营性应收票据变现，列经营活动现金流入；
不满足终止确认条件：本质更像以票据质押取得借款，列筹资活动现金流入。
```

### 判断逻辑

| 情形 | 会计实质 | 现金流量表分类 |
| --- | --- | --- |
| 贴现满足金融资产终止确认条件 | 应收票据真正变现 | 经营活动现金流入 |
| 贴现不满足金融资产终止确认条件 | 票据风险未转移，收到的款项实质为借款 | 筹资活动现金流入 |
| 不满足终止确认条件，后续票据到期偿付、借款终止确认，但企业没有现金收付 | 只是账面结清 | 不虚拟确认现金流量 |

### 为什么一边是经营、一边是筹资

应收票据通常来自销售商品、提供劳务。

如果贴现满足终止确认条件，说明票据已经真正卖掉或变现，企业不再承担主要票据风险。这笔现金的源头仍然是销售商品、提供劳务形成的收款，只是收款形式从票据变成现金，因此列经营活动现金流入。

如果贴现不满足终止确认条件，说明票据没有真正卖掉，相关风险仍留在企业。如果付款人到期不付款，企业还可能承担追索责任。银行给企业的现金更像企业以票据作担保或质押取得借款，因此列筹资活动现金流入。

### 易错点

1. 不要看到“贴现收到现金”就一律列经营活动；先看是否终止确认。
2. 不满足终止确认时，资产负债表上通常确认借款或相关负债，现金流量表中取得现金属于筹资活动。
3. 商业承兑汇票贴现不必然列筹资活动；只有不满足金融资产终止确认条件时，才按类似质押借款的逻辑列筹资活动现金流入。
4. 后续票据到期、借款终止确认，如果企业没有真实现金收付，不得为了分录配平虚拟现金流。

### 记忆口诀

```text
贴现看终止；
终止是经营，不终止是筹资；
后续无现金，不虚列现金流。
```

## 七、定期存单质押和解除质押的现金流量表分类

### 核心结论

定期存单质押是否产生现金流量，第一步不是看“质押”两个字，而是看定期存单本身是否属于现金及现金等价物。

```text
定期存单本身不属于现金及现金等价物：
质押、解除质押都不产生现金流量。

定期存单本身属于现金及现金等价物：
质押后使用受限、不再符合定义，视为现金及现金等价物流出；
解除质押后重新符合定义，视为现金及现金等价物流入。
```

### 完整业务场景

甲公司为一般非金融企业。2X25 年 12 月 1 日，甲公司将闲置资金 1,000 万元存入银行，形成 3 个月期定期存单。该存单期限短、流动性强、易于转换为已知金额现金，价值变动风险很小，因此作为现金及现金等价物管理。

2X25 年 12 月 20 日，甲公司向银行借入短期借款 800 万元，并将上述 1,000 万元定期存单质押给银行。质押期间，存单不能随时支取或自由用于支付。

| 事项 | 现金流量表影响 |
| --- | --- |
| 购买 3 个月期定期存单，且符合现金等价物定义 | 现金与现金等价物之间转换，不产生现金流量 |
| 取得短期借款 800 万元 | 一般非金融企业列筹资活动现金流入 |
| 存单质押，不再符合现金等价物定义 | 一般非金融企业列筹资活动现金流出 |
| 偿还短期借款 800 万元 | 筹资活动现金流出 |
| 存单解除质押，重新符合现金等价物定义 | 一般非金融企业列筹资活动现金流入 |

### 行业判断

现金流量分类还要结合企业所属行业。

```text
金融企业：通过定期存款质押获取短期借款，可能属于经营活动；
一般非金融企业：通过定期存款质押获取短期借款，通常属于筹资活动。
```

### 易错点

1. 如果定期存单本身不属于现金及现金等价物，质押和解除质押不会产生现金流量。
2. 如果定期存单原本属于现金及现金等价物，质押导致使用受限，才会导致现金及现金等价物范围变化。
3. 这里的现金流量不是银行账户真的少了一笔钱，而是“现金及现金等价物范围”发生了变化。
4. 分类不是固定经营或筹资，要结合企业是否金融企业以及业务目的判断。

### 记忆口诀

```text
先看是不是现金等价物；
不是，质押解押不进表；
是，质押流出，解押流入；
金融看经营，一般看筹资。
```

## 八、承租人租赁付款的现金流量表分类

### 核心结论

承租人支付租赁相关款项时，先看这笔款项是否纳入租赁负债。

```text
租赁负债本金和利息：通常计入筹资活动现金流出；
短期租赁付款额、低价值资产租赁付款额：通常计入经营活动现金流出；
未纳入租赁负债的可变租赁付款额：通常计入经营活动现金流出。
```

```red
未纳入租赁负债的可变租赁付款额，不属于租赁负债本金或利息的偿付，现金流量表中通常列经营活动现金流出。
```

### 对照表

| 承租人支付项目 | 现金流量表分类 |
| --- | --- |
| 偿还租赁负债本金 | 筹资活动现金流出 |
| 支付租赁负债利息 | 筹资活动现金流出 |
| 支付短期租赁付款额 | 经营活动现金流出 |
| 支付低价值资产租赁付款额 | 经营活动现金流出 |
| 支付未纳入租赁负债的可变租赁付款额 | 经营活动现金流出 |
| 支付租赁预付款、租赁保证金 | 通常计入筹资活动现金流出 |

### 易错点

1. 不要把所有“租金付款”都列筹资活动；关键看是否进入租赁负债。
2. 短期租赁、低价值资产租赁未形成租赁负债的付款额，通常列经营活动现金流出。
3. <span class="text-danger">未纳入租赁负债的可变租赁付款额，通常列经营活动现金流出。</span>
4. 租赁预付款和租赁保证金，教材口径下计入筹资活动现金流出。

### 记忆口诀

```text
进租赁负债，多走筹资；
短租低值，经营流出；
可变未纳入，经营流出；
预付保证，筹资流出。
```

## 九、银行承兑汇票背书购买原材料的现金流量表处理

### 核心结论

以银行承兑汇票背书购买原材料，通常不作为经营活动现金流出。

原因是：现金流量表主表反映的是现金及现金等价物的流入和流出；银行承兑汇票属于票据权利，不是现金及现金等价物。企业背书转让票据取得原材料，本质是以票据权利结算采购款，不发生现金及现金等价物流出。

```red
看到“购买原材料”不能直接判断为经营活动现金流出；还要看付款方式。用银行存款支付才有经营活动现金流出，用银行承兑汇票背书支付通常不产生现金流量。
```

### 对照表

| 事项 | 现金流量表影响 |
| --- | --- |
| 用银行存款购买原材料 | 购买商品、接受劳务支付的现金，列经营活动现金流出 |
| 以银行承兑汇票背书购买原材料 | 不产生现金流量，属于非现金结算交易 |
| 银行承兑汇票贴现取得现金 | 先看是否满足金融资产终止确认条件：满足终止确认通常列经营活动现金流入；不满足终止确认通常列筹资活动现金流入 |

### 判断逻辑

1. 先判断有没有现金及现金等价物发生流入或流出。
2. 银行承兑汇票背书只是票据权利转移，不是银行存款、库存现金等现金及现金等价物流出。
3. 因此，虽然交易内容是采购原材料，但现金流量表主表不列“购买商品、接受劳务支付的现金”。
4. 如果题目问补充资料或非现金交易信息，可以关注其作为不涉及现金收支的重大投资和筹资活动或非现金交易披露的可能性；但主表不虚拟列示现金流。

### 易错点

1. 不要把“采购原材料”和“经营活动现金流出”机械绑定，现金流量表看的是现金收付。
2. 不要把“票据背书采购”和“票据贴现收现”混在一起：背书采购没有收现或付现，贴现才有现金流入。
3. 不要为了体现采购业务，在现金流量表中虚拟列一笔现金流出。

### 记忆口诀

```text
银行存款买材料，经营流出；
票据背书买材料，不进主表；
票据贴现收现金，再看终止确认。
```

## 十、报告分部当年达标与以后不达标的列报

### 核心结论

经营分部是否作为报告分部，不能只用“上年有没有单独列报”来否定本年的列报。

```text
本年首次达到报告分部确定条件：本年应作为报告分部单独披露。
为保证可比性：上年比较信息通常应按本年口径重述。
以后年度未达到数量标准：不一定马上取消，若管理层认为仍重要，仍应继续单独披露。
```

### 当年新达标

如果 W 经营分部在本年度达到报告分部的确定条件，即使上年度未达到，也应当在本年度作为单独的报告分部列报。

可比性要求不是“不让本年单列”，而是要求企业尽量让本年和上年数据具有可比口径。

```text
本年 W 达标
=> 本年单独列报
=> 上年比较数据能够取得且编制成本不过高的，按本年口径重述
```

如果上年相关信息无法取得，或者取得成本过高，可以不重述上年比较信息，但不影响本年单独披露。

```red
“上年未达到报告分部条件，所以本年即使达到也不单独披露”是错误说法。可比性要求解决的是比较信息口径，不是否定本年报告分部身份。
```

### 以后不达标

如果某分部以前年度已经作为报告分部披露，本年度未达到数量标准，并不必然马上取消。

```text
以前年度已经作为报告分部披露
本年度未达到数量标准
但管理层认为该分部仍然重要
=> 本年度仍应继续作为报告分部单独披露
```

如果管理层认为该分部已经不重要，可以不再作为单独报告分部披露，而是并入其他分部或“其他”项目。

### 记忆口诀

```text
今年新达标：本年单列，比较数据尽量重述。
今年不达标：不一定撤，看是否仍重要。
```

### 易错点

1. 不要把可比性要求理解成“本年不能新增报告分部”。
2. 新达标分部本年应单独披露，比较期间信息只是重述问题。
3. 以前已披露的报告分部以后不达标，是否继续单独披露，要看管理层是否认为仍重要。

## 十一、关联方关系的认定框架

### 核心结论

关联方关系的存在，通常以控制、共同控制或者重大影响为前提，并遵循实质重于形式原则。

```text
控制链条都算；
控制或共同控制可以搭桥，两个重大影响不能搭桥；
关键管理人员和关系密切家庭成员要看影响力；
普通交易对象和仅同受国家控制，不当然构成关联方。
```

### 五组判断对象

| 判断组别 | 通常构成关联方 | 易错边界 |
| --- | --- | --- |
| 控制关系 | 母公司、子公司、同受一方控制的兄弟公司、间接控制链条上的企业 | 控制可以直接，也可以间接 |
| 共同控制 | 对本企业实施共同控制的投资方、<span class="text-danger">本企业的合营企业及其子公司</span> | 共同控制同一企业的几个投资方之间，不仅因共同控制同一对象就互为关联方 |
| 重大影响 | 对本企业施加重大影响的投资方、<span class="text-danger">本企业的联营企业及其子公司</span> | 多个对同一企业有重大影响的投资方之间，不仅因共同影响同一对象就互为关联方 |
| 个人相关 | <span class="text-danger">主要投资者个人、关键管理人员及其关系密切的家庭成员，以及由这些人员控制、共同控制或施加重大影响的企业，通常属于关联方。</span> | 仅有同一位关键管理人员的两家企业，不当然构成关联方 |
| 特殊主体 | 企业设立的企业年金基金；为企业关键管理人员提供服务的服务提供方等 | 关键管理人员服务提供方与服务接受方的判断有方向性 |

### 常见认定

1. A 控制 B，B 控制 C：A 与 B、B 与 C、A 与 C 都是关联方。
2. C 同时控制 A 和 B：A 与 B 属于同受一方控制的兄弟公司，构成关联方。
3. A、B、C 共同控制 D：A 与 D、B 与 D、C 与 D 是关联方；A、B、C 之间不因此当然构成关联方。
4. A 对 D 有重大影响：A 与 D 是关联方；多个对 D 有重大影响的投资方之间，不因此当然互为关联方。

### 同一方连接两家企业的横向判断

| 同一方 A 对 B、C 的关系 | B 和 C 是否构成关联方 | 理解 |
| --- | --- | --- |
| A 控制 B，A 控制 C | 构成 | 同受一方控制 |
| A 控制 B，A 共同控制 C | 构成 | 控制可以搭桥 |
| A 控制 B，A 重大影响 C | 构成 | 控制可以搭桥 |
| A 共同控制 B，A 共同控制 C | 构成 | 共同控制可以搭桥 |
| A 共同控制 B，A 重大影响 C | 构成 | 共同控制可以搭桥 |
| A 重大影响 B，A 重大影响 C | 不当然构成 | 两边都只是重大影响，影响力不够强 |

### 持股比例例题：直接持股加间接影响

甲公司持有乙公司 80% 股份，持有丙公司 10% 股份，乙公司持有丙公司 15% 股份。题目假设 20% 以下不具有控制、共同控制和重大影响，50% 以上形成控制，20% 至 50% 形成重大影响。

```text
甲持有乙 80% -> 甲控制乙；
甲直接持有丙 10%；
乙持有丙 15%，且乙受甲控制；
甲对丙的影响 = 10% + 15% = 25%；
25% -> 甲对丙具有重大影响。
```

因此：

| 选项 | 是否构成关联方 | 理由 |
| --- | --- | --- |
| 甲公司与乙公司 | 构成 | 甲控制乙 |
| 甲公司总经理的妻子与乙公司 | 构成 | 总经理是关键管理人员，其妻子是关系密切家庭成员；乙公司是甲控制的子公司 |
| 甲公司与丙公司 | 构成 | 甲对丙直接 10% 加通过控制乙公司形成的 15% 影响，合计 25%，构成重大影响 |
| 甲公司与丁公司 | 构成 | 丁公司向甲公司提供关键管理人员服务，甲公司作为服务接受方编报时将丁公司作为关联方披露 |

```red
判断控制、共同控制或重大影响时，不只看直接持股；通过受控制子公司形成的间接持股或影响也要纳入判断。甲直接持有丙 10%，再通过控制乙影响乙持有丙的 15%，合计 25%，所以甲与丙构成关联方。
```

### 不构成关联方的典型情形

1. 普通资金提供者、公用事业部门、政府部门和机构。
2. 普通客户、供应商、特许商、经销商、代理商。
3. 与企业共同控制合营企业的合营者之间。
4. 仅仅同受国家控制而不存在其他关联方关系的企业。
5. 两方或两方以上受同一方重大影响的企业之间。

```red
共同控制、重大影响不要“横向扩散”：投资方与被投资方有关联，但投资方彼此之间不当然有关联。
```

```red
同一方连接两家企业时，控制或共同控制可以“搭桥”：控制+重大影响、共同控制+重大影响通常能让两方构成关联方；但重大影响+重大影响不搭桥，两方或两方以上仅受同一方重大影响的企业之间不当然构成关联方。
```

```red
共控同一对象的投资者之间：不当然关联；重大影响同一对象的投资者之间：不当然关联。除非这些投资者之间另有控制、共同控制、重大影响、同受控制或关键管理人员等其他关联关系。
```

```red
主要投资者个人、关键管理人员及其关系密切的家庭成员，如果控制、共同控制或施加重大影响其他企业，该其他企业通常属于本企业的关联方。这里的“具体分析”主要用于判断家庭成员是否关系密切、是否可能影响该个人或受该个人影响；关键管理人员本人控制、共同控制或重大影响的企业，通常直接按关联方处理。
```

```red
本企业的合营企业、联营企业是关联方；合营企业控制的子公司、联营企业控制的子公司，通常也沿着控制链条作为本企业的关联方判断。但两个不同联营企业彼此之间，仍不因同属联营企业网络而自动关联。
```

### 披露规则

1. 企业无论是否发生关联方交易，均应披露与该企业之间存在控制关系的母公司和子公司有关信息。
2. 企业与关联方发生关联方交易的，应披露关联方关系性质、交易类型及交易要素。
3. 对外提供合并财务报表的，已经包含在合并范围内各企业之间的交易不披露。

### 记忆口诀

```text
控制链条都算；
控、共控能搭桥；
两个重影不搭桥；
关键人员看影响；
普通交易别误判。
```

## 十二、合并报表中与合并范围外关联方的交易披露

### 核心结论

编制合并财务报表时，只是不披露合并范围内企业之间已经抵销的内部交易；对于合并范围外但存在关联方关系的企业，相关交易仍需要作为关联方交易披露。

```text
合并范围内彼此交易：抵销，不披露关联方交易。
合并范围外但有关联关系：不抵销，仍披露关联方交易。
```

### 例子

甲公司控制乙公司，并对丙公司具有重大影响。甲公司编制合并报表：

```text
甲公司 + 乙公司 = 合并范围内集团
丙公司 = 合并范围外联营企业 / 关联方
```

因此：

| 交易 | 合并报表中的关联方披露 |
| --- | --- |
| 甲公司与乙公司交易 | 合并范围内内部交易，抵销后不作为关联方交易披露 |
| 甲公司与丙公司交易 | 丙公司在合并范围外，且为联营企业，仍需披露 |
| 乙公司与丙公司交易 | 站在集团角度，属于集团成员与合并范围外关联方交易，通常仍需披露 |

```red
合并报表不披露的是“合并范围内企业之间的内部交易”，不是把所有关联方交易都免披露。联营企业、合营企业等合并范围外关联方，与集团发生交易仍要披露。
```

### 记忆口诀

```text
进合并范围，内部抵销不披露；
没进合并范围，关联交易仍披露。
```

## 十三、企业集团边界与集团成员联营企业之间的关联方判断

### 核心结论

企业集团以控制关系为基础圈定。母公司和被其控制的子公司属于同一企业集团；联营企业、合营企业通常不纳入企业集团成员范围。

```text
集团靠控制圈定；
联营企业在集团外；
集团成员能关联到集团成员的联营企业；
两个联营企业之间不自动关联。
```

### 典型结构

甲公司控制乙公司和丙公司，丁公司是乙公司的联营企业，戊公司是丙公司的联营企业。

```text
        甲公司
       /    \
    控制    控制
    乙公司  丙公司
      |       |
   重大影响 重大影响
    丁公司  戊公司
```

这里的企业集团成员是：

```text
甲公司、乙公司、丙公司
```

丁公司、戊公司只是集团成员单位的联营企业，不是甲公司集团内的成员单位。

### 逐项判断

| 关系 | 是否构成关联方 | 理由 |
| --- | --- | --- |
| 甲公司与丁公司 | 构成 | 丁公司是甲公司所属企业集团内成员单位乙公司的联营企业 |
| 乙公司与丙公司 | 构成 | 乙、丙同受甲公司控制，属于同一集团成员 |
| 丙公司与丁公司 | 构成 | 丙公司是集团成员，丁公司是集团内其他成员单位乙公司的联营企业 |
| 丁公司与戊公司 | 不当然构成 | 丁、戊都是集团外联营企业，二者之间只是重大影响 + 重大影响，不自动搭桥 |

```red
“企业与其所属企业集团内其他成员单位的联营企业”这条，是让集团成员与集团外联营企业产生关联；不是把所有联营企业都拉进企业集团，也不是让两个联营企业之间自动构成关联方。
```

### 记忆口诀

```text
甲乙丙进集团；
丁戊在集团外；
集团成员连联营；
两个联营不互连。
```

## 十四、年度财务报告与中期财务报告的组成和计量差异

### 核心结论

年度财务报告通常是“四表一附注”；中期财务报告通常至少是“三表一附注”。

```text
年报：资产负债表、利润表、现金流量表、所有者权益变动表、附注。
中期：资产负债表、利润表、现金流量表、附注。
```

中期财务报告不是年度财务报告的简单缩略版。确认和计量原则应与年度财务报告一致，但为了及时提供信息，中期计量相对于年度计量更依赖估计。

```red
“中期财务报告计量在很大程度上依赖于估计”不是说可以随便估，而是说中期报告出具时间短，很多事项来不及像年报那样完整盘点、函证、最终结算，因此在可靠基础上更多使用合理估计。
```

### 对比表

| 项目 | 年度财务报告 | 中期财务报告 |
| --- | --- | --- |
| 报表组成 | 四表一附注 | 至少三表一附注 |
| 所有者权益变动表 | 通常完整列报 | 通常不作为最低组成要求 |
| 附注详细程度 | 完整附注 | 可适当简化，重点披露重大变化和重要事项 |
| 会计政策 | 年度完整口径 | 应与年度财务报表采用相同会计政策 |
| 会计期间观 | 一个完整会计年度 | 中期也应视为独立会计期间 |
| 季节性、周期性、偶然性收入 | 按准则确认 | 不得为平滑全年结果提前或递延确认，除非年度末也允许 |
| 不均匀发生的费用 | 按准则确认 | 只有年度末允许预提或待摊的，中期才可以预提或待摊 |
| 所得税费用 | 按年度实际情况确认 | 通常按预计年度平均实际税率计算 |
| 重要性判断 | 以年度财务数据为基础 | 以中期财务数据为基础 |
| 计量方式 | 更接近完整结算和最终资料 | 为体现及时性，更多依赖估计 |

### 中期比较财务报表口径

中期比较报表要按报表性质区分。资产负债表是时点报表，利润表和现金流量表是期间报表。

| 报表 | 中期报告本期列报 | 比较期间 |
| --- | --- | --- |
| 资产负债表 | 本中期末资产负债表 | 上年度末资产负债表 |
| 利润表 | 本中期利润表；年初至本中期末利润表 | 上年度可比中期利润表；上年度年初至上年可比中期末利润表 |
| 现金流量表 | 年初至本中期末现金流量表 | 上年度年初至上年可比中期末现金流量表 |

```red
资产负债表永远抓“本中期末 vs 上年度末”；利润表抓“两套期间”：本中期单期 + 年初至本中期末；现金流量表只抓“年初至本中期末累计”。
```

如果编制 9 月 30 日三季度报告：

| 报表 | 本期口径 | 比较口径 |
| --- | --- | --- |
| 资产负债表 | 2×25.9.30 | 2×24.12.31 |
| 利润表：本中期 | 2×25.7.1-2×25.9.30 | 2×24.7.1-2×24.9.30 |
| 利润表：年初至本中期末 | 2×25.1.1-2×25.9.30 | 2×24.1.1-2×24.9.30 |
| 现金流量表 | 2×25.1.1-2×25.9.30 | 2×24.1.1-2×24.9.30 |

如果编制 6 月 30 日半年度报告，本中期和年初至本中期末通常都是 1-6 月；如果是第二季度季度报告，本中期是 4-6 月，年初至本中期末是 1-6 月。

### 估计依赖怎么理解

中期报告追求及时性，通常要在半年、季度等较短时间内向报表使用者提供信息。此时很多资料还没有最终确定，例如：

```text
存货可能尚未完成年度全面盘点；
所得税费用可能尚未完成年度汇算清缴；
年终奖金、返利、质量保证支出等可能还没有最终结算；
减值、预计负债等项目可能只能基于当前可获得资料估计。
```

因此，中期报告中会更多使用估计数，但这种估计仍应建立在可靠信息基础上，并保持与年度财务报告一致的确认和计量原则。

### 按履约进度确认收入不是平滑收入

如果工程合同满足在某一时段内履行履约义务的条件，收入准则本来就要求按照履约进度确认收入。这种处理在年度财务报告中也适用，因此中期财务报告也可以按已经完成的履约进度确认收入。

```text
合同价款 1,000 万；
6 月 30 日履约进度 40%；
中期可以确认收入 = 1,000 × 40% = 400 万。
```

这不是为了平滑利润而预计收入，而是因为截至中期末已经履约 40%。

```red
按履约进度确认：确认已经完成的履约部分；禁止平滑收入：确认未来尚未履约的部分。工程按履约进度确认收入，是收入准则本来允许或要求的处理，不属于中期报告中禁止的预计或递延收入。
```

如果 6 月 30 日履约进度为 0%，即使预计全年会完成 60%，也不能在中期提前确认 600 万收入。

### 记忆口诀

```text
年报四表一附注；
中期三表一附注；
资产比上年末；
利润单期加累计；
现金流只看累计；
确认计量原则一致；
中期及时，所以多估计；
独立期间，不准平滑；
进度确认看已履约，未来履约不能提前。
```

## 十五、现金流量表投资活动项目填列

### 核心逻辑

投资活动看的是“长期资产和投资”的现金收付，不看损益科目名称。先分清两件事：

```text
收回的是投资本金，还是取得的投资收益；
处置的是单项长期资产，还是子公司及其他营业单位。
```

### 主要项目对照

| 项目 | 填列内容 | 易错点 |
| --- | --- | --- |
| 收回投资收到的现金 | 收回交易性金融资产、债权投资、其他债权投资、其他权益工具投资、长期股权投资等取得的现金 | 只放投资本金回收；债权投资收回的利息不放这里 |
| 取得投资收益收到的现金 | 现金股利、利润分配、债权投资利息收入等实际收到的现金 | 股票股利不产生现金流量 |
| 处置固定资产、无形资产和其他长期资产收回的现金净额 | 处置长期资产收到现金减处置费用后的净额 | 自然灾害造成固定资产毁损收到保险赔款，也放这里 |
| 处置子公司及其他营业单位收到的现金净额 | 处置价款中收到现金的部分，减去该单位持有的现金及现金等价物和相关处置费用后的净额 | 负数时改列“支付其他与投资活动有关的现金” |
| 收到其他与投资活动有关的现金 | 其他投资活动现金流入 | 金额较大的，应单独列示 |
| 购建固定资产、无形资产和其他长期资产支付的现金 | 购买、建造长期资产实际支付的现金，包括相关税费 | 为购建长期资产发生的资本化借款利息不放这里 |
| 投资支付的现金 | 购买交易性金融资产、债权投资、其他债权投资、其他权益工具投资、长期股权投资等支付的现金，以及相关佣金手续费 | 不包括取得子公司及其他营业单位支付的现金净额 |
| 取得子公司及其他营业单位支付的现金净额 | 取得价款中以现金支付的部分，减去取得单位持有的现金及现金等价物后的净额 | 负数时改列“收到其他与投资活动有关的现金” |
| 支付其他与投资活动有关的现金 | 其他投资活动现金流出 | 金额较大的，应单独列示 |

### 难点拆解

“收回投资收到的现金”和“取得投资收益收到的现金”最容易混。

```text
卖出或收回投资本金：收回投资收到的现金；
收到现金股利、利润、债券利息：取得投资收益收到的现金；
收到股票股利：没有现金流量。
```

“处置长期资产”和“处置子公司及其他营业单位”也要分开。

```text
卖一台设备、卖一项专利、固定资产毁损收到保险赔款：
处置固定资产、无形资产和其他长期资产收回的现金净额。

卖掉一个子公司、处置一个业务单位：
处置子公司及其他营业单位收到的现金净额。
```

```red
处置子公司及其他营业单位看的是“整体交易净额”：收到的现金，要扣掉被处置单位账上带走的现金及现金等价物，还要扣相关处置费用。净额如果为负数，不在流入项目硬列负数，而是转到“支付其他与投资活动有关的现金”。
```

### 反常识点

为购建固定资产、无形资产等长期资产发生的借款利息，即使会计上资本化进在建工程，也不列“购建固定资产、无形资产和其他长期资产支付的现金”。

```red
现金流量表按现金流性质分类，不按会计资本化去向分类。资本化借款利息仍属于筹资成本，列“分配股利、利润或偿付利息支付的现金”。
```

分期付款购买固定资产、偿还租赁负债本金和利息等，也不要机械放进购建长期资产项目，教材口径通常放在筹资活动相关项目中判断。

### 记忆口诀

```text
投资本金回收，收回投资；
股利利息入账，取得收益；
卖长期资产，看净额；
卖子公司，扣掉它带走的现金；
资本化利息，仍走筹资。
```

## 十六、现金流量表筹资活动项目填列

### 核心逻辑

筹资活动看的是导致资本和债务规模、结构发生变化的现金流。重点抓三类：

```text
向所有者筹资；
向债权人借款或发债；
向所有者和债权人还本付息或分配利润。
```

### 主要项目对照

| 项目 | 填列内容 | 易错点 |
| --- | --- | --- |
| 吸收投资收到的现金 | 发行股票等权益工具实际收到的现金净额 | 发行股票由企业直接支付的审计、咨询等费用，列“支付其他与筹资活动有关的现金” |
| 取得借款收到的现金 | 短期借款、长期借款、发行债券实际收到的现金净额 | 发行债券收入按扣除直接支付佣金等发行费用后的净额反映 |
| 收到其他与筹资活动有关的现金 | 其他筹资活动现金流入 | 金额较大的，应单独列示 |
| 偿还债务支付的现金 | 偿还借款本金、债券本金等 | 只放本金，利息另列 |
| 分配股利、利润或偿付利息支付的现金 | 现金股利、利润分配、借款利息、债券利息等 | 借款利息用途不影响本项目 |
| 支付其他与筹资活动有关的现金 | 其他筹资活动现金流出 | 包括发行股票债券直接支付的审计咨询费、偿还租赁负债本金和利息、租赁预付款和租赁保证金、分期付款购买长期资产支付的现金等 |

### 难点拆解

偿还债务和偿付利息要拆开：

```text
还本金：偿还债务支付的现金；
付利息：分配股利、利润或偿付利息支付的现金。
```

借款利息不看它最后进了哪个会计科目。

```text
计入财务费用的利息；
资本化进在建工程的利息；
其他符合资本化条件的利息；
```

只要是借款或债券利息现金支出，通常都放“分配股利、利润或偿付利息支付的现金”。

```red
“资本化利息进资产成本”只影响会计计量；现金流量表仍按筹资性质列示，不能因为借款利息资本化就放到投资活动。
```

### 反常识点

发行股票收到的钱是筹资流入，但企业为发行股票直接支付的审计、咨询等费用，不是投资活动，也不是经营活动，而是“支付其他与筹资活动有关的现金”。

租赁相关付款也容易反常识：

```red
偿还租赁负债本金和利息、支付租赁预付款和租赁保证金，教材口径通常归入筹资活动现金流出；但短期租赁、低价值资产租赁和未纳入租赁负债的可变租赁付款额，更接近日常经营支出，通常列经营活动现金流出。
```

## 十七、汇率变动影响与现金流量表补充资料

### 汇率变动对现金的影响

外币现金流量和境外子公司的现金流量折算时，通常按现金流量发生日的即期汇率折算；也可以采用按照系统合理方法确定、与发生日即期汇率近似的汇率折算。

但是，现金流量表中的“现金及现金等价物净增加额”还要和资产负债表的期末现金及现金等价物余额衔接。资产负债表上的期末外币现金通常按资产负债表日即期汇率折算。

```text
现金流发生日汇率折算的现金流量净额
和
资产负债表日汇率折算的期末现金余额变动
之间的差额
= 汇率变动对现金及现金等价物的影响
```

```red
“汇率变动对现金及现金等价物的影响”不是经营、投资、筹资活动本身产生的新现金流，而是外币现金用不同日期汇率折算产生的换算差额。
```

### 补充资料披露

现金流量表附注通常要披露三类信息：

| 补充资料 | 作用 |
| --- | --- |
| 将净利润调节为经营活动现金流量 | 解释利润和经营现金流为什么不同 |
| 不涉及现金收支的重大投资和筹资活动 | 说明虽然影响资产、负债或权益，但没有现金流入流出 |
| 现金及现金等价物净变动情况 | 衔接现金流量表与资产负债表现金余额 |

### 难点拆解

净利润调节为经营活动现金流量，核心是把“权责发生制利润”调整成“经营活动现金收付”。

```text
第一步：从净利润出发；
第二步：加回没有现金流出的费用，如折旧、摊销、减值损失；
第三步：剔除不属于经营活动的损益，如投资收益、处置长期资产损益、财务费用中的非经营部分；
第四步：调整经营性资产和经营性负债的增减变动。
```

反常识点在于：这张调节表不是重新编一遍主表，而是解释“净利润为什么不等于经营活动现金流量净额”。

```red
净利润调节表只服务于“经营活动现金流量净额”，不把投资活动、筹资活动现金流量重新列一遍。处置长期资产损益、投资收益、财务费用等要从净利润中剔除，是因为它们虽然影响利润，但不属于经营活动现金流。
```

### 记忆口诀

```text
外币现金流，发生日折；
期末现金，期末日折；
两边差额，汇率影响。

补充资料三件事：
利润调经营；
非现金投筹；
现金净变动。
```
