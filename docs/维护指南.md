# 维护指南

本项目以“内容源 → 构建 → 离线网页 → GitHub Pages”为唯一发布链路。不要直接编辑生成后的 `study-data.js` 或 `CICPA会计复习手册.html`。

## 日常内容更新

1. 在 `01-会计/01-章节笔记/` 整理或勘误 Markdown 内容。
2. 修改对应的 `会计复习网页/data/topics/*.mjs` 卡片源；新增卡片时同步更新 `data/index.mjs` 的 `entryOrder`，并更新 `data/meta.mjs` 日期。
3. 如需改页面结构、样式或交互，只改 `会计复习网页/src/`。
4. 运行检查并确认生成物变化合理；它会同步离线网页和 30 章 Markdown：

   ```bash
   npm run check
   git diff --check
   ```

5. 打开 `会计复习网页/CICPA会计复习手册.html`，检查搜索、章节筛选、卡片展开和分录视图。

章节 Markdown 位于 `01-会计/04-章节复习卡片/`。该目录由 `npm run notes:build` 生成；卡片内容的实际维护入口仍是 `会计复习网页/data/topics/`，不要手改生成的章节文件。

## 发布前检查

```bash
git status --short
git diff --check
npm run check
```

提交时只暂存已确认的路径，避免使用无差别的 `git add .`：

```bash
git add README.md docs .github .gitignore .gitattributes .editorconfig
git add '会计复习网页/data' '会计复习网页/src' '会计复习网页/scripts'
git add '会计复习网页/CICPA会计复习手册.html' '会计复习网页/study-data.js'
git commit -m "维护 CPA 复习资料库"
git push origin <你的分支>
```

合并到 `main` 后，`.github/workflows/deploy-pages.yml` 会再次执行完整校验，并发布单页离线手册为 GitHub Pages 首页。

## 本地资料约定

- `01-会计/03.完整讲义/`：本地课程讲义与个人归档，不纳入 Git。
- `.local-artifacts/`：本地浏览器截图和临时校验输出，不纳入 Git。
- PDF、XLSX 等二进制学习资料默认不纳入 Git；若确需公开，请先确认来源与授权，再单独调整规则。
